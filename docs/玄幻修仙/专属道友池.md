### 3.2 道侣候选四人工传与结缘词（`spouse.{npcId}.{form}` / `bond.{npcId}.flavor` 词表正典源 · 原 v1.2）


> 创作纪律：双修文案一律写意留白（灯灭帷幕落级别），炉鼎形态的黑暗感只写「失去」不写「占有」；每条炉鼎结缘词都止于分离——与机制（karma −20 入账 / 回头即散 / 好感锁死）同频。

#### 苏晚 `suwan`（暖玉 · 通-地-02 前人遗藏）

**小传**：那封没寄出的家书的收信人。你在山下找到她时，她正在浣衣，手背冻得发红。她安静听完洞府里的事，没有哭，只是把信末「父字」两个字摩挲了一遍又一遍，说：「我早知道。他说七日，哪怕七年，也总会回来的。」后来她学着认灵文、绘符纸，在坊市口支了个小摊。她说，修士的家眷，不能只会等。

- **阴阳双修** `spouse.suwan.yinyang`：结契那夜，她把那封家书摆在两人之间的案上：「爹，我等到一个与我共灯的人了。」窗外月色如水，窗内灯没有灭。
- **互助双修** `spouse.suwan.huzhu`：她把小摊挪到了你洞府外。你看你的剑诀，她绘她的符纸，一句话说半天，偶尔也各自安静——安静的时候，谁也不觉得欠谁。
- **炉鼎采补** `spouse.suwan.luding`：她看清你运行的法门后，沉默良久，把围裙解下来叠得整整齐齐：「家书的恩，我还到这里。往后——两清了，各自珍重。」

#### 谢青鸾 `xie`（剑侣 · 通-地-06 街头较技）

**小传**：集市设擂的游方剑修，剑尖永远垂着三分——这份礼节她此生只给过两个人，一个是故去的师父，一个是你。比剑之后她拉你喝到月上中天，把剑拍在桌上：「能接我三剑的人不多，接了还收得住力的，更少。」她从不说师门的旧事，只在剑穗上挂着半截旧绳。另外半截在哪里，她不提，你也一直没问。

- **阴阳双修** `spouse.xie.yinyang`：她把另外半截剑穗给了你。大礼设在剑崖，没有宾客，只有山风。她说：「我找了一辈子对手，没想过最后输给一个收剑的人。」
- **互助双修** `spouse.xie.huzhu`：你们约定每月七号比剑一场，胜负各半，谁也不许让谁。「道侣不必同室，」她收剑入鞘，「同剑就够了。」
- **炉鼎采补** `spouse.xie.luding`：她看清法门的瞬间拔了剑，剑却在离你眉心半寸处停住，终究收鞘。「我打不过你，也打不过自己。」她自嘲一笑，「这半截剑穗，算我输给了从前那个你。此后江湖，剑不相见。」

#### 夜芜 `yewu`（引夜 · 修-地-02 魔道密使）

**小传**：三更落进你洞府传帖的魔道密使。帖子是血色的，递帖的手很稳；话是主上的，一个字不多。可临走时她会在檐上停一瞬，说一句与任务无关的话——「坊市口那炷香歪了，你以后别去买。」「你洞府阵法第三眼漏风。」魔窟里没人知道她传了多少年的话，也没人知道她入道前叫什么。她只记得自己每次传完帖，都会回头看一眼。那晚你当众撕帖逐她，她走时没有留下一句狠话，只是多看了你一眼。

- **阴阳双修** `spouse.yewu.yinyang`：她穿着魔道使服来赴大礼，当着满堂宾客把血色请帖投进火盆：「魔道的帖，我传完了。往后——只传你家的家书。」那晚帖子烧了很久，灰是白的。
- **互助双修** `spouse.yewu.huzhu`：你们约定每夜三更，檐上一炷香的说话时间，说完各自散去。「魔道里没人说话，」她望着远处的黑，「你我之间，能说话，就够了。」
- **炉鼎采补** `spouse.yewu.luding`：她在你开口前就看穿了法门，竟没有走。她坐下来，慢慢解下腕上的铃：「魔道双修，说不清谁是炉鼎，谁是薪柴。你要修——这只铃，先押在你这里。」

#### 沈孤鸿 `shen`（鉴宝 · 修-地-06 残卷交易）

**小传**：为葬母变卖半卷家传功法的穷书生。成交那日他朝你长揖到底：「卷是残卷，价是实价，君子不欺。」后来他真成了坊市最讲信用的鉴宝人——过手的东西，真就是真，假就是假，多一个字都不肯说。没人知道他鉴宝台的抽屉里锁着一本手账，账上第一笔就是你的名字，旁边注着一行小字：「此账，以余生偿。」

- **阴阳双修** `spouse.shen.yinyang`：结契那夜他把手账取出来，当面划掉了第一笔，然后在新一页写下：「今日起，同账。」他话很少，朱笔的注释却写满了整页。
- **互助双修** `spouse.shen.huzhu`：他鉴他的宝，你修你的剑，闲时替他把功法的错漏一条条校出来。「道侣如合伙，」他给你斟茶，「各记各的账，也共一本。」
- **炉鼎采补** `spouse.shen.luding`：他听明白你的来意后，静了整整一炷香，然后把手账合上，收进怀里：「君子不问人所为。只是账上第一笔——请容我撕了。」纸撕得很慢。他拱手，转身，没有回头。

### 6.1 为什么要给道友标阵营

用户诉求原话：「我魔道阵营称谓到顶了，按道理会让那些魔道的角色心生好感。」此前**阵营归属与道友好感完全脱钩**——玩家修到「极道魔尊」，魔道中人照样形同陌路；反之浩然道尊也不受正道另眼相待。善恶名号九段（`KARMA_RANKS`）与道友池两套数据各自成立、互不通信。

### 6.2 三向归属判据

### 6.4 同道相吸（名号 → 好感）内容侧口径

| 项 | 口径 |
|---|---|
| 触发时机 | 善恶名号**跨段瞬间**（`recalcDerived` 里 `rankPrev !== rankNow`，与「名号更迭」日志同一刻） |
| 受益者 | 与新名号**同向**（`align === dir`）且**已相识**（`bond > 0`）的道友 |
| 幅度 | `+BOND_ALIGN_GIFT_BASE(2) × dist`，封顶 `BOND_ALIGN_GIFT_CAP(8)`；`dist` = 名号到中段「左道散人」的段位距离 ∈ [0,4] |
| 实测档 | 浩然道尊 / 极道魔尊（dist 4）→ **+8**；正气魁首 / 魔道巨擘（dist 3）→ **+6**；清明真人 / 邪修（dist 2）→ **+4**；持正之士 / 入魔（dist 1）→ **+2**；左道散人（dist 0）→ **0** |
| 频次 | **每名号每世限一次**（`ws.rankGiftSeen`）——karma 在段界来回震荡不能刷好感 |
| 写口 | 走 `Bonds.gain` 唯一正向写口 → 绝交锁（−99）与心结锁自动拒入账 |

**三条内容纪律（护栏）**

1. **未相识不白送档位**：`bond === 0` 的同向道友**不入账**。结缘必须由出身/专属事件门控触发，否则「名号一升、58 人集体相识」会一次性烧掉全部小传与结缘词的揭示节奏。
2. **中性段零发放且不占名额**：跨到「左道散人」不发好感、也**不写** `rankGiftSeen`——否则玩家先在中性段晃一次就把该段名额吃掉，后续真跨段反而不发。
3. **只增不减、不做反向惩罚**：本联动**只有正向**。魔道名号不会让正道道友掉好感（那属事件代价，走 §二 的情谊有裂/真绝交锁），避免「名号一升、半池道友集体翻脸」把好感系统变成不可逆的单向门。
