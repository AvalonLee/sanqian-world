功法融合与法宝器灵是《三千世界》的**终局长线双轴**：前者把「70 部正典功法」从收集终点变成**重组起点**——两部满级天阶作父本，玩家可以铸出属于自己的功法，三代封顶、词条守恒、双亲消耗，数值上不越正典一步；后者把「46 件法宝」从静态签名效果养成**有名字、有脾气、会开口**的同伴——温养觉醒、五档人格、一灵一技，全部机制经由既有通道兑现小额、限时、带 CD 的干预。两轴共享同一条纪律：**叙事自由度不泄漏进数值层**——判词再毒舌，护魂的 `tribBonus` 也只能 +0.01；自创再逆天，单字段每级也超不过现行全录最大值。

## 一、定位与世界适用

### 1.1 系统定位

- **功法融合（自创功法）**= 功法层终局水槽：消耗两部 Lv9 功法（含升级途中投入的全部修为）+ 悟道条件，产出一部词条重组、档位定档、可命名、可再融合的自创功法——给「功法已集齐」的长线玩家一条继续投入的纵深线；
- **法宝器灵** = 法宝层叙事 + 主动技深化：温养值把「祭出中的法宝」变成持续陪伴，觉醒后的器灵人格提供判词陪伴（复用天道卷判词引擎构型，天道系统设计 §二），器灵技给法宝追加**第二回调**（主动技，走既有法宝回调通道扩展，不开新执行面）；
- 与既有系统的关系是「消费既有通道，不新开轴」：自创功法持有/升级/散功 = Arts 既有通道；护魂渡劫修正 = 数值详设 §8.3 talent 加项同读点；剑意/凶性/仙音 = pushBuff 既有构型；吞噬 = `on_kill_stones` 既有消费点限时加项；真灵承继 = 轮回卷 meta 层 ✅（2026-10-07 死链修复批解判定环 #259 → 同线 **真灵承继补完批 2026-10-07** 再落**器灵状态随件承继**（`meta.heirSpirit` 快照 → `Treasures.gain` 后 `Fusion.heirRestore`）与**跨世彩蛋**（`actions.js:246` → `Fusion.onEquipHeir`，#260）两环，逐环取证见文末 §十四 ①；残留仅「无玩家承继选择 UI」）。

- 本卷为**玄幻修仙世界系统落地卷**（功法融合用修仙语汇，器灵人格 = 剑灵/兽灵/古灵/妖灵/仙灵；器灵半卷挂法宝系统——修仙专属，古武无法宝）；

### 2.2 融合成功率（公式定案）

```
p_fuse = clamp( FUSE.BASE_P (0.60)
              + min( floor(神/6), 8 ) × 0.01        /* 悟性修正：神每 6 点 +1pp，封顶 +8pp（神 ≥48） */
              + min(境界索引, 9) × 0.02,             /* 境界修正：每阶 +2pp，封顶 +18pp（真仙） */

```

|---|---|---|---|
| 裸身化神（门槛画像） | 30 | 4 | 0.60 + 0.05 + 0.08 = **0.73** |
| 典型炼虚 | 36 | 5 | 0.60 + 0.06 + 0.10 = **0.76** |
| 深养真仙 | 48+ | 9 | 0.60 + 0.08 + 0.18 = **0.86**（封顶） |

- **失败语义**：失败**不毁父本**（双亲原样保留、等级不动）；悟道石已消耗**不返还**（通道 B 的风险成本）；通道 A 计数不清零（资格已在发起时消耗判定——实施口径：发起即扣资格快照，失败后需重新满足 12h 增量或再耗一石，实施批对表后二者取一并登记，本卷正典按「资格随尝试消耗」执行）；CD 照常 3 现实天；

## 三、功法融合 · 词条重组与定档

### 3.1 字段定义

- **主修字段**：一部功法 `effects` 中**每级值最高**的字段（并列时按功法全录正典出场序取先者）；**副字段**：其余字段；
- **主修双亲**：双亲中主修字段每级值较高者（并列取正典出场序先者）；另一部为副亲；
- **代数 gen**：正典部 gen = 0；自创部 gen = max(双亲 gen) + 1；**gen ≥ 3 的部禁作父本**（代数封顶三代，发起校验拒绝）。

### 3.2 重组算法（定案）

| 词条块 | 规则 |
|---|---|
| **主修字段** | 每级值 = clamp( 双亲主修字段均值 × **1.1** × `GEN_MULT[gen]`, ≤ `FIELD_CAP[字段]` )；`GEN_MULT = {1: 1.05, 2: 1.02, 3: 1.00}`（三代重组加成递减，防数值失控）；双亲主修字段不同名时，子部主修 = **主修双亲的字段**（均值只在该同名字段间发生；异名时取主修双亲字段、值 = 主修双亲值 ×1.0×GEN_MULT——异名不双承，防字段数膨胀） |
| **副字段** | 双亲全部副字段并入候选池，**随机保留一条**（原值、不放大）；其余丢弃 |
| **特殊词条** | 按**稀有度保留表**掷定一次、结果永久：主特殊（主修双亲的 special）按档位保留概率 **强(grade2) 100% / 标准(grade1) 75% / 弱(grade0) 50%**；副特殊（副亲 special，与主特殊同池则跳过）固定 **25%** 保留；保留下来的 special 池与档位原样继承（不升档）；**独占签名 3 条（三尸宴坐/人间烟火/枯井不波）与非乘区字段（checkBonus / attrBonusAmp / tribFailLossMod）永不进重组池**——独占 3 部本就禁入融合（§2.1），此行为第二道闸 |
| **档位 tier** | `tier = min( floor( (tier₁ + tier₂)/2 + 0.5 ), 天阶 )`（序：黄0/玄1/地2/天3）——天+天→天、地+天→地、玄+地→地、黄+玄→玄、黄+黄→黄；品阶系数随定档 tier 取 `ARTS_COST_TIER`（黄1/玄3/地10/天36，升级消耗同口径） |

| **学习要求** | 不再校验——融合门槛（双亲 Lv9）已含资格；自创部直接入门 Lv0，升级/入槽/练习度规则与正典部完全一致（数值详设 §4.1/§4.2 同源） |

### 3.3 数值守恒原理（为什么敢开融合）

1. **双亲消耗**：成功即吃掉两部满级父本——自创部不是「额外新增的第七部功法」，而是把两部正典的词条预算**压缩重组**进一部；六槽总预算天然守恒；
2. **FIELD_CAP = 不造新上限**：任何字段每级值不超过现行全录同字段最大值，自创最强 = 正典同字段之最的等值替身；
3. **#105 静态审计零漂移**：#105 逐字段审计上限的基线 = 正典 70 部静态池（通用规范 §一），自创部**不入全录静态池、不改上限表**；玩家层装备极值因「父本已消耗 + cap 等值」不超出正典极值结构；
4. **代数递减**：×1.05/×1.02/×1.00 让二代、三代融合在 cap 之下的中段字段也逐代收敛，「越融越强」只在 gen1 显著、gen3 归零——三代是荣誉代数，不是数值代数。

- 结论 ①：**三代最强期望 = FIELD_CAP = 现行全录同字段每级最大值等值**——最强链在 gen1 即触顶，代数递减系数只对 cap 之下的中段字段生效（如 combatSpeed 夺魂 9 + 破锋 7 → gen1 9.24 → cap 9；artsSpeed 丹元 8 + 养丹 6 → gen1 8.1 → cap 8），「三代」的数值意义是收敛不是膨胀；
- 结论 ②：**对照天阶独占 3 部不越位**——独占 3 部的强度在独占签名字段（checkBonus +3%/级、attrBonusAmp +10%/级、tribFailLossMod −8pp 固定值，均为**不入乘区审计字段**，通用规范 §一），自创部**永不产出**这三类字段与三条签名（§3.2 第二道闸 + §2.1 独占禁入双闸）；主修数值面自创最强（combatPower 14/级）= 正典之最等值，独占部的「独」不被稀释；
- 结论 ③：**成本对照**——独占 3 部 = 天级特殊奇遇「指定分支 + 判定链全过」一次性授予；三代自创链 = **消耗 8 部满级天阶正典**（gen3 需 2 部 gen2，每部 gen2 需 2 部 gen1，每部 gen1 需 2 部正典天阶）+ 7 次融合掷判（每次 CD 3 现实天 → ≥21 现实天纯 CD）+ 7 份悟道条件——获取成本远高于独占部，数值等值、独占不侵、成本远高，**不越位成立**。

### 8.3 CD 防刷三件套

1. **时间戳账本**：`st.spirit.cd` 发动瞬间落账（绝对时间戳，离线判定同源），CD 内点击拒绝且不落账；
