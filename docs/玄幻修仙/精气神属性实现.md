## 二、修仙世界：精 · 气 · 神 定义

| 属性 | 世界观含义 | 判定覆盖的事件类型 | 被动效果（带封顶，登记乘区总表） |
|---|---|---|---|
| **精**（jīng） | 肉身体魄、筋骨之力 | 斗战类：斩妖、护镖、承受伤势、军阵冲杀 | `combatPower +0.1%/点`，**封顶 +12%**；瓶颈时精达标 → 击杀间隔惩罚 ×3 降为 ×2（以武破巧） |
| **气**（qì） | 真元储量、灵根亲和 | 修行类：悟道残碑、炼丹炼器、灵泉吐纳 | `qiCap +0.5%/点`，**封顶 +30%**（只放宽挂机上限，不加速产出） |
| **神**（shén） | 神魂道心、意志定力 | 心志类：抗心魔、破幻术、奇遇抉择、护法 | 渡劫**失败损失修正** `clamp(1 − 神/dc标准, −1, +1) × 0.10`（神高损四成、神低损六成，**不动 p 公式四项**；**校对批订正 2026-10-01**：P5/v1.1 勘误式 `clamp(神/dc −1)` 在主公式加法口径（`0.5 + 修正`，主设计 §7.2）下算得「神高损六成」，与语义注及天赋池符号约定（−0.10 = 只损 40%）恰好相反，撤销该勘误、恢复原式方向）；`eventLuck +0.2%/点`，封顶 +10% |

> 三属性各管一条「非经济」支线：精管打、气管存、神管稳——与既有 13 个乘区（数值详设 §八）零重叠、零双吃。

## 三、数值构成与成长曲线

### 3.1 境界基础值

```
基础值 = (境界索引 + 1) × 6        三属性同值（境界滋养三维，分化靠养成）
练气 6 → 筑基 12 → … → 渡劫 54 → 真仙 60
```

### 3.2 功法滋养（主要分化来源一）

每部功法新增 `attr` 字段（精/气/神 之一），滋养值 = **正道/左道 2 点/级、魔道 3 点/级**（魔道属性长得快，与其 karma 代价、渡劫劣势呼应「快但险」）。满级单部 **+18/+27**（Lv9 = 每级 ×9，修行状态批 v2.0；旧 Lv5 口径 +10/+15）。

| 属性 | 功法（12 部映射） |
|---|---|
| 精 | 云踪步（左）、金钟罩（正）、炼尸诀（魔）、夺魂术（魔） |
| 气 | 吐纳法（左）、聚灵诀（左）、拂尘木咒（正）、噬血功（魔） |
| 神 | 清心咒（正）、福缘咒（正）、护体神光（正）、聚仙幡（魔） |

- 渡劫成功功法等级清零 → **属性滋养同步回落**（属性跟随重算），突破后有一段「三维虚弱期」，与重修循环互为表里；
- 6 槽全堆同属性：满级极限 **+108（正/左）~ +162（全魔道）**（Lv9 口径；旧 Lv5 为 +60~+90）。

### 3.3 法器滋养（主要分化来源二）

法器新增第四词条 **`attrValue`（属性亲和）**，**灵品起解锁**（凡 1 / 良 2 / 上 3 / 灵·仙 4 词条——上品及以下维持复核锁定的三词条池不动）：

| 品阶 | attrValue 区间 | 说明 |
|---|---|---|
| 灵品 | 8~14 | 单属性随机（精/气/神 等权） |
| 仙品 | 15~25 | 同上 |

- **不随秘境缩放**（属性是判定轴，dc 难度线随境界走，装备若再随秘境指数缩放会让后期判定全部失去悬念——与 resist 同理）；
- **槽位亲和权重**（掉落时决定 attr 归属，非硬绑定）：兵刃/甲衣 → 精 50%/气 25%/神 25%；灵器 → 气 50%/精 25%/神 25%；佩饰 → 神 50%/气 25%/精 25%；
- 4 件仙品单堆极限 ≈ +80；
- **评分公式同步扩展**：`score = atk + qiBonus×100 + resist×0.5 + attrValue×3`（自动择优时属性词条计入价值）。

### 3.4 事件永久加成

悟道/机缘类事件可给 `attrEventBonus`（单次 +1~3，**只增不清**，与 karmaEventScore 同款「做过的事赖不掉」语义），存档单独字段。全程累计设计上限 ≈ +15。

### 3.5 天赋与 buff

- 天赋结构**预留 `attrBonus` 字段，现行天赋池 130 条（通用 50 + 修仙专属 80，《天赋池设计》v1.4）全部暂不启用**（不动已复核的天赋池；P6 新世界或大版本再投放属性天赋；旧「首发 42 条」为二轮扩容前口径）；
- 丹药/奇遇 buff 可给限时属性（如「悟道茶」：神 +20，4 小时），走既有 `buffs[]` 通道。

### 3.6 成长曲线总览（单属性）

| 阶段 | 裸身 | 适中养成 | 极限单修 |
|---|---|---|---|
| 金丹 | 18 | ≈30（2 功法 Lv3） | ≈70 |
| 化神 | 30 | ≈55（4 功法 + 1 灵品） | ≈110 |
| 合体 | 42 | ≈90（5 功法 Lv4 + 3 灵品） | ≈165 |
| 真仙 | 60 | ≈150（6 功法 Lv5 + 4 仙品 + 事件） | ≈317 |

> **Lv9 重校准注（修行状态批 v2.0 · 校对批 2026-10-01）**：本表为 Lv5 时代快照——等级上限 0~9 后功法滋养部分整体 ×1.8（单部满级 +18/+27、六槽全堆 +108~+162）。**极限单修**列真仙行已机械重校准 = 60 基 + 162 功法（全魔 Lv9）+ 80 装备（4 仙品单堆极限，§3.3）+ 15 事件 = **≈317**；其余境界段极限列含养成进度假设，随实施批模拟一并重校准。**适中养成**列的终局主流等级（Lv6~9 取舍，受数值详设 §4.2 修为消耗曲线约束）待实施批 sim-pacing 重校准，旧值保留为快照。

## 五、事件词条接入示例（事件池增量）

### 5.1 数据结构扩展

事件条目的 `outcomes` / `choices` 支持可选 `check` 字段：

```
check: { attr: '神', dc: '中等', onSuccess: […效果], onFail: […效果] }
```

无 `check` 的条目行为不变（纯权重），32 条存量词条**零改动兼容**；首批改造 6~8 条 + 新增 2 条。

### 5.2 示例词条

| 事件 | 判定 | 成功 | 失败 |
|---|---|---|---|
| 残碑悟道（改造） | 气 · 中等 | 主修功法 +2 级 | 参悟不得，`artsProgress +0`，日志「碑文晦涩，无功而返」 |
| 岔路妖踪（改造） | 「出手相救」分支挂 精 · 简单 | karmaScore +15，stones +80 | 救下人但被妖所伤：karmaScore **+15 照给**（义挙不因力竭打折），qi −10% |
| 妖雾迷途（改造） | 神 · 中等 | 破雾而出：无事 + buff 气产出 +10% 2h | 迷失半日：combatProgress −8% |
| 走火入魔（改造） | 神 · 困难 | 强行压下：仅 qi −5% | 经脉受损：qi −12% + debuff 产出 −20% 8h |
| 幻境试探（**新增**，realmMin 3） | 神 · 困难 | 识破幻境：stones +300、attrEventBonus 神 +1 | 沉溺幻境：buff 战斗速度 −15% 6h |
| 力拔山兮（**新增**，zoneMin 2） | 精 · 中等 | 搬开巨岩得遗藏：dropGear{tierMin:2} | 闪了腰：buff 精 −10 4h |

> 设计守则：**善行判定时 karma 分照给**（判定只影响物质收益，不影响善恶记账——「力竭救人」仍是善）；失败效果永不重于原祸事事件幅度（≤15% 资源、≤24h debuff，与事件池守则一致）。

### 5.3 判定的 UI 反馈

- 选择分支按钮上预告难度与成算：「出手相救（精 · 十之七八）」——文案转换表见 §六；
- 掷判演出 1 秒：属性名 + 难度 + 结果（「神判定 · 五五之数 → 成！」）；
- 事件日志追加判定标记：`[奇遇][气·中等✓] 残碑悟道：功法精进两级`。
