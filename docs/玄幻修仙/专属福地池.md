## 三、隐世福地（3 处 · v2.0 新增 · obtain 门控）

> **设计定位**：不进灵石购买通道的成就型福地——所有权由修行履历**自动授予**（达成即在 claim/normalize 内入 owned，写日志 + toast，无需手动购买）；未获所有权前入驻按钮显「缘法未至」缺项。mult 介于主线档之间，签名与主线同档持平或略优，作为长线成就的兑现。
> **caveTrack 纪律**：obtain 门控福地**不进入** `sim-pacing.cjs` 最优进程推导（模型不假设玩家必然达成），节奏验收带零影响。

## 四、附属设施养成（v2.0 新增 · 地柱纵深）

> **设计定位**：已拥有的福地可投灵石逐步营建四座附属设施（0~3 级），**营建 / 扩建入口只在当前驻留福地出现**（非驻留福地只读展示各设施等级与效果，按钮位显「仅驻留中可营建」，不显示升级选项）。营建进度**随所有权永久保留**（迁居不带走、跨渡劫不清零），效果**仅在当前驻留福地的设施生效**（搬离即失，与签名同口径）。这是「置业」感的深化：每一处福地都是一份可积累的产业。

| 设施 id | 名称 | 效果（每级） | 满级（3 级） | 营建费/级（灵石） |
|---|---|---|---|---|
| `lingtian` | 灵田 | stonesRate +1% | +3% | 3 万 / 30 万 / 300 万 |
| `danfang` | 丹房 | artsSpeed +1.5% | +4.5% | 同上 |
| `shuge` | 藏书阁 | eventLuck +2% | +6% | 同上 |
| `julingzhen` | 聚灵阵 | offlineEff +2% | +6% | 同上 |

- **乘区归属**：独立登记的小额加算来源「洞府设施」（mods 来源 `caveFac`，数值详设 §8.2 v2.0 行）——驻留唯一 ⇒ 同一时刻只有一处福地的设施生效，天然不叠加；逐字段封顶 = 满级值（stonesRate 3% / artsSpeed 4.5% / eventLuck 6% / offlineEff 6%），**不并入 #128 签名预算**，另立 #156 设施预算对表（同 #129 道友封顶范式）；
- **禁 qiRate**：与签名同纪律（caveMult 已是独立乘区，设施再进产出加算池 = 双吃）；
- 营建费记 `ledger.out.cave`（与购地同通道，不新开分类）；营建入口 = **当前驻留**福地卡内设施行（逐座 + 号，缺灵石红字）——非驻留福地只读、无按钮（洞天设施驻留限营批，2026-10-05）；
- 存档：`worlds.{id}.cave.fac = {caveId: {lingtian: lv, …}}`，normalize 逐层钳位（未知福地 id / 未知设施 / 越界等级丢弃）；
- 满配增量（四座满级 + 驻留）≈ 全局 +19.5% 小额乘区分布四轴，量级 ≈ 半个道友满档合计，处于「典型画像满驻 ≥5 天」验收带的安全边际内（速通画像带外单列，同 §九.11 口径）。
