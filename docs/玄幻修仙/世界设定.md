- 三千小世界之首发世界，中式玄幻修仙小说的鸿蒙宇宙世界观；
- 世界卡关键词标签：**修为 · 秘境 · 渡劫**；
- 专属系统：**渡劫**（概率突破）+ **善恶 karma**（正道/魔道/左道三阵营）+ **精气神属性判定**——核心规则在主设计文档 §六/§七（善恶与渡劫为全项目决策正典，不在本卷复写）。

## 五、世界名命名池（registry.nameParts）

```
prefix: 玄 青 紫 太 九 沧 天 罗 幽
middle: 云 霄 虚 阳 冥 岚 岳
suffix: 界 境 天 域 洲
```

样例：青云界 · 太虚境 · 九霄天。创角屏 3 生成一次，固定写入 `profile.worldName`。

### 5.1 法器命名池（P4 登记）

法器 `item.name` 生成规则：**材质 × 器形** 两段拼接（与品阶无关，品阶走角标/词表 `gear.tier.N`）：

```
材质: 玄铁 寒铜 青冥 紫霄 星辰 流光 墨玉 赤阳 幽银 龙虎
器形: 兵刃 → 剑 / 灵器 → 珠 / 甲衣 → 甲 / 佩饰 → 佩
```

样例：玄铁剑 · 青冥珠 · 星辰甲 · 墨玉佩（40 组合，同槽可重名，重名不影响择优——score 说了算）。
