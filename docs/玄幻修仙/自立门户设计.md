---

自立门户是《三千世界》修仙线的**终局身份玩法**：化神之后，玩家不再是「某谷某宗的供奉」，而是把自己的名字刻上山门——收徒、传法、营建、宣战，直至真仙后传位，让宗门作为第 17 个势力在世界里继续活下去。它不新开任何数值轴：弟子推进是**玩家轴外的背景养成**（sim-pacing 稳态带复跑不变），设施是 caveFac 构型的宗门侧复刻，战争是战功制引擎的第 17 位接入，供奉是 Ledger 唯一新增的一路进项（`in.tribute`）。设计上它同时是三件事：**长线资源水槽**（营建 + 培养吃掉合体期后的溢出收入）、**身份叙事装置**（宗规决定世界怎么看你、天道怎么评你）、**跨世传承锚**（宗门本身转世重置，但「开山祖师」称号与图鉴永久跨世——这一世的山门倒了，你的名字还在）。

## 一、定位与开宗门槛

### 1.1 系统定位

- 宗门 = 16 固定势力池（势力全录 §一）之外的**第 17 个动态位**：由玩家创立、经营、传位，入势力排行、可被宣战也可主动宣战（§五）；
- 全部机制干预**白名单化、构型复用、幂等化**：设施复用 caveFac 等级/营建/normalize 构型（福地池卷 §四），战争复用战功制（势力全录 §七 ✅），调遣复用职位实权构型（§8.2 ✅），弟子推进复合同代天骄 NPC 推进模型（天骄卷 ✅）；

### 1.3 声望阈值核算（2000 的来历）

- **来源渠道与速率**（势力全录 §3.2 三渠道）：捐献 rep = 灵石 ÷1000、**每现实 24h 累计上限 +300**；委托每单 +20~30；战功制胜场 +50（✅ §七）；
- **纯捐献口径**：2000 rep ≈ 200 万灵石当量 ≈ **6.7 个现实日满额捐献**（300/日上限硬顶）；混入委托与战功后 ≈ 5~6 日——对应炼虚~合体段的中长线投入；
- **节奏对位**：典型玩家真仙 ≈15.5 天（数值详设 §6.4 重校准口径），开宗门槛落在**第 6~10 天**区间（捐献细水长流 + 化神/炼虚境界线自然并行）——宗门玩法开放在真仙冲刺期与真仙后终局期之间，与「末位水槽」定位咬合；
- ⚠️ **跨卷口径注记**：势力全录 §3.2 存在已登记未澄清的歧义——「重供档（100 万 → +1000）单笔超日上限 300 按字面永不生效」（任务清单 v1.14 收口记录）。本卷核算**按 300/日上限的保守口径**取值；该歧义澄清批若放开单笔重供，峰值 2000 的达成时长缩短，属门槛放宽方向、不破坏本卷红线，无需回调常量。

### 2.2 宗名（命名词库生成 + 自定义）

- **生成器 = 前缀池 × 后缀池**：前缀 12（青/白/紫/玄/赤/苍/墨/金/灵/剑/星/雷）× 后缀 8（剑宗/丹门/谷/阁/山庄/峰盟/观/宫）= 96 组合；掷名可重掷（免费无限次，纯词表拼接零存档成本）；
- **自定义 ≤6 字**（`SECT.NAME_MAX = 6`）：入存档 `ws.sect.name`（≤6 CJK ≈18B UTF-8）；校验 = 去空白后 1~6 字符、敏感词过滤（天道卷 §2.3 同一过滤器复用，越线拒绝不落档）；**自定义名只进存档不进词表**（数据文件禁文案纪律的反向约束：玩家文本永远不写回数据文件）；

- **胜**：目标势力**声望压制**（NPC 声望 −10%，`WAR_REP_SUPPRESS`，只影响排行展示口径）+ 赔偿灵石 `ZONES×500` 记 `in.event` + 战胜场次 +1 + rel 软化/声威大振沿用；
- **败**：战创沿用 + 宗门声望零增长（不扣——败仗的代价是时间与战创，不做声望螺旋防止弃档感）；
- **⏸ 灭门不采纳（登记裁定）**：主动宣战**只打到 rep 压制与资源赔偿为止**，不删除、不吞并、不占领 NPC 势力——理由：①16 固定池是关系网/奇遇锚点/传闻文案的公共资产，删一位即破坏正典种子与十条 flavor 联动（势力全录 §十一）；②吞并带来的弟子/声望/设施继承规则是内容黑洞；③战功制 20 分钟窗口的体量撑不起「灭门」叙事承诺。观察项登记见 §十.4。

## 六、宗主实权

### 6.1 调遣弟子（个体助力 buff · ✅ 职位实权「调遣同门」构型放大版）

- **对象**：任一门徒（弟子或供奉）；**效果 = 2h buff，CD 每现实 24h**（`DISPATCH.hours / cd`，与势力全录 §8.2 执事技能同构型同 CD 带）：
  - 弟子：buff field = 弟子生成时掷定的 perk 字段（从既有 `Mods.FIELDS` 白名单 {combatPower, stonesRate, artsSpeed, offlineEff, combatSpeed} 五选一等权掷定，生成瞬间落 `disciple.perk` 字段——**不新增 FIELDS 字段**）；数值 = 资质档 `DISPATCH_APT = {fine: 0.10, mid: 0.07, raw: 0.05}`；
  - 供奉：复制该道友个体助力 perk 同口径（`perkValue = perk.perTier × tier`，§8.2 读点公式）再 **×1.5**（`DISPATCH_OFFERING_MULT`，放大版）；

- **独立预算登记**：来源 'sect' 不占 #129 道友助力预算（对表另立，实施批入断言）；量级红线 = 单次 dispatch 最大 combatPower +10%（良才）或供奉复制 ×1.5（满档道友 ≈12% 上界）× 2h / 24h CD——低于势力 perk 职级放大（≤13.5%）常驻口径，无膨胀轴；
- 与执事「调遣同门」的关系：两技能**并存、独立 CD**（职位实权 §8.1「执事权不随升迁消失」同款纪律）；开宗后玩家 `factionId='sect'`，旧势力职级派生自然归零（§1.4 清理）——调遣弟子是宗主对执事权的替代与放大。

## 八、叛宗与传承

### 8.1 传位（真仙后终局动作）

- **条件**：`ws.realm = 9`（真仙）+ 至少 1 名弟子（供奉不可继位——客卿不接山门，裁定）；
- **流程**：宗门浮层「传位」→ 择弟子（展示各弟子境界/资质/战力预览）→ CONFIRM 模态（明示三项后果：宗门转 NPC / 自己获称号 / 当世不可再开宗）；
- **结算**（mutate 单事务）：①宗门转为**第 17 位 NPC 势力**——声望 = 继承值（传位瞬间 `sectRep` 定格为正典常量入排行）、rel 表原样保留、名称/山门/宗规沿用；②弟子名录清空（随宗门转入 NPC 侧，当世存档只留 `succession = {done:true, heirName索引, sectRep快照, at}` 轻量纪念结构 ≈60B）；③玩家获称号「开山祖师」（§7.4 ✅）+ 编年史大事 + 传闻卡「一代宗师传位下山」；④`factionId` 由 `'sect'` 转为 null（自由身，可 join 其他势力——「传位下山，再入红尘」）；
- **不可逆**：传位后当世**不可再开宗**（开宗资格当世已消耗；转世后凭 meta 资格重开，§7.3）。

### 8.2 玩家死亡/渡劫失败与宗门

- 渡劫失败**不损宗门**（既有失败代价 = 修为半损 + streak，宗门资产零触碰——弟子/设施/声望不随渡劫失败蒸发，防终局弃档感）；
- 转世（轮回）= 宗门重置（§7.3 裁定）。

### 8.3 转世重置登记（裁定）

- **裁定：宗门不跨世继承**——弟子、设施、宗门声望、战争记录、第 17 位 rel 全部随当世清零；理由：①跨世继承会让第二世跳过终局水槽，破坏轮回卷的当世节奏设计；②弟子是当世 NPC 生成物，跨世存续需要整套名录迁移工程，成本与「重开一局」的体验收益不成比例；③「每一世重新开山」本身就是轮回叙事的一部分——称号与图鉴跨世（§7.4）已经把「我曾是一宗之祖」的记忆保住了。
