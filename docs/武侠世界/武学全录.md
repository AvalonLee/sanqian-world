## 一、五类与挂机产出

| 类 | 定位 | 挂机产出 |
|---|---|---|
| **内功** `neigong` | 根基，决定功力上限与恢复 | 功力速率 / 上限 |
| **拳掌** `quan` | 徒手路数 | 战力 |
| **兵刃** `blade` | 器械路数（刀枪剑鞭…） | 战力 / 暴击 |
| **轻功** `qing` | 移动与逃脱 | 遇袭逃生率 / 地界通行 |
| **奇门** `qimen` | 毒 / 暗器 / 音功 | 特殊效果 / 事件成功率 |

五类即**五装配位**（册245 确认 `kind` 五位枚举与装备位一一对应）。**品阶四档**：黄 → 玄 → 地 → 天（跨世界通用规范，与第一世界 `arts` 同构）。

**内力四性**：刚猛 → 阴柔 → 中正 → 邪异 → 刚猛（环克）。相克方战力 **×1.15**、被克 **×0.87**、同性 ×1.00。**入码（册232）**：乘区接在 `battleOdds`（对战判定层，**不进 `powerOf`**——相性依赖「对谁」）。三处「性」来源：**主角 = 主修内功之性**（无内功 ⇒ 中正）；**世界事件 boss = 门派之性**（CAST 的 `sec` 映射）；**闯荡杂鱼 = 地界之性**（13 地映射，四性齐：刚 3 / 中 5 / 阴 2 / 邪 3）。

**走火入魔（现行口径，册233 落码）**：判据看**修习槽**——槽里同挂环上相邻互克的两性即相冲；**中正豁免**（基准性，与谁都冲不起来）⇒ 实际相冲对只有「刚猛 ↔ 阴柔」「刚猛 ↔ 邪异」两对。每「行功日」（10 现实分钟练功尺度，与历法日解耦）内伤 +1，**封 12 不致死**（到 12 进咯血档逼撤槽或疗伤），`world.fireDays` 记连续走火日、≥3 日界面加重提示、撤槽清零。**余量**：`nat` 逐条人工赋性（现走门派与地界规则推导）· 悬赏泛化对手不赋性（×1.00）。

## 三、入门池（10）与秘籍（18）

### 3.1 入门池（10）——为什么必须有

按热度选品阶会**挤空低阶**：36 部取 ≥19 次 ⇒ 黄阶只剩 2 部，`Lv0~2` 无武功可学。补入门池 10 部（黄阶为主，频次可低）：

`八极拳`(20) · `龙爪手`(27) · `武当长拳`(15) · `五行拳`(12) · `查拳`(11) · `太祖长拳`(10) · `少林长拳`(7) · `十段锦`(8) · `分筋错骨手`(20) · `草上飞`(4)

> **教训（写进正典）**：**选品不能只用单一指标**。频次决定「认知快感」，但不决定「梯度是否连续」——低阶缺货会让开局两小时无武功可学，比学到冷门武功更伤。

### 3.2 秘籍（18）——物品层，与招式分开

词表里的 384 条「武功」是**招式**（技能）；书名号《》抽取能干净切出第二层 = **秘籍**（物品）：`九阴真经`(185) · `四十二章经`(98，藏宝线索) · `辟邪剑谱`(96) · `葵花宝典`(51) · `紫霞秘笈`(26) · `药王神篇`(26) · `金蛇秘笈`(21) · `连城剑谱`(15) · `广陵散` / `清心普善咒` / `碧海潮生曲`（琴谱）等。

**两步链 = 奇遇得秘籍（入 `shelf`）→ 修习成招式（入 `artsKnown`）**，前者是物品、后者是技能，存档分开存。✅ 已入码（册156 `MANUALS` 18 条；市集秘籍稀有格三件 + 世界事件主奖励秘籍 4 部都挂 `art` 指向真招式）。

## 四、分层口径与入选依据（改名单前必读）

> **🔧 v1.2 改口（册155）**：「首发 36 部一律取自 ≥19 次区间」的旧口径已作废。全量入库后，**所有条目都在表里**，只是**层次不同**：频次与原著地位共同决定品阶，品阶决定谁学得到、在哪遇见。

语料实测：382 条有效招式里**只有 8 条过百次、106 条过 10 次**，是极端长尾分布。据此分四层：

| 层 | 取法 | 用在哪 | 现值（实数） |
|---|---|---|---|
| **天阶（招牌）** | 频次 ≥100 或原著镇派绝学（人工提级/补入） | 掌门与主角终局、秘籍奇遇上限 | **20** |
| **地阶（名门）** | 频次 30~99 | 门派长老与主要对手、师门授艺中段 | **42** |
| **玄阶（常见）** | 频次 10~29 | 门人弟子、镖师马贼、市井传说 | **65** |
| **黄阶（基础）** | 频次 <10 或入门池 | 开局、杂役、路人 | **276** |

**三条改不动的规矩**：

1. **品阶由「频次 + 原著地位」共同定，人工口必须留**——`斗转星移`(22) 与 `黯然销魂掌`(19) 频次低却是镇派绝学，人工提天；`铁掌`(113) 频次高但只是铁掌帮一路，压到地阶。
2. **人工补入必须先证明「原著有」再补**——两批共补 24 条，每条都写明理由：**词表漏项导致零命中，不是原著没有**。
3. **入门池不许被频次规则吃掉**（见 §3.1）：低阶连续性是硬需求。

**曾被推翻的四处凭印象**（留档防再犯）：`五郎八卦棍` / `燕子三抄水` / `金蛇剑法` / `玉女素心剑法` 实测 <25 ⇒ 降黄阶；`点苍` 仅 7 次 ⇒ 出门派首发（转扩展池）；`五毒教` 零命中 ⇒ 删；`八步赶蝉` 是词表错字（实为 `八步赶蟾`）。

## 五、三途来源与瓶颈

| 途 | 机制 | 对应第一世界 |
|---|---|---|
| **拜师** | 入门派 → 按辈分与贡献解锁师门武学（册217 落码：品阶锁贡献 黄 0 / 玄 100 / 地 300 / 天 600） | 宗门 |
| **奇遇** | 秘籍 / 洞窟 / 高人传功 / 偷学 | 奇遇事件池 |
| **自悟** | 某部武学满层 + 特定见闻 → 悟出新招 | 自创功法（三代封顶 / 并存 ≤4） |

> **高人传功已落码（册242）**：闯荡平安步 1% 遇前辈授业，只传**长尾武学**（未学 / 无门派 / 非秘籍非事件主奖励），按品阶加权（黄 60 / 玄 30 / 地 8 / 天 2）、按境界开门（黄 0 / 玄 2 / 地 4 / 天 6）。它补的是「门派学不到、秘籍里没有」那约三百部——不是替代拜师与秘籍两条主途。**世界事件主奖励**（天阶武学 / 名兵 / 秘籍三型，36 案逐案声明）是第四条获得口，见 [`世界事件.md`](./世界事件.md) §七。

**瓶颈**：每部武功在关键层（**3 / 6 / 9**）需**心境门槛**（见闻值 / 特定地界到访 / 特定关系），不满则卡层。这条逼玩家出关走动——纯闭关在武侠里不该通。

**禁功**：可学，但入档即挂「邪异」，且正道门派会逐出。把「走捷径」做成一条**有代价的真实路径**，而不是简单禁止。（原书形态的「修习违和 +1/层」计数随书形态退役；辟邪剑法的「折寿」自伤通道保留，见 §2.0 注。）

## 七、数据层结构

```
character = { id, name, alias[], books[], freq, sect?, gender?, align? }
sect      = { id, name, alias[], camp:'zheng|zhong|xie|yin', freq, books[] }
art       = { id, name, kind:'neigong|quan|blade|qing|qimen', tier, nature, freq, forbidden?, origin? }
place     = { id, name, region, freq, books[] }
relation  = { a, b, cooccur }          // 叙事取人的权重，不是「关系设定」
```

**别名是资产不是噪声**：`乔峰`(1132) 与 `萧峰`(1786) 同人、`小桂子`(355) 与 `韦小宝`(9913) 同人、`老顽童`(316) 与 `周伯通`(1212) 同人。武侠里称谓随关系亲疏变化，**正文可以按亲密度换称法**——所以存 `alias[]` 而不是删别名。

**语料给不了的**（不得由数据推断）：人物性别、正邪归属、门派归属、武功归类。必须人工标注；「共现最高的门派」可作初猜，但**必须标待核、不得直接进正典**。
