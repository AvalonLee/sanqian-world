## 一、五类与挂机产出

| 类 | 定位 | 挂机产出 |
|---|---|---|
| **内功** `neigong` | 根基，决定功力上限与恢复 | 功力速率 / 上限 |
| **拳掌** `quan` | 徒手路数 | 战力 |
| **兵刃** `blade` | 器械路数（刀枪剑鞭…） | 战力 / 暴击 |
| **轻功** `qing` | 移动与逃脱 | 遇袭逃生率 / 地界通行 |
| **奇门** `qimen` | 毒 / 暗器 / 音功 | 特殊效果 / 事件成功率 |

**品阶四档**：黄 → 玄 → 地 → 天（跨世界通用规范，与第一世界 `arts` 同构）。

**内力四性**：刚猛 → 阴柔 → 中正 → 邪异 → 刚猛（环克）。相克方战力 **×1.15**、被克 **×0.87**、同性 ×1.00。

> **入码（册232）**：乘区已进 `battleOdds`（对战判定层，**不进 `powerOf`**——相性依赖「对谁」，而 `powerOf(ws)` 没有对手参数；判定本就用比值，等价于战力式那一项）。三处「性」的来源（本卷未逐条规定，按可叙事口径推导）：**主角 = 主修内功之性**（`artsLevels` 里 `neigong` 类层数最高那部的 `nat`；无内功 ⇒ 中正）；**世界事件 boss = 门派之性**（CAST 的 `sec` 映射，26 门全覆盖：少林/嵩山/铁掌/崆峒/丐帮 刚猛 · 武当/全真/华山等 中正 · 桃花岛/古墓/逍遥/灵鹫 阴柔 · 日月/星宿/血刀/天鹰/神龙/长乐/明教/侠客岛 邪异）；**闯荡杂鱼 = 地界之性**（13 地映射，四性齐：刚 3 / 中 5 / 阴 2 / 邪 3）——遇敌看「你走到谁的场子」，主查看「他是谁的人」。**余量**：`nat` 逐条人工赋性（现走门派与地界的规则推导）· 「同修相冲两性 → 内伤 +1/日」这条走火入魔通道未落码 · 悬赏目标为泛化对手、暂不赋性（相性 ×1.00）。

> 这条给「学什么武功」而不是「学最高级的武功」提供了理由，也让走火入魔有机制出口：**同时修习相冲两性 → 内伤 +1/日**（超过 3 日进濒死预警）。这是唯一一个「不打架也会受伤」的通道。

> **入码（册233）**：走火入魔落码——判据看**修习槽**（正在练的那几部），已学但不练不算：槽里同挂**环上相邻、互克**的两性即相冲。**中正豁免**：它是「不偏不倚」的基准性，能调和刚猛与阴柔，与谁都冲不起来 ⇒ 实际相冲对只有「刚猛 ↔ 阴柔」「刚猛 ↔ 邪异」两对（邪异与阴柔隔一位、不相克，也不冲）。这条同时保证「标准玩家」练中正入门内功 + 一路专精不会莫名走火（册233 sim R4 实证：不豁免就一路卡在咯血档破不了关）。
> **日尺度**：用「行功日」= 10 现实分钟，**不是 worldDay**——后者目前不推进（缺陷已登记，见 §一 末注），且其尺度一动就牵动整个 sim 时间模型。对照既有恢复（内伤 1 层/30 现实分钟）：走火 +1/10 分 ≫ 恢复 −1/30 分 ⇒ 净每小时约 +4 层，约 3 小时走到封顶。**封 12 不致死**：正典「超过 3 日进濒死预警」是压力不是死刑——内伤 15 即死留给战斗与极端运气，别让挂机把人练死；到 12 进咯血档（行走被拒）逼玩家撤槽或疗伤。`world.fireDays` 记连续走火日、撤槽清零，≥3 日界面加重提示。
> ⚠️ **另发现（未修）**：`worldDay` 日常**从不推进**（只在退隐 +3600）⇒ 窗口型世界事件、惯例型届次、滑窗回声、传闻预告、寿元五族机制在真实游玩中全是死的。修它要连带重标定 `.tests/sim-wuxia.cjs` 的「一月 = 43200 挂机分钟」口径、并复核 echo 见闻值（世界日一推进，17 案 echo × 2 = +34 见闻会顶穿心境墙）⇒ 独立成批。

## 三、入门池（10）与秘籍（18）

### 3.1 入门池（10）——为什么必须有

按热度选品阶会**挤空低阶**：36 部取 ≥19 次 ⇒ 黄阶只剩 2 部，`Lv0~2` 无武功可学。补入门池 10 部（黄阶为主，频次可低）：

`八极拳`(20) · `龙爪手`(27) · `武当长拳`(15) · `五行拳`(12) · `查拳`(11) · `太祖长拳`(10) · `少林长拳`(7) · `十段锦`(8) · `分筋错骨手`(20) · `草上飞`(4)

> **教训（写进正典）**：**选品不能只用单一指标**。频次决定「认知快感」，但不决定「梯度是否连续」——低阶缺货会让开局两小时无武功可学，比学到冷门武功更伤。

### 3.2 秘籍（18）——物品层，与招式分开

词表里的 384 条「武功」是**招式**（技能）；书名号《》抽取能干净切出第二层 = **秘籍**（物品）：

`九阴真经`(185) · `四十二章经`(98，藏宝线索) · `辟邪剑谱`(96) · `葵花宝典`(51) · `紫霞秘笈`(26) · `药王神篇`(26) · `金蛇秘笈`(21) · `连城剑谱`(15) · `广陵散` / `清心普善咒` / `碧海潮生曲`（琴谱）

> **这一层是原框架缺的**：只设计了 `artsKnown` 一个承接面，没法表达「先得到书、再修成招」。两步链 = **奇遇得秘籍（入 `shelf`）→ 修习成招式（入 `artsKnown`）**，前者是物品、后者是技能，存档分开存（`shelf` / `artsKnown`）。

## 四、分层口径与入选依据（改名单前必读）

> **🔧 v1.2 改口（册155）**：本节原写「首发 36 部一律取自 ≥19 次区间、长尾 278 条只作随机秘籍」——**该口径已作废**。全量入库后，**所有条目都在表里**，只是**层次不同**：频次与原著地位共同决定品阶，品阶决定谁学得到、在哪遇见。

语料实测：382 条有效招式里**只有 8 条过百次、106 条过 10 次**，是极端长尾分布。据此分三层：

| 层 | 取法 | 用在哪 | 现值 |
|---|---|---|---|
| **天阶（招牌）** | 频次 ≥100 或原著镇派绝学（人工提级/补入） | 掌门与主角终局、秘籍奇遇上限 | **17** |
| **地阶（名门）** | 频次 30~99 | 门派长老与主要对手、师门授艺中段 | **38** |
| **玄阶（常见）** | 频次 10~29 | 门人弟子、镖师马贼、市井传说 | **65** |
| **黄阶（基础）** | 频次 <10 或入门池 | 开局、杂役、路人 | **276** |

**三条改不动的规矩**：

1. **品阶由「频次 + 原著地位」共同定，人工口必须留**——`斗转星移`(22) 与 `黯然销魂掌`(19) 频次低却是镇派绝学，人工提天；`铁掌`(113) 频次高但只是铁掌帮一路，压到地阶。
2. **人工补入必须先证明「原著有」再补**——本批补 17 条（洗髓经 / 天罡北斗阵 / 太玄经 / 凝血神抓 / 鹰爪擒拿手 …），每条都写明理由：**词表漏项导致零命中，不是原著没有**。
3. **入门池不许被频次规则吃掉**（见 §3.1）：低阶连续性是硬需求。

**曾被推翻的四处凭印象**（留档防再犯）：`五郎八卦棍` / `燕子三抄水` / `金蛇剑法` / `玉女素心剑法` 实测 <25 ⇒ 降黄阶；`点苍` 仅 7 次 ⇒ 出门派首发（转扩展池）；`五毒教` 零命中 ⇒ 删；`八步赶蝉` 是词表错字（实为 `八步赶蟾`）。

| **自悟** | 某部武学满层 + 特定见闻 → 悟出新招 | 自创功法（三代封顶 / 并存 ≤4） |

**瓶颈**：每部武功在关键层（**3 / 6 / 9**）需**心境门槛**（见闻值 / 特定地界到访 / 特定关系），不满则卡层。这条逼玩家出关走动——纯闭关在武侠里不该通。

**禁功**：可学，但入档即挂「邪异」，修习时**违和 +1/层**（与干预代价同一条量，见 [`干预与代价.md`](./干预与代价.md) §三），且正道门派会逐出。把「走捷径」做成一条**有代价的真实路径**，而不是简单禁止。

## 七、数据层结构

```
character = { id, name, alias[], books[], freq, sect?, gender?, align? }
sect      = { id, name, alias[], camp:'zheng|zhong|xie|yin', freq, books[] }
art       = { id, name, kind:'neigong|quan|blade|qing|qimen', tier, nature, freq, forbidden?, origin? }
place     = { id, name, region, freq, books[] }
relation  = { a, b, cooccur }          // 叙事取人的权重，不是「关系设定」
```

**别名是资产不是噪声**：`乔峰`(1132) 与 `萧峰`(1786) 同人、`小桂子`(355) 与 `韦小宝`(9913) 同人、`老顽童`(316) 与 `周伯通`(1212) 同人。武侠里称谓随关系亲疏变化，**正文可以按亲密度换称法**（陌生时「那老者」，相识后「周伯通」，熟稔后「老顽童」）——这反过来是叙事层的一个表现手段，所以存 `alias[]` 而不是删别名。

**语料给不了的**（不得由数据推断）：人物性别、正邪归属、门派归属、武功归类。必须人工标注；「共现最高的门派」可作初猜，但**必须标待核、不得直接进正典**。
