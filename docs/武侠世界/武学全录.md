## 一、五类与挂机产出

| 类 | 定位 | 挂机产出 |
|---|---|---|
| **内功** `neigong` | 根基，决定功力上限与恢复 | 功力速率 / 上限 |
| **拳掌** `quan` | 徒手路数 | 战力 |
| **兵刃** `blade` | 器械路数（刀枪剑鞭…） | 战力 / 暴击 |
| **轻功** `qing` | 移动与逃脱 | 遇袭逃生率 / 地界通行 |
| **奇门** `qimen` | 毒 / 暗器 / 音功 | 特殊效果 / 事件成功率 |

**品阶四档**：黄 → 玄 → 地 → 天（跨世界通用规范，与第一世界 `arts` 同构）。

**内力四性**：刚猛 → 阴柔 → 中正 → 邪异 → 刚猛（环克）。相克方战力 **×1.15**、被克 **×0.87**、同性 ×1.00。

> 这条给「学什么武功」而不是「学最高级的武功」提供了理由，也让走火入魔有机制出口：**同时修习相冲两性 → 内伤 +1/日**（超过 3 日进濒死预警）。这是唯一一个「不打架也会受伤」的通道。

## 三、入门池（10）与秘籍（18）

### 3.1 入门池（10）——为什么必须有

按热度选品阶会**挤空低阶**：36 部取 ≥19 次 ⇒ 黄阶只剩 2 部，`Lv0~2` 无武功可学。补入门池 10 部（黄阶为主，频次可低）：

`八极拳`(20) · `龙爪手`(27) · `武当长拳`(15) · `五行拳`(12) · `查拳`(11) · `太祖长拳`(10) · `少林长拳`(7) · `十段锦`(8) · `分筋错骨手`(20) · `草上飞`(4)

> **教训（写进正典）**：**选品不能只用单一指标**。频次决定「认知快感」，但不决定「梯度是否连续」——低阶缺货会让开局两小时无武功可学，比学到冷门武功更伤。

### 3.2 秘籍（18）——物品层，与招式分开

词表里的 384 条「武功」是**招式**（技能）；书名号《》抽取能干净切出第二层 = **秘籍**（物品）：

`九阴真经`(185) · `四十二章经`(98，藏宝线索) · `辟邪剑谱`(96) · `葵花宝典`(51) · `紫霞秘笈`(26) · `药王神篇`(26) · `金蛇秘笈`(21) · `连城剑谱`(15) · `广陵散` / `清心普善咒` / `碧海潮生曲`（琴谱）

> **这一层是原框架缺的**：只设计了 `artsKnown` 一个承接面，没法表达「先得到书、再修成招」。两步链 = **奇遇得秘籍（入 `shelf`）→ 修习成招式（入 `artsKnown`）**，前者是物品、后者是技能，存档分开存（`shelf` / `artsKnown`）。

## 四、入选口径与分布依据（改名单前必读）

语料实测：384 条武功里**只有 8 条过百次、106 条过 10 次**。分布是极端长尾。

- **首发 36 部一律取自 ≥19 次区间**——理由：玩家学到的若是没人听过的武功，武侠的认知快感反而下降。
- **长尾 278 条只作「秘籍奇遇」随机掉落**，不进首发正典、不做图鉴硬指标。
- **入门池例外**（见 §3.1）：低阶连续性是硬需求，可以低于 19。
- **入选门槛不随心情改**：改名单必须重跑语料统计，改完同批更新本卷与 `arts.js`。

**曾被推翻的四处凭印象**（留档防再犯）：`五郎八卦棍` / `燕子三抄水` / `金蛇剑法` / `玉女素心剑法` 实测 <25 ⇒ 移入长尾；`点苍` 仅 7 次 ⇒ 出门派表；`五毒教` 零命中 ⇒ 删；`八步赶蝉` 是词表错字（实为 `八步赶蟾`）。

## 五、三途来源与瓶颈

| 途 | 机制 | 对应第一世界 |
|---|---|---|
| **拜师** | 入门派 → 按辈分与贡献解锁师门武学 | 宗门 |
| **奇遇** | 秘籍 / 洞窟 / 高人传功 / 偷学 | 奇遇事件池 |
| **自悟** | 某部武学满层 + 特定见闻 → 悟出新招 | 自创功法（三代封顶 / 并存 ≤4） |

**瓶颈**：每部武功在关键层（**3 / 6 / 9**）需**心境门槛**（见闻值 / 特定地界到访 / 特定关系），不满则卡层。这条逼玩家出关走动——纯闭关在武侠里不该通。

**禁功**：可学，但入档即挂「邪异」，修习时**违和 +1/层**（与干预代价同一条量，见 [`干预与代价.md`](./干预与代价.md) §三），且正道门派会逐出。把「走捷径」做成一条**有代价的真实路径**，而不是简单禁止。

## 七、数据层结构

```
character = { id, name, alias[], books[], freq, sect?, gender?, align? }
sect      = { id, name, alias[], camp:'zheng|zhong|xie|yin', freq, books[] }
art       = { id, name, kind:'neigong|quan|blade|qing|qimen', tier, nature, freq, forbidden?, origin? }
place     = { id, name, region, freq, books[] }
relation  = { a, b, cooccur }          // 叙事取人的权重，不是「关系设定」
```

**别名是资产不是噪声**：`乔峰`(1132) 与 `萧峰`(1786) 同人、`小桂子`(355) 与 `韦小宝`(9913) 同人、`老顽童`(316) 与 `周伯通`(1212) 同人。武侠里称谓随关系亲疏变化，**正文可以按亲密度换称法**（陌生时「那老者」，相识后「周伯通」，熟稔后「老顽童」）——这反过来是叙事层的一个表现手段，所以存 `alias[]` 而不是删别名。

**语料给不了的**（不得由数据推断）：人物性别、正邪归属、门派归属、武功归类。必须人工标注；「共现最高的门派」可作初猜，但**必须标待核、不得直接进正典**。
