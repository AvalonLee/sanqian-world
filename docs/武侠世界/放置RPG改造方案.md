## 三、核心循环（钉版）

```
挂机「闯荡江湖」（地界推进 · G2/G3 换皮）
   ├─ 产出：功力（累计值）· 银两 · 偶发奇遇（EVENTS）
   ├─ 消耗口 A：修习槽练武（练习度制 · 被动时长 → 武学层数）
   ├─ 消耗口 B：主动动作（精力闸）：闯荡推进 / 拜师学艺 / 研读秘籍 / 师门任务 / 结交拜访 / 疗伤
   ├─ 大节点：世界事件（WORLD_EVENTS · 天下大事，[`世界事件.md`](./世界事件.md)）——预告赴会、参与档、改写江湖格局
   └─ 节点：境界破关（功力阈值 + 心境门槛双条件）→ 解锁地界 / 门派武学上限 / 事件池档位
              ↓
        更远的地界 → 更多的人物 → 更高品阶的武学与秘籍 → 循环放大
```

四条循环铁律（对位数值卷 §一 三原则的 RPG 化改写）：

1. **量在挂机，质在节点**。功力大头来自挂机（复利线），但每次破关的最后一段、每部高阶武学、每张秘籍，都卡在「事件 / **世界事件** / 师承 / 秘籍」四个主动口上——纯挂机能到绝顶，到不了宗师（心境门槛硬卡，数值卷 §四 原设计平移）；宗师线的主动力就是世界事件（见闻主产地）。
2. **封顶不清零**（原口径不动）：心境不足时功力封顶在下一档阈值，时间投入永远不亏。
3. **精力防秒满**（调研自《放置江湖》）：修习槽是被动时长，主动动作一律过精力闸——玩家在线的决策密度由精力决定，不由点击频率决定。
4. **经济是难度调节器**（原口径扩展）：钱不够从「改道」扩展为「改道 + 买不了」，消费场所恢复（§八 减法清单勘正）。

**资源定案**（v1.0 拍板，P2 数值批细化）：

| 功力 `qi` | 修为 | 挂机（练功 basal + 闯荡） | 不消耗（累计值） | 境界阈值 / 封顶 / `powerOf` 全按现行 |

## 五、新专属系统六件

### 之一 · 师承系统（本改造的最大新增）

MUD 师承链的正典化，落位 = 江湖设定卷 §四「门派四件事」表 + 数值卷 §九 `sect` 字段（`{id, rank, contribution, joinedAt, betrayed}` 已在 initialState）：

| 环节 | 机制 | 数值入口 |
|---|---|---|
| 拜师 | 侠名门槛 + 试炼（门派向 KNOTS/EVENTS）+ 引荐人降档（`relations.kind='master'` 或门中人 ≥20 好感） | `renown` |
| 学艺 learn | 门派可学武学 = ARTS `s` 字段反查（98 部已在码）；按**辈分**解锁——辈分 = `contribution + rank` 派生（不进存档，江湖设定 §四 原口径）；学一部耗 精力 + 贡献 | `sect.contribution` |
| 自修炼 | 非门派武学走修习槽练习度（册162 闭环），3/6/9 层心境卡层照旧 | `artsPractice` |
| 师门任务 | 门派向事件（EVENTS 门派线 + G17 传闻委托）供贡献 | `sect.contribution` |
| 叛门 | 侠名重罚 + **追杀事件链**（持续状态，非一次性惩罚——原口径平移）；叛门后可拜他派 | `sect.betrayed` |

**师父池** = CAST 中 `role` 为掌门/长老级 + `sec` 对应门派的人（数据现成，P4 批补师父资格标记与授艺课程表）。

### 之二 · 精力闸（防秒满）

新字段 `stamina`：上限随境界（初值与斜率 P2 批定），现实分钟恢复。主动动作价目表（闯荡推进 / 拜访 / 研读 / 学艺 / 师门任务 / 疗伤）P2 批与产出基准同表定值。设计红线：**精力只闸主动动作，不闸修习槽**——放置的本体（挂机练武）不许被闸死，闸的是在线决策频率。

### 之三 · 闯荡推图（G3 换皮）

ZONES 13 地界按境界解锁（对位秘境区域层级）；每地界 2~4 子场景 = 进度节点（`scenes[]` 已在码）；遇敌 = EVENTS `kind:'action'` + CAST 对手池（tier 四档 = 打不打得过锚，人物与地方卷原口径）；战力公式 / 胜负掷判 / 败走窄路表（数值卷 §六）全部平移，战斗表现为**战报一段文字 + 结果卡**（不做动画，减法清单口径不变）。首通奖励对齐第一世界 `zones` 口径（江湖设定 §三 原注）。

### 之四 · 秘籍收集线

MANUALS 18 部三途获取：市集稀有格（G6）/ 奇遇掉落（EVENTS `kind:'gain'`）/ 门派贡献兑换（师承系统）。得秘籍 → 入 `shelf` 待修习架（字段已在）→ 研读（耗精力）→ 学得所指 `art` 武学 → 进修习槽。秘籍与门派武学两线并行：秘籍是「江湖奇缘」，门派是「师承正统」，玩家两条都要走。

### 之五 · 结交知己（G14 轻量版）

CAST 107 人 = 结交池（`relations` 字段与 affinity/kind 四态已在码）；好感渠道对位第一世界三渠道改武侠语义：**结伴闯荡**（同地界事件自动 +）/ **赠礼**（酒/兵刃/秘籍抄本）/ **同贺**（扬名事件自动 +）。仇家线（`kind:'enemy'`）由败战与夺宝事件自动结成。不做护法位/道侣位（减法清单），人际深度走事件不走红点——「三十年前你师父救过我一命」的人情债 `debts` 跨代继承原口径保留。

### 之六 · 世界事件（册213 增补 · 天下大事层）

把金庸十五部的重要关键剧情（华山论剑 / 襄阳大战 / 光明顶之战 / 聚贤庄 / 雁门关……）改造成**世界事件**：预告（G17 传闻）→ 主动赴会 → 参与四档（避免/旁观/卷入/主导）→ 走向分支（canon 自然走向 / alt 改史，仅主导档）→ **写回江湖格局**（人物生死、门派声望、事件链解锁）。惯例型（论剑 6 年一届）与独发型两类窗口，错过出「江湖传言收场」回声。schema、首批 20 + 二批 16 名录、重点八案细设全在展开卷。**设计地位**：宗师线的主动力（心境门槛的见闻主产地）+ 「这一世江湖」与「别人的江湖」的差异所在。

## 十一、验收口径

- **节奏**：P2 起以 sim-wuxia（改造版）定种——「标准玩家」日程直设口径照旧（仿真验内核账，不当玩家体验读数）；境界行逐卷对表改**逐月对表**（无卷结构后以游戏年为单位验证曲线）。**定种两段口径（册213 校对补）**：P2 定种跑（事件层未入）预期「纯挂机卡绝顶心境墙」= 设计自洽的验收点，**不是缺陷**；P5 世界事件入码后 sim 换种（标准玩家参与 6~10 桩/主导 2~4 桩），宗师线可达方为绿。
- **体验红线**（平移数值卷 §十 的 RPG 化改写）：纯挂机能到绝顶到不了宗师（心境墙在）；满配越一档胜率保持 39~45% 带；精力闸后在线决策密度与离线收益都要为正（离线不亏、在线有得决策）。**世界事件线（册213 补）**：纯挂机（零事件）到不了宗师；标准玩家参与/主导世界事件后宗师线可达；每桩主导（lead）支门槛落在带内（不出现零门槛 lead）；独发型错过 = canon 写回 + 回声传闻、惯例型下届重开；改史后事件链与 `wefate` 读数一致。
- **门禁**：全链照走（`npm test` + `test:ui`，改数值批补 `test:sim`）；判据随批改口纪律照旧（判据随现实改，历史记录不改写）。
- **存档红线**：主档容量 65,536B 红线不变；摘键批照 normalize 反证口径（旧档带死键读入即剪、二次 normalize 不复活）。
