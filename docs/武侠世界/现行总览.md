## 二、现行形态与玩家旅程

**形态**：山河棋盘。主壳 = `qunxiaHome`（`assets/worlds/wuxia/index.js`），进入即同文档导航挂游戏页 `view/games/qunxia/game.html`（册250 起，无 iframe）；棋盘与扩展世界的结果回流走本地队列 + `pack.applyResult` 单写（册259）。

**一局旅程**（36 旬）：

1. **创角**：立名、选门派/出身 → 进入棋盘（第一世界「入定」同款入口）。
2. **每旬**：走一格（行脚）——闯荡遇敌 / 赴会天下大事 / 修炼与市集 / 回门派。
3. **天下大事**：36 桩世界事件按旬排期，顶栏只显示最急 3 桩（册258），其余在传闻页；参与四档 = 旁观 watch / 卷入 join / 主导 lead（对赌，败则结仇与内伤）。
4. **结局**：第 36 旬传世终章 → 轮回（余响三轴带入世）。

**系统地图**（谁管什么）：

| 层 | 组件 | 职责 |
|---|---|---|
| 主壳 | `index.js` `qunxiaHome` | 装载世界包、拼内容桥 payload、事件结果单写回 |
| 游戏 | `view/games/qunxia/`（game.html + content-merge.js） | 棋盘玩法、36 案日程、战斗、存档（localStorage） |
| 世界包 | `assets/worlds/wuxia/data.js` + `lexicon-*.js` | ZONES/CAST/ARTS/SECTS/WEAPONS/MANUALS/KNOTS/EVENTS/WORLD_EVENTS 数据与词表 |
| 世界层 | `assets/worlds/wuxia/` 引擎件 | worldEvents 四档参与、窗口与回声、写回、轮回余响 |

## 七、术语表

| 术语 | 含义 |
|---|---|
| 旬 | 棋盘的一步；一局共 36 旬，是玩家唯一时间轴（§一 #3）。 |
| 世界事件（WE） | 天下都在谈论的大事（36 案，`we_*`），按旬排期；每案有 canon/alt 两走向与写回。 |
| 参与四档 | 旁观 `watch`（无门槛兜底）/ 卷入 `join`（站队，轻败不改史）/ 主导 `lead`（对赌 boss，败走窄路、结仇）。 |
| canon / alt | 守史（无主角干预的自然走向）/ 改史（主角付代价换的另一种结局）。结局键存 `wefate`：canon / alt / lose / echo（错过回声）。 |
| KNOTS | 地方桥段 = 「当场那段戏」的执行器；世界事件管去不去/结局，KNOTS 管戏怎么演（`WE.knot` 挂接）。 |
| 写回 | 棋盘终局经 `applyResult` 单写扩展世界：`wefate`、门派声望、人物去向（dead/flee/secluded/saved）、结仇。 |
| `worldDay` | 扩展侧现实时钟（1 现实分钟 = 1 游戏日）；单轨拍板后**只管离线挂机计时**，不再决定事件窗口。 |
| 山河棋盘 | 现行主形态：全屏挂 `game.html` 的棋盘玩法（行脚 / 旬 / 大事列表 / 邸报传闻）。 |
| 侠名 | 棋盘成长主轴之一，幕门（三幕进出门槛）用侠名分段。 |
| 血衣楼 | 一局的**暗线**：序章埋线、每幕余波传闻、第 35 旬华山终局揭底。 |
| 余响 / 轮回 | 终章传世：余波三轴（境界/最高武学/最深交情 ≤3）经 `rebirthCarry` 带入下一世；`wefate/wecyc/wseen` 重置。 |
