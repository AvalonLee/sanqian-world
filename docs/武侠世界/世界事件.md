> **一句话定位**：EVENTS 是你在江湖上**遇上**的事，KNOTS 是你在某地**撞见**的戏，世界事件是**天下都在谈论**的大事——华山论剑、襄阳大战、光明顶之战。你听说了它，决定去不去；去了，决定站在哪；站在哪，江湖就因为你改写一分。
>
> **为什么要有这一层**（改造方案 §三 铁律 1「量在挂机，质在节点」的顶点）：数值卷 §四 心境门槛表里，宗师以上要「与两个门派有往来」「一段刻骨关系」「天阶绝学满层」——这些都是**人间的分量**，纯挂机与普通奇遇喂不出来。世界事件是宗师线的主动力，也是「这一世江湖」与「别人的江湖」不同的地方。

## 一、三层事件结构（与现有数据的关系）

| 层 | 表（在码） | 规模 | 粒度 | 玩家关系 |
|---|---|---|---|---|
| 奇遇 | `EVENTS` | 96 | 一件事（得书/遇袭/听闻/交易） | 随机撞上，单场结算 |
| 地方桥段 | `KNOTS` | 24 | 一地的一段戏（手写名场面，cast + 分支） | 闯荡到该地撞上；**世界事件的场面执行器** |
| **世界事件** | `WORLD_EVENTS` 🆕 | 现役 20（二批 16 预留） | 一桩天下大事（预告期 → 赴会 → 结局写回江湖格局） | **主动赴会**：听传闻 → 选中 → 参与档 → 走向 → 写回 |

**同源挂接**（不重写、不撞车）：KNOTS 已把藏经阁 / 聚贤庄 / 围攻光明顶 / 雁门关 / 封禅台 / 少室山等场面写成地方桥段——世界事件**复用它们做场面执行器**（`WE.knot` 指向 KNOTS id）：世界事件管「要不要去、站在哪、结局如何、江湖如何改写」，KNOTS 管「当场那段戏怎么演」。KNOTS 未覆盖的场面（华山之巅 / 黑木崖 / 侠客岛），P5 批补 KNOTS 场面条目（`knot:null` 者随批补齐，第一批先补赴会入口，正文走模板句库）。


## 二、共时化改编原则（承接江湖设定 §二「共时大江湖」）

原著十五部有编年先后，共时江湖把它们拆成**并存的势力与惯例**，改编三则：

1. **惯例化**：周期性盛会成为江湖惯例，错过这届等下届——华山论剑每 **6 游戏年**一届、侠客岛腊八之约每年腊月、杀龟大会天地会每数年一聚。惯例型事件是放置长线的周期大节点。
2. **悬案化**：原著「某人的宿命」改写成「江湖的悬案/传言」——乔峰的身世是「正在发酵的丑闻」而非已发生的过去；谢逊夺屠龙刀是「现下的武林公案」。事件触发时事情**正在发生**。
3. **无主角自然走向 = canon**：canon（守史）分支不是「必须尊重原著」，而是**无主角干预时江湖的自然走向**（autoPick 时代的默认结果）——共时江湖没有「原著历史」的约束，改写的是**这一世**的走向。改史（alt）分支因此不需要「违背天意」的合法性辩护，只需要付得起代价。

**改编红线**：不写具体年号与朝代更替（江湖设定 §二 原口径）；事件名与场面名保留原著认知（「华山论剑」不改叫「五岳之巅」——华山之巅作为**不可游历的会址**出现，见 §四 z:null 口径）。

## 三、参与四档与门槛

| 档 | 含义 | 门槛（`req`，复用数值卷 §八 门槛族） | 回报 | 风险 |
|---|---|---|---|---|
| **避免** `avoid` | 不去 | 无 | 无 | 无（错过的后果见 §五 回声） |
| **旁观** `watch` | 在场不落子 | 见闻 exp 低带 | 见闻 +8~15、余波关系小 + | 极低（池鱼之殃事件率） |
| **卷入** `join` | 成为事件的一部分（站队/护送/传信/助拳） | 境界带 + 门派/关系条件 | 见闻 +20~30、侠名 ±10~20、事件级掉落 | 战败走窄路（轻） |
| **主导** `lead` | 改变走向的人 | 境界 + 战力 + 指定武学/关系/性格轴（逐事件定） | 见闻 +40~60、侠名 ±30~60、**天阶武学/名兵/秘籍主奖励池**、心境大额 | **lead 即对赌**：失败走败走窄路表（内伤 2~6、侠名 −20~40、关键关系恶化） |

**档位由 `tiers[]` 逐事件声明**——门槛写在明处（面板直陈「非绝顶高手不可主导」），玩家不读数字也能从传闻措辞掂量自己（数值卷 §八 第 3 条「门槛必须可推断」原口径）。lead 档失败不是惩罚演出：**它本身就是事件的一种结局**（「那位无名少年力战而竭，被擒/重伤遁走」），江湖记得败者。

> **入码（册228 / 册231）**：`lead` 档「即对赌」落码——对上 `boss`（CAST id，`tier` 按数值卷 §六 折算战力）三回合取两胜（与闯荡战同口径，降方差不改期望；判点走 `Math.random`，玩家主动操作不入章号散列面）。**败 = 走窄路**：内伤 +2~6、侠名 −20~40、**不发放 `gain` 与主奖励**，结局写 `wefate='lose'`（第四结果键，与 canon/alt/echo 并列，正文 `we.<id>.fate.lose`、括注「力战而竭」）。`watch` 不掷判（旁观无对手）；**`join` 册231 起也掷**——同一套 `boss` 但战力 **0.7 折**（护拳/站队不是单挑），败则内伤 1~3、侠名 −5~−10、**见闻照发、侠名不发**，**结局仍写 `canon`**：卷入不是「改变走向的人」，没资格写 `lose`。**败局无戏**（lead 早退、join 由 `joinLose` 拦）：人被波及退到一边，台上还是那几个人在打。门槛与难度正交：门槛只管准入，难度由 boss 档定（例：门槛 5 的案配 S 档 boss = 硬闯档，胜率约四成）。**旁观一届一次**（册235）：`world.wseen[id]` 记本届已旁观，惯例型随届次重开、独发型终身一次；旁观仍不写 `wefate/wecyc`（在场不落子），只挡 `watch` 档，join/lead 不受影响。地界侧同批开口：行走页当前地若有可赴的案，挂「此地有大事：X」+「往江湖页」（选项仍在江湖页，`pack.worldEventsAt(ws, place)`）。**空间闸（册239）**：案声明了 `z` 而人不在该地时，赴会要先赶路——赴会精力另加 **3**（`TRAVEL_STAMINA`）并自动把 `place` 移到会址、记入 `visited`；地界未解锁则拒（`locked`）。行走页「前往」同价 3 精力，于是「去哪儿」第一次成为真实取舍，而不是任意地界随手参加。

## 四、触发与错过：两类窗口

> **时钟现行口径（册234）**：`worldDay` 由 `claim` 推进——**1 现实分钟 = 1 游戏日**（1 游戏年 = 6 现实小时），离线单次封顶 12 现实小时（2 游戏年）。窗口 [0,8] 年 = 开局 0~48 现实小时；惯例 cyc 6 年 = 36 现实小时；传闻「≤1 年」= 6 现实小时、「在即 ≤30 日」= 30 现实分钟。世界日不推进时本卷五族全是死机制（册233 实勘，册234 修）。

| 型 | 窗口 | 预告 | 错过 |
|---|---|---|---|
| **惯例型** | 周期重开（论剑 6 年 / 腊八之约每年 / 杀龟大会数年） | G17 传闻卡提前 **1~2 游戏月**反复预告 | 本届缺席出回声，下届窗口再来（`window.cyc`） |
| **独发型** | 一次性条件窗（前置事件 + 时间窗 `window:[y0,y1]`） | 同上，窗口内预告密度渐增 | 永久错过 = 以「江湖传言收场」的形式结局：`writeback` 按 canon 落定 + 回声传闻（见闻 **+2 封顶**——17 案全错过也只记一次「听说过江湖上的事」，零奖励）——**江湖没有等你** |

**z:null 口径（不可游历的会址）**：华山之巅 / 黑木崖 / 侠客岛 / 襄阳城下等事件主场不在十三地游历圈内（六区十三地计数不动）——这类事件 `z:null`，**入口在江湖页**（传闻卡 / 世界事件列表），语义是「持英雄帖赴会」而非「走到某地」。地界内事件（光明顶 / 聚贤庄）入口双开：江湖页选中或地界闯荡走到。

**窗口分级（册239）**：独发型窗口的收口年按事件 lead 门槛后移，避免「玩家还没到主导门槛，事已经完了」——`lead ≤ 4` → **year 6**；`lead = 5` → **year 7**（襄阳 `[0,8]` 例外，保住开局主线）；`lead 6~7` → **year 8**（雁门关 / 黑木崖这类天花板案留到后期）。王盘山 `[0,2]` 有意留作**教程窗**：开局 2 游戏年内给一桩低门槛的扬刀大会，教玩家看懂事件面板。改前 17 案多在 year 7 前收口，节奏试跑（20 游戏年、最优策略）只有少数能落到 lead；改后独特 lead 17/17、赴会 45 次（旁观 0 / 卷入 3 / 主导 42）——这是**上界**，标准玩家仍按门槛和精力自然缺席若干桩。

## 五、走向与写回（改史的分量）

- **分支**：`br[]` 至多两条——`canon`（自然走向，所有参与档默认）与 `alt`（改史，**仅 lead 档可选**，门槛显著高于 canon 支）。不搞多结局树：一桩大事，一个分歧点，一条改写路——分量在代价不在数量。
- **改史代价**：侠名大动（±30~60）、阵营关系重排、**蝴蝶效应**——`writeback.next` 解锁/关闭后续事件（救下雁门关那人，少室山一线就走另一条变体；聚贤庄的仇家名单因此改写）。事件依赖图是**轻链**（每事件至多 `pre` 2 条 / `next` 3 条），不做全图锁定。
- **写回四写口**（`writeback`）：① `cast` 人物生死/去向（CAST 人物可死可活——这是改史的意义，逐事件白名单声明，不开放全 CAST 死亡）；② `sects` 门派声望修正（光明顶之战后明教与六大门派的关系重排）；③ `rumor` 余波传闻注入 G17 池；④ `next` 事件链解锁。
- **写回进存档**：江湖格局增量落 `ws.world.wefate`（事件 id → 结果键），主档容量走「只存结果键不存叙述」纪律，逐事件 ≤ 8B。
- **入码（册236 / 册238）**：四写口**现役 20 案全覆盖**（`WRITEBACK` 表；册236 先落 §九 八案，册238 补齐其余 12 案——只动门派声望，不扩 cast 白名单）——① `cast` 短码 `dead/flee/secluded/saved`（逐案声明，不开放全 CAST）② `sects` 门派声望增量（±5~50，封 ±100）③④ `rumor`/`next` **合并为一条余波句**（`ws.world.wafter` 存 `事件:结果[:届次]` 短码，正文走 `we.<id>.wb.<canon|alt>`，展示面在江湖页「江湖格局」，不做链式触发/事件图锁定）。写口 = `applyWriteback(ws, e, outcome)`：赴会 canon/alt 与 lead 败局（canon）、错过 echo（**按 canon 落定**）三路同口；同场同届重复写入幂等（不叠声望/余波）。存档三面 `wbcast` / `wbsect` / `wafter` 进 `normalize` 白名单。

- **入码（册241）**：`writeback.next` / `close` 从展示面升级为真链式——`nextVerdict` 由**已了结事件的结局**派生（`canon/alt` 各带 `next` / `close`，`lose/echo` 按 canon 落定），`worldEvents` / `worldRumors` / `sweepExpired` / `attendEvent` 四处同判；`next` 可越过 `pre` 直接开门，`close` 优先且被关掉的案不落回声。跨世：`rebirthCarry` 把 `wbcast`（人物去向）/ `wbsect`（门派声望）/ `wafter`（余波）带进来世，`wefate/wecyc/wseen` 重置——上世改的格局看得见，事件本身重新赴。

### 之一 · 华山论剑 `we_huashan`
