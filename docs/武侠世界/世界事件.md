## 二、共时化改编原则（承接江湖设定 §二「共时大江湖」）

原著十五部有编年先后，共时江湖把它们拆成**并存的势力与惯例**，改编三则：

1. **惯例化**：周期性盛会成为江湖惯例，错过这届等下届——华山论剑每 **6 游戏年**一届、侠客岛腊八之约每年腊月、杀龟大会天地会每数年一聚。惯例型事件是放置长线的周期大节点。
2. **悬案化**：原著「某人的宿命」改写成「江湖的悬案/传言」——乔峰的身世是「正在发酵的丑闻」而非已发生的过去；谢逊夺屠龙刀是「现下的武林公案」。事件触发时事情**正在发生**。
3. **无主角自然走向 = canon**：canon（守史）分支不是「必须尊重原著」，而是**无主角干预时江湖的自然走向**——共时江湖没有「原著历史」的约束，改写的是**这一世**的走向。改史（alt）分支因此不需要「违背天意」的合法性辩护，只需要付得起代价。

**改编红线**：不写具体年号与朝代更替（江湖设定 §二 原口径）；事件名与场面名保留原著认知（「华山论剑」不改叫「五岳之巅」——华山之巅作为**不可游历的会址**出现，见 §四 z:null 口径）。

## 三、参与四档与门槛

| 档 | 含义 | 门槛（`req`，复用数值卷 §八 门槛族） | 回报 | 风险 |
|---|---|---|---|---|
| **避免** `avoid` | 不去 | 无 | 无 | 无（错过的后果见 §四 回声） |
| **旁观** `watch` | 在场不落子 | 见闻 exp 低带 | 见闻 +8~15、余波关系小 + | 极低（池鱼之殃事件率） |
| **卷入** `join` | 成为事件的一部分（站队/护送/传信/助拳） | 境界带 + 门派/关系条件 | 见闻 +20~30、侠名 ±10~20、事件级掉落 | 战败走窄路（轻） |
| **主导** `lead` | 改变走向的人 | 境界 + 战力 + 指定武学/关系/性格轴（逐事件定） | 见闻 +40~60、侠名 ±30~60、**天阶武学/名兵/秘籍主奖励池**、心境大额 | **lead 即对赌**：失败走败走窄路表（§九 逐案「失败代价」列） |

**档位由 `tier:{join,lead}` 逐事件声明**——门槛写在明处（面板直陈「非绝顶高手不可主导」），玩家不读数字也能从传闻措辞掂量自己（数值卷 §八 第 3 条「门槛必须可推断」原口径）。lead 档失败不是惩罚演出：**它本身就是事件的一种结局**（「那位无名少年力战而竭」），江湖记得败者（lead 败局另记仇，见 §五 结仇）。

> **入码口径汇总（册228~259）**：`lead` 即对赌——对上 `boss`（CAST id，`tier` 按数值卷 §六 折算战力）三回合取两胜（判点 `Math.random`，玩家操作不入章号散列面）；败 = 走窄路（内伤 +`FAIL[i].injury`、侠名 ±`FAIL[i].renown`、不发放 gain 与主奖励，结局写 `wefate='lose'`，正文 `we.<id>.fate.lose`、括注「力战而竭」）。`watch` 不掷判；**`join` 同掷**——boss 战力 **0.7 折**（护拳/站队不是单挑），败则内伤 1~3 / 侠名 −5~−10 / 见闻照发、侠名不发，**结局仍写 `canon`**（卷入不改史）+ **败局无戏**（`joinLose` 拦场面）。**旁观一届一次**（`world.wseen[id]`）。**空间闸**：案声明 `z` 而人不在该地 ⇒ 赴会另加精力 3 并自动移地、记 `visited`；地界未解锁拒（`locked`）；`z:null` 会址走江湖页持帖、不受此闸。门槛与难度正交：门槛只管准入，难度由 boss 档定。

## 四、时间轴与窗口（单轨口径）

> **🔄 单轨拍板（2026-11-07 用户裁定）**：**棋盘 36 旬是玩家唯一时间轴**——事件的何时开、何时关，全部由棋盘旬位（§八 排期表）说了算。扩展侧 `worldDay` 现实时钟（1 现实分钟 = 1 游戏日）**降级为离线挂机计时器**，不再决定事件的开/关/回声；「棋盘打赢了、后台风把案扫成 echo」的竞态从设计上根除。**代码现状（如实记）**：引擎侧窗口/届次/回声仍按 `worldDay` 判、棋盘侧按 `EV_TURNS` 旬位判，双轨仍在跑——单轨落码 = 批 266（棋盘排期对齐 + 扩展窗口降级），本节先立口径。

| 型 | 窗口（设计口径，按 §八 排期） | 预告 | 错过 |
|---|---|---|---|
| **惯例型** | 周期重开（论剑每届 6 游戏年 / 腊八之约每年 / 杀龟大会数年）——排期表给的是**首届旬位** | G17 传闻卡提前反复预告 | 本届缺席出回声，下届窗口再来（`window.cyc`） |
| **独发型** | 一次性（排期表给固定旬位 + `window` 保留为引擎侧换算带） | 同上 | 永久错过 = 以「江湖传言收场」的形式结局：`writeback` 按 canon 落定 + 回声传闻（见闻 **+2 封顶合计**）——**江湖没有等你** |

**z:null 口径（不可游历的会址）**：华山之巅 / 黑木崖 / 侠客岛 / 襄阳城下等事件主场不在十三地游历圈内（六区十三地计数不动）——这类事件 `z:null`，**入口在江湖页**（传闻卡 / 世界事件列表），语义是「持英雄帖赴会」而非「走到某地」。地界内事件（光明顶 / 聚贤庄）入口双开：江湖页选中或地界闯荡走到。

## 五、走向与写回（改史的分量）

- **分支**：`br[]` 至多两条——`canon`（自然走向，所有参与档默认）与 `alt`（改史，**仅 lead 档可选**）。不搞多结局树：一桩大事，一个分歧点，一条改写路——分量在代价不在数量。36 案逐案的 canon / alt 主轴见 §九 立场表；重点八案的展开细设见 §十一。
- **写回五写口**（`writeback` + 结仇）：① `cast` 人物生死/去向（**八案白名单**：华山/襄阳/光明顶/聚贤庄/雁门关/珍珑/屠狮/黑木崖，逐案声明，不开放全 CAST）；② `sects` 门派声望修正（36 案全覆盖，±5~50 封 ±100）；③④ `rumor`/`next` 余波句（`ws.world.wafter` 短码，展示封 20 条）+ 链式 `next/close`（册241：光明顶 canon 开教主之争 / alt 关门；五岳并派 canon 开黑木崖 / alt 关门）；⑤ **结仇**（册256，写主角关系不写江湖格局）——`markEnemy` 只在 lead 败局把主使 `e.boss` 写进 `relations`（`kind='enemy'`、≤ −30、幂等）。
- **写回进存档**：江湖格局增量落 `ws.world.wefate`（事件 id → 结果键），主档容量走「只存结果键不存叙述」纪律。写口 = `applyWriteback(ws, e, outcome)`：赴会 canon/alt、lead 败局（canon）、错过 echo（**按 canon 落定**）三路同口，同场同届幂等；存档三面 `wbcast` / `wbsect` / `wafter` 进 `normalize` 白名单。跨世：`rebirthCarry` 带格局三面进来世，`wefate/wecyc/wseen` 重置——上世改的格局看得见，事件本身重新赴。
- **棋盘回流（册259）**：山河棋盘打赢扩展大事 = `alt`、错过 = `echo`；游戏侧只在**终局**写本地队列 `qunxia-result-queue-v1`，扩展主壳回程走 `SQ.mutate` 单写 `pack.applyResult`，已写结局幂等拒绝。
