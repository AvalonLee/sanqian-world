## 一、三档落笔

| 档 | 名义 | 形态 | 墨 | 效果 | 主角是否察觉 |
|---|---|---|---|---|---|
| 微 | **批** | 页边一句念头 | **1** | 微调下一次自动选择的倾向（性格轴 ±2~5） | 无 |
| 中 | **改** | 改一处选择 | **3** | 直接指定本分岔走哪支 | 隐约（「他忽然心头一凛」） |
| 大 | **删** | 删/改一段既成事实 | **8** | 逆转一个已发生的结果（错过的人重逢、已败的局未败） | 明确（「命数有异」） |

**解锁节奏**：卷一只有「批」→ 卷二解锁「改」→ 卷五解锁「删」。**结构性权力一律不提前**。

---

## 二、墨：每章回满的「注意力配额」

| 项 | 规则 |
|---|---|
| 上限 | **按卷解锁**：卷一 2 / 卷二~四 3 / 卷五~七 4 / 卷八~十 5（度量感情，不按等级） |
| 补充 | **每章开头回满**；章内**不随时间恢复** |
| 结转 | 未用完的**最多留 1 点**到下一章（节俭有奖，囤积无益） |
| 额外 | 剧情里程碑（拜师 / 破关 / 卷末）**+2**，但不超上限 |
| 不可购买、不可继承 | 干预强度由「你读得多细」决定，不由付费决定 |

**为什么不做「时间恢复」**：那会诱导玩家**憋着不用、攒满再一次性改命**，与「边读边批」的体感正好相反；而且挂机时长不同的人手里墨量不同，等于用在线时长换剧情权力。按章给配额，每一章就变成一个真问题：**这一章最值得改的是哪一处？**

> **墨上限必须与 ※ 密度一起调**（体感参数，不是设定）：一章 1 个 ※ 时，3 点成本会让玩家犹豫；一章 2 个 ※ 且都是 1 点，就会变成「随便按按」。两者是乘法关系，单改一个必然失衡。

## 三、代价：违和

每次落笔累积**违和**；每完结一章自然消退 −1；上限 100。

| 落笔 | 违和 |
|---|---|
| 批 | +1 |
| 改 | +5 |
| 删 | +20 |
| 修习禁功 | +1/层（见 [`武学全录.md`](./武学全录.md) §五） |

| 阈值 | 表现 |
|---|---|
| **≥60** | 正文出现异样（叙述口吻游移、主角自言自语「我这几日总觉有人替我拿主意」）——**纯叙事警示，不改数值** |
| **≥100** | **墨厄**：本卷重写（退回卷首）、性格轴回弹 30%、失去本卷已得武学——一次性重罚 |

**设计意图**：让「把小说改成流水账」在机制上不划算。这与第一世界的 `karma` / 道伤同构（一条持续累积、越线即重罚的量），但语义不同：那边是善恶，这边是**叙事真实性**。

> **验收硬线**：零干预路线违和恒为 0；重度干预路线**不许自然摸到 100**（≤95）——墨厄必须是玩家自己选出来的，不是被动触发。见 [`数值与经济.md`](./数值与经济.md) §六。

## 四、性格三轴

| 轴 | 两极 | 影响 |
|---|---|---|
| **心性** | 侠 ↔ 枭 | 助人 / 夺物的默认倾向；同门与仇家的生成倾向 |
| **行止** | 沉稳 ↔ 狂放 | 遇敌「忍/战」默认倾向；文风（长句/短句、写景/写杀） |
| **立身** | 独行 ↔ 结义 | 是否接受结伴；结义事件触发率；败局时是否有人来救 |

各轴 **−100 ~ +100**，初始 0。批注微调 **±2~5**，重大剧情选择 **±10~20**。

轴值反过来改变**自动选择的概率分布**，于是「你没批的地方也在按你教的样子走」——这是「引导剧情发展」的真正落点，比单点改分支的长期感强得多。

## 五、落笔提前：把「参与感」和「决策权」拆开

用户要求「落笔时机提前、参与感更强，但控好度」。**这两件事看似打架，是因为被当成一回事**：

| | **参与**（可高频） | **决策**（必须稀缺） |
|---|---|---|
| 影响什么 | 语气 / 称谓 / 小动作 / 态度 | 走向 / 生死 / 去留 / 站队 |
| 例子 | 他自称「在下」还是「老子」；喝茶还是喝酒；遇见乞丐是施舍还是绕开 | 救不救这个人；入不入这个门派；杀不杀 |
| 成本 | **0~1 墨** | 3 墨（改）/ 8 墨（删） |
| 频率 | **每屏都可能** | 每 1.5~2 章一次 |
| 后果 | 只改文风与性格轴（±2） | 改剧情分支 |

**提前到多早**：

1. **第一屏就给第一次落笔**：给主角取个**诨号**（三个候选或自拟）。零成本、零风险、立刻建立「我在场」，而且这个诨号后面会被人叫出来（「原来你就是那个『半块饼』」）。
2. **第一章结束**给第一次真正的选择。
3. **卷一**解锁双选项，但**只有「批」，没有「改」**。
4. 「改」卷二、「删」卷五——结构性权力不提前。

**控度三条闸**：① 提前给的必须是**轻权力**（重权力早给必失控）；② **墨总量不变**——频率升、单次成本不变，玩家面对的是「这次批哪一句」而不是「能不能批」；③ **结构锁死**（谁死谁活、去哪不去哪，卷五之前一概不给）。

> **一句话记法：频繁给「怎么说」，稀缺给「做什么」。**

## 六、合卷：另起一书，还是续写此江湖

身死（寿尽 / 内伤 / 战死）或走完十卷即合卷。**合卷不是终点，是岔口**——屏上给两个选择：

| 路 | 内容 |
|---|---|
| **另起一书** | `worldSeed` 重掷，零继承，读一个全新的江湖 |
| **续写此江湖** | 同一江湖过若干年，你会遇到他的传人、仇家的后人、他没还上的人情 |

**续篇隔年由结局决定**（不是机械 +30）：

| 结局 | 隔年 |
|---|---|
| 有弟子 | 3~15 年 |
| 有子嗣 | 15~25 年 |
| 门派尚存 | 20~30 年 |
| 门派已灭 | 40~80 年 |
| 死得极惨 | 60~100 年（刻意留「翻案线」） |

**继承分层（关键）**：

| 层 | 继承 |
|---|---|
| 江湖格局 · 人物（转后代，初始态度受前作影响） | ✅ |
| 人情与仇（`debts` 记在后人身上） | ✅ |
| 武学谱系（成流传绝学） | ✅ |
| 地理位置（改貌） | ✅ |
| 主角数值 | ❌ |
| 好感数值（只继承态度倾向） | ❌ |
| 未完成目标 | ⚠️ 部分转嫁且不强制 |

**第三视角（情绪最强的一档）**：续篇主角可以是与前作无关的江湖新人，只在酒馆听过「当年有个人持断刀过此」。既让新玩家不被挡住，又有「你读过他的传，如今你站在他坟前」的劲。

> **铁律：独立可读性。** 没读前作也必须能懂。前作信息只允许三种形态：**传闻 / 旧物 / 他人转述**；禁止「必须知道前作才能懂」的写法。

**另起一书必须有独立价值**否则没人选：全新江湖（世界扰动重掷）· 五声音全开 · 可选「更难的江湖」（难度即世界状态）· 图鉴跨本积累（唯一跨本，纯荣誉零加成）。

**书架**：同系列书脊同纹样，旧书只读、可回看 / 跳 ※ / 看落笔记录；三代后纹样变。

> ⚠️ **工程判断（写进批次计划）**：合卷与书架是**最大的一次结构改动**（书架 + 多本，所有字段要区分「属于这本」还是「属于这个江湖」）。**放 S2 末尾做，不要一开始做**——否则前面每批都要照顾两种模式。
