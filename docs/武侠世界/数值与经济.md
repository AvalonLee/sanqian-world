## 一、三条总原则

| # | 原则 | 与第一世界的差别 |
|---|---|---|
| 1 | **挂机只给底量，事件给突破** | 第一世界挂机产出 = 成长主线；本世界挂机占总量约七成，但**每次破关的最后一段、每部绝学、每次越级，都来自事件**——量在时间，质在节点（现行主节点 = 36 桩世界事件，见 [`世界事件.md`](./世界事件.md)） |
| 2 | **时间轴单轨**（2026-11-07 拍板） | 棋盘 36 旬是玩家唯一时间轴（§二） |

## 二、时间尺度：棋盘 36 旬（单轨）

> **🔄 单轨拍板（2026-11-07，承接 [`现行总览.md`](./现行总览.md) §一 #3 与世界事件卷 §四）**：**棋盘 36 旬是玩家唯一时间轴**——走一格过一旬，事件按旬位排期（世界事件卷 §八），旬内动作受精力闸约束。**`worldDay` 降级为离线挂机计时器**：只数离线多久、发离线收益，**不再决定事件的开/关/回声**——「棋盘打赢了、后台风把案扫成 echo」的竞态从设计上根除。
>
> **代码现状（如实记）**：扩展侧 `worldDay` 时钟仍活（`claim` 内推进：1 现实分钟 = 1 游戏日，**离线单次封顶 12 现实小时 = 2 游戏年**，窗口 / 届次 / 回声 / 传闻五族仍由它驱动）；棋盘侧按 `EV_TURNS` 旬位推进。**单轨落码 = 批 266**（棋盘排期对齐 + 扩展窗口降级为后台换算带），本节先立口径。
>
> 历史口径（书形态双时钟「叙事时钟 + 修炼时钟」与放置形态「一局 18~22 游戏年」段）逐字走 git 史 v1.14 §二——它们的倒推依据（一档 ≈ 3 游戏年）已不约束现行 36 旬节奏。

**寿元不做倒计时**（不设寿命条），只在两处结算：① 老病 / 寿尽是一种结局方式；② 高境界寿元更长，用于跨世推算；另有「自伤折寿」通道（辟邪在槽每游戏年 +1 `lifeCut`，见 §九）。

## 四、破关：两个必要条件，缺一不可

**破关不掷骰**（这一点与第一世界渡劫相反）：

| 条件 | 内容 | 不满足时 |
|---|---|---|
| ① 功力 | 累计功力 ≥ 本档阈值 | 继续练 |
| ② 心境 | 见闻 / 武功层数 / 关系 / 内伤 四类门槛 | **功力封顶在下一档阈值**，正文写「内息已满，只是心里那口气不顺」 |

**心境门槛表**：

| 破关 | 见闻值 | 附加条件 |
|---|---|---|
| → 三流 | ≥ 2 | 无 |
| → 二流 | ≥ 4 | 任一部武功 ≥ 4 层 |
| → 一流 | ≥ 8 | 任一部武功 ≥ 6 层 |
| → 绝顶 | ≥ 14 | 一部内功 ≥ 7 层 **且** 内伤 ≤ 3 |
| → 宗师 | ≥ 22 | 与 ≥2 个门派/势力有往来（`relations` 中非同门者 ≥ 3 人） |
| → 大宗师 | ≥ 32 | 任一部绝学（天阶）满层 |
| → 天人 | ≥ 45 | 一段刻骨关系：`friend` 或 `enemy` 的 `affinity ≥ 80` |
| → 化境 / 无招 | ≥ 60 | 需余响（**第一世不可达**：`heritage.gen > 1` 或 `inherited` 非空方可破；余响 = 境界 / 最高武学 / 最深交情三轴，≤3 项） |

`见闻值 = visited.length × 2 + relations 中 affinity ≥ 20 的人数`（+ 世界事件见闻奖励，落 `world.webonus` 进派生式）。**纯闭关在武侠里通不了**——世界事件是见闻主产地（主导 1 桩 + 卷入 2 桩 ≈ 90+，覆盖天人线 45）。

**为什么封顶而不是清零**：封顶让时间投入**永远不亏**，只是被心境卡住——卡住的那一刻玩家能自己悟出「该出门了」。

**唯一失败路径 = 强行冲关**：心境差得远却硬破（主页强行冲关钮），成功率 `p = 0.5 × (见闻/门槛)`，失败则内伤 +2~4、功力 −20%。给「赌一把」留的口子，不是主路径。

## 五、产出

```
每分钟功力 = 8.0 × (1 + 0.15 × 已学武功总层数) × 模式系数（册215 重定种；模式系数闭关 1.0 / 闯荡 0.6）
```

| 项 | 取值 | 说明 |
|---|---|---|
| 基础 | **8.0 功力/现实分钟** | 挂机保底速率（离线 = 在线，不打折；一档 ≈38 现实分钟） |
| 内功加成 | `1 + 0.15 × 总层数` | 层数是「境界的镜子」 |
| 模式系数 | 闭关 1.0 / 闯荡 **0.6** | 闯荡少产功力，但见闻 +1/地界、遇敌与奇遇 ⇒ 心境只靠走动能补 |
| 事件补充 | 挂机段节点投放 + 世界事件见闻/奖励 | 节点出现在卡点上，不均匀撒（`ARC_GAIN` 预算；36 案接手后节点主产 = 世界事件，批 266 对齐） |

**「闭关 vs 出门」是本世界唯一的策略选择**，且两条路都不通：纯闭关功力涨得快但卡心境；纯出门见闻够但功力不够 ⇒ 玩家被迫交替。

> **定种验算历史（保留）**：10 卷 × 20 章零干预的卷末读数表（境界行逐卷复现、两卡点落「一次奇遇就能补上」带内）与册160 勘正注逐字保留于 git 史 v1.14 §五/§十；机器读数唯一出处 = `sim-wuxia.cjs` 逐卷读数行（在册锚，改锚须归因）。

## 六、战力与胜负

```
战力 = 境界基准 × 武艺 × 兵刃 × 相性 × 状态
```

| 项 | 取值 | 说明 |
|---|---|---|
| 境界基准 | 江湖设定 §五 表 | 10 → 14,000 |
| **武艺** | 1.00 ~ **1.35** | `1 + Σ(品阶权重 × 层数) × 0.012`，封顶 1.35；实现权重 **天 1.0 / 地 0.6 / 玄 0.3 / 黄 0.1** |
| **兵刃** | 0.90 ~ **1.20** | 空手/不趁手 0.90；寻常 1.00；好兵刃 1.10；名兵 1.20（`WEAPONS` 表） |
| **相性** | 0.87 / 1.00 / **1.15** | 内力四性环克（接 `battleOdds`，依赖「对谁」） |
| **状态** | 0.60 ~ 1.00 | 完好 1.00；内伤 ≥8 ×0.75；≥12 ×0.60 |

**关键标定：系统性加成总上限 ≈ 一档境界差，且必须小于它。** 满配（1.35 × 1.20 × 1.15 = **1.86 倍**）＜ 档差（约 2.3 倍）⇒ 越一档有戏但劣势（满配胜率 39~45%），跨两档只是奇迹。**装备与武艺能补半档到一档，不能补两档**——令狐冲能靠剑法越级，但不能凭剑法打东方不败。

**行头三槽不进战力式**（册230 红线）：暗器 → 胜战战利品 +20%；护身 → 败战内伤 −1 层；鞋履 → 遇敌概率 −5 点。判据 = 冒烟 **E30 ③**「穿满与赤身 `powerOf` 逐位相等」守门断言。

**胜负掷判**：`p = 1/(1 + (敌战力/我战力)^1.5)`，夹 0.05~0.95；**三回合制**（掷三次取两胜）降方差。**败了不等于结束**：胜（拿人拿物扬名）/ 险胜（惨胜带伤）/ **败走窄路**（被擒 / 重伤逃 / 失物 / 被救 / 结仇；内伤 +1~3、侠名 −）/ 大败（p<0.15：濒死 → 被救 / 断臂 / 武功被废；内伤 +4~6）。内伤 0~15：≥12 进咯血档且引擎把后续分岔往「寻医/退隐」压；**=15 即死**——但「死」永远是玩家或极端运气的产物，不是自然结果。

## 七、银两：市集有限货架，经济是**难度调节器**

**现行口径**：市集 = **有限货架**（`SHOP_LIST` 七件，册217 落码：金疮药 50 文 / 老山参 5 两 / 铁刀 2 两 / 好剑 20 两 / 秘籍稀有格三件高价）。**不做**坊市 / 拍卖行 / 玩家交易（§十一）。

| 钱花在哪 | 数额（文 / 两） | 换来什么 |
|---|---|---|
| 吃住 | 面 3~5 文 / 通铺 10 文 / 上房 80 文 / 一壶好酒 200 文 | 体力恢复、听到消息 |
| 疗伤 | 金疮药 50 文 / 请郎中 200 文 / 老山参 5 两 | 内伤 −1 ~ −3 |
| 行路 | 车马一日 100 文 / 渡船 50 文 / 快马 15 两 | 少一日路程 = 少一次遇袭判定 |
| 打通关节 | 城门吏 1 两 / 衙门书办 10 两 / 通缉销案 200 两 | 消一次麻烦 |
| 人情 | 赎人 100~1,000 两 / 送礼 5~50 两 / 施舍 10 文 | `affinity`、`debts` |
| 兵器 | 铁刀 2 两 / 好剑 20 两；名兵 18 件 `cost:0` 不卖（夺兵 / 事件主奖励 / 托付取得） | 兵刃乘区 |

**口径**：1 两 = 1,000 文。开局 100 文——**穷是开局的一部分**。**收入**：押镖 5~40 两 · 悬赏 10~200 两 · 变卖 · 师门月例 · 劫道 20~300 两（侠名 −10~−40）。

**核心机制：钱不够不是阻塞，是改道。** 走官道要打点，没钱走山路 ⇒ 遇匪或奇遇；住不起上房住通铺，夜里听见密谈；抓不起药硬扛，内伤拖着走。**经济压力全部转化为分支，一分钱都不许变成「请去赚钱」的提示。** 人情债 `debts` 跨代继承——「三十年前你师父救过我一命」比三百两银子管用。

## 八、数值 → 门槛生成

| 门槛类 | 判什么 | 不满足时 |
|---|---|---|
| 战力 | `战力 ≥ 阈值`（赴会 lead / 遭遇战） | 「他若上前，是送死」——该支不出现 |
| 武功 | 会某部 / 某层 | 不会就是不会，正文不提 |
| 银两 | `stones ≥ N` | 走另一条路（§七） |
| 关系 | `relations[x].affinity ≥ N` / `kind`（雁门关式人心门槛） | 求不到人 |
| 性格轴 | `persona.xia ≥ 30` 之类 | 他说不出那句话 |
| 物品 | 秘籍 / 兵刃 / 信物 | 用不了 |
| 见闻 | `visited` 含某地 / 见过某人 | 想不到 |

**三条配套规则**：① 够不着的选项不显示，但事后留回声（每段 1~2 次）；② 每幕有「差一点」的 ※（门槛落在触手可及处——36 案排期里就是难度带的落位）；③ **门槛必须可推断**——玩家凭措辞掂量自己，不凭数字。
