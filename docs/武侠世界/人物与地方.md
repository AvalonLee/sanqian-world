## 一、人物池：40 人核心池（设计底座）→ 现役 CAST 107

**设计底座 = 40 人（26 门代表 + 14 位江湖名人）**，选人标准不是频次排名，而是「26 门全覆盖 + 高频补人」：纯按频次取会全是《鹿鼎记》《书剑》主角，门派覆盖一半不到，事件池会没有对手可派。两表逐人（id / 频次 / 阵营 / 门派 / 定位 / tier）逐字保留于 git 史 v1.2 §一（26 门代表表 + 14 名人表 + 两处低频说明：`洪安通`(43，称谓替代「洪教主」) / `宗维侠`(51，崆峒出场少)——**低频不等于不重要**）。

**现役 = CAST 107**（2026-11-07 实数 `data.js`）：40 人工全字段为底座，其余为规则推断（`auto` 标记）与后续批次补入；tier 分布 **S 11 / A 16 / B 24 / C 56**。世界事件 36 案的 `boss` 全部落 CAST；名宿池（S/A）与市井池（B/C）经内容桥进山河棋盘（册245）。

### tier = 叙事取人的「打不打得过」锚

| tier | 含义 | 对应境界 |
|---|---|---|
| **S** | 绝顶以上，主角终局也难撄其锋 | R7~R8 |
| **A** | 宗师，三幕中后段才谈得上交手 | R5~R6 |
| **B** | 一流，第一~二幕的主要对手 | R3~R4 |
| **C** | 二流及以下，开局就能打 | R1~R2 |

**用法（棋盘口径）**：世界事件 lead 对赌按 boss tier 折算战力（数值卷 §六）；闯荡遇敌按「主角当前境界 ±1 档」筛（对手档不与 tier 混用——遭遇战是杂鱼系数 0.6 的散兵，名场面级对手属 KNOTS / 世界事件层）。R2 的主角撞上 S 级人物不写「交手」，只写「那人只抬了抬手，他便退了七步」——**数值不到不是不写他，是换一种写法**。

## 二、四个必填字段是人工标注的（语料给不了）

| 字段 | 取值 | 为什么必须人工 |
|---|---|---|
| `sex` | m / f | 语料里「他/她」在对话与旁白中混用，统计不可靠 |
| `align` | zheng 正 / zhong 中 / xie 邪 / yin 隐 | 原文不给「阵营」这个标签，正邪是读者判断 |
| `sect` | 门派 id / null | 「共现最高的门派」只能作初猜（虚竹同时近少林与灵鹫宫），**标待核、不得直接进正典** |
| `tier` | S / A / B / C | 武力高低在原文是模糊比较，需人工判 |

这条口径沿用勘察报告 §四的结论：**别指望数据推断语义**。数据只给「谁常和谁一起出现」，不给「他是哪一派的好人」。

## 三、别名组：称谓是资产，不是噪声

`萧峰 ⇐ 乔峰` · `童姥 ⇐ 天山童姥` · `灭绝 ⇐ 灭绝师太` · `韦小宝 ⇐ 小宝/小桂子/韦香主` · `黄蓉 ⇐ 蓉儿/黄帮主` · `杨过 ⇐ 过儿` · `周伯通 ⇐ 老顽童` · `赵敏 ⇐ 绍敏郡主` · `胡斐 ⇐ 雪山飞狐` · `洪安通 ⇐ 洪教主` · `任盈盈 ⇐ 圣姑`（未入核心池，留档）

**这是叙事层的表现手段**：同一人按关系亲疏换称法——陌生时「那老者」，相识后「周伯通」，熟稔后「老顽童」。所以存 `alias[]` 而**不删**别名。

⚠️ **别名归组不做机械删除**：`韦小宝`(9,913) 与 `小宝`(10,039) 频次各自独立，合并后**不许相加**（子串会重复计数），归组只用于「指同一人」，不用于频次求和。

**称谓替代是统计陷阱**：`任盈盈` 全文仅 **3** 次（原文几乎只叫「盈盈」）、`洪安通` 43 次（多称「洪教主」）。⇒ **低频榜单前列的名字，先查它是不是被称谓替代了，再判断重不重要。**

## 五、关系网：70 对（核心池内部既有关系）

源 = 8,451 对共现全表 ∩ 40 人池，取 ≥20 次，得 **70 对**。前 10：

| 对 | 次数 |
|---|---|
| 郭靖 ↔ 黄蓉 | 1,514 |
| 小龙女 ↔ 杨过 | 978 |
| 张无忌 ↔ 赵敏 | 581 |
| 杨过 ↔ 郭靖 | 387 |
| 杨过 ↔ 黄蓉 | 369 |
| 洪七公 ↔ 郭靖 | 325 |
| 令狐冲 ↔ 岳不群 | 318 |
| 洪七公 ↔ 黄蓉 | 315 |
| 令狐冲 ↔ 仪琳 | 277 |
| 周伯通 ↔ 郭靖 | 276 |

**它是什么**：不是「关系设定」，是**取人权重**——事件里要同时出现两个 NPC 时，优先取有共现的对（读者读到「黄药师与郭靖对坐」比「黄药师与韦小宝对坐」不违和）。

**它不是什么**：不代表本世界主角与他们的关系。主角 `relations` 是另一张表（`affinity/kind`），随剧情生成——含**结仇写口**（册256：lead 败给世界事件主使时 `markEnemy` 把 `e.boss` 写进 `relations`，`kind='enemy'`、交情压到 ≤ −30），人物页「仇敌」档自此有真生产者。

## 六、词表不可信的三个实证（方法论，写死）

本批对「词表统计」做了全文复核，抓到三类系统性缺陷：

| 类型 | 实例 | 后果 |
|---|---|---|
| **漏项** | `东方不败`（全文 320）· `丘处机`（829）· `方证`（415）· `王重阳`（136）· `俞莲舟`（377）· `程英`（308）—— 在五类词表里**全部零命中** | 只看词表会得出「这些人不存在」，把顶级人物漏出池 |
| **称谓替代** | `任盈盈` 全文仅 3（原文多称「盈盈」）· `洪安通` 43（多称「洪教主」） | 重要人物被误判为龙套 |
| **异体/错字** | `峨眉` 2 次而「峨嵋」高频 · `八步赶蝉` 实为「八步赶蟾」 | 地点/武功被误标冷门 |

**结论（本项目的方法论约束）**：**词表只能当候选清单，频次必须回到全文重算**。三个 `*-exact.json` 就是这条的执行产物，日后改名单一律重跑，不许手改 JSON。
