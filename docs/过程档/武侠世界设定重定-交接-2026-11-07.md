### 3.2 三个跨卷结构断层（比单卷错字更严重）

**① 两套事件模型**
- 扩展侧：watch / join / lead 四档、tier 门槛、lead 对赌、失败代价、canon/alt 写回（[index.js:1631](../../extensions/com.avalonlee.sanqian-world/assets/worlds/wuxia/index.js#L1631)）。
- 棋盘侧：事件卡 → 赴会 → 一场战斗 → 胜/败 → 邸报，没有四档与扩展 tier 判定；奖励走游戏自己的 `QUNXIA_CRISIS_REWARD`（[content-merge.js:167](../../extensions/com.avalonlee.sanqian-world/view/games/qunxia/content-merge.js#L167)）。
- **玩家只看到后者。** 文档现在描述的是前者。36 案做主干的第一个决定：以棋盘事件模型为玩家可见规则，扩展四档降为后台/测试口径，或反向把四档搬进棋盘（见 §六 B265）。

**② 两套时间轴**
- 棋盘：36 旬，事件排第 1~35 旬（`EV_TURNS`，[content-merge.js:158](../../extensions/com.avalonlee.sanqian-world/view/games/qunxia/content-merge.js#L158)）。
- 扩展：`worldDay`，1 现实分钟 = 1 游戏日，事件窗口按「游戏年」判。
- 两者只在回程 `applyResult` 时相接；世界钟先把案扫成 `echo`，棋盘里的胜局会被拒（册259 已知余量）。这是玩家会遇到的真 bug，不是文案问题。

**③ 两套数值**
- 棋盘：侠名 / 境界 / 气血 / 真气 / 行脚 / 战力。
- 扩展：修为 / 境界 0~9 / 精力 / 内伤 / 银两 / 武学层数。
- payload 只桥接武学、门派、人物、事件，**不桥接玩家成长**（[qunxia-home.js:37](../../extensions/com.avalonlee.sanqian-world/view/qunxia-home.js#L37)）。文档里的「功力阈值 / 破关双必要条件 / 精力闸」玩家在棋盘里看不到，也没被消费。

## 八、工作纪律（沿用本仓硬规矩）

- **分支**：`wuxia` 上提交；不要动 `dev` / `master`；发布时开 `wuxia → dev` PR。`master` 由 `dev` 合并。
- **先文档后代码**：261~263 不改代码；264/265 必须单独获批。
- **只有一份事实源**：不要复制 `assets/` 或 `manifest.json` 到仓库根；旧卷归档用 `git mv`，不要两份并存。
- **历史注不改写**：旧卷整卷移入 `_archive`，正文逐字保留；现行卷重写时，版本志保留旧版本行。
- **升版本 = 改 `manifest.json` 一处 + `npm run ledger:fix`**；每批只加 `0.0.1`。
- **门禁**：收口跑 `npm test`（21 件 / 650）；改界面再 `npm run test:ui`；改玩法数值再 `npm run test:sim`。
- **探针门禁要真档**：本机现行 `extensions/com.avalonlee.sanqian-world/.storage.json` 无 xiuxian 世界态，探针只有 235 < 在册 245。跑全量门禁用：
  ```bash
  SQ_STORAGE="E:/下载/extensions/sanqian-world/extensions/com.avalonlee.sanqian-world/.storage.json.0" npm test
  ```
  然后再 `npm run ledger:fix`（否则 `LEDGER_REFUSE`）。
- **推远端**：本机 HTTP/2 会被重置，**必须加 `-c http.version=HTTP/1.1`**；若仍 reset，再指定可达 IP：
  ```bash
  git -c http.version=HTTP/1.1 -c http.curloptResolve=github.com:443:140.82.114.4 push
  ```
  ⚠️ **`push` 报 `Recv failure: Connection was reset` 不代表失败**——2026-11-07 实测 `POST git-receive-pack` 已返回 200、远端 ref 已更新，重置发生在响应尾部。先复核再决定是否重试：
  ```bash
  gh api repos/AvalonLee/sanqian-world/git/ref/heads/wuxia --jq '.object.sha'
  ```
  不要因为 reset 就 force push 或重复推。`gh-proxy.com` 只代理读、不接 push；不要用它推。
- **一次性件写仓外**（`%TEMP%`），仓根不留脚本/备份/日志；`.gitignore` 的 `sq-*` 会让 `git status` 看起来干净，别被骗。
- **提交后复确认**：`git status --porcelain` 为空 **且** `git show --stat HEAD` 的文件清单与批次叙述一致。
- **不动测试来换绿**：判据红了先归因；采样族偶发红按 N27/N69 的纪律定种子，不放宽容差。
