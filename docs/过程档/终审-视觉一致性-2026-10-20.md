> 背景：UI v2「宣纸水墨」移植在 B15-a…k 完成十六页逐页换装后，对全站做一轮一致性终审。

## 一、方法

仓外一次性探针（`%TEMP%\sq-final\final-audit.cjs`，playwright-core + Edge 无头）：

- 载入测试存档（`fixture-save.json`，真仙九境），逐页切 16 个 tab；
- 每页在 **亮 / 暗双主题 × 1440 / 720 / 380** 四态下测七项指标，并采三张截图（1440 亮、1440 暗、380 亮）；
- 共 **16 页 × 4 态 = 64 组读数 + 48 张截图**，零 pageerror、零 console error。

## 二、七项一致性指标（16 页全过）

| 指标 | 口径 | 结果 |
|---|---|---|
| 纸面色 | 亮 `rgb(246,241,229)` / 暗 `rgb(28,26,23)`（`html` 底） | 16/16 命中 |
| 纸纹层 | `html::before` 含 SVG 噪点，亮 .26 / 暗 .12 | 16/16 存在 |
| 外层面板 | `.panel` 背景必须透明（B15-a 去大卡） | 16/16 = 0 处有底色 |
| 圆角 | 除药丸（99px）与圆（50%）外，5–90px 圆角应为 0 | 16/16 = 0 处泄漏 |
| 数值字体 | `.big/.num/.lg-n/.val/.rankno/.g-buy` 走宋体栈 | 16/16 全衬线（抽样 1~29 个/页） |
| 380 横向溢出 | `scrollWidth ≤ clientWidth` | 16/16 无 |
| 720 横向溢出 | 同上 | 16/16 无 |

**结论：异常页 0 ／ 16。**
