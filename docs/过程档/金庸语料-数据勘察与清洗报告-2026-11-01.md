### 3.1 四类实测缺陷（直接当选典会出事）

| # | 缺陷 | 实例 | 后果 |
|---|---|---|---|
| ① | **子串重复计数** | `韦小宝` 与 `小宝` 同表，两个各计 9,913 / 10,039 | 同一人算两遍，人物榜失真 |
| ② | **词表噪声** | 武器表把 `无` 计成武器 **26,241 次**（全表第一），另有 `剑` / `刀` / `枪` 等通名 | 词频被通名淹没 |
| ③ | **同义未合并** | `少林寺`(1121) / `少林派`(699) / `西少林`(14) / `南少林`(5)；`华山派` / `华山剑宗` / `华山气宗` | 门派热度和战力被切碎 |
| ④ | **类别错置** | 地名表混入 `蒙古`(1411) / `契丹`(487) / `满洲`(265) / `波斯`(190) 等政权名；武功表混入 `一阳书指`（错字） | 分类直接不可用 |

### 3.2 第二轮修正与结果

改用**最长匹配优先**扫描（首字索引 + 长度降序，命中即跳过该词长度），子串问题消除：`小宝` 不再独立成条，`韦小宝 9,913` 归位第一。

同时人工拉黑 24 条确定噪声（`无` / `剑` / `东支` / `倚天剑剑` / `打狗棒`+`狗棒` 等），单字词一律不入。

修正后：实体命中 **2,195**、人物共现对 **8,451**（≥2 次）。
跨类同名 **12 例**：`桃花岛` / `灵鹫宫` / `侠客岛` 等 8 例「门派 vs 地点」（金庸里本就是双重身份，游戏应两者都留）、`淑女剑` / `鳄嘴剪` 等 4 例「武功 vs 武器」（同名器物与同名招式，同处理）。

### 3.3 仍然存在的三类残留（必须人工裁定，不能自动）

1. **别名未归并**：`乔峰`(1132) 与 `萧峰`(1786) 是同一人；`蓉儿`(370) 与 `黄蓉`(5092)；`小桂子`(355) / `韦香主`(298) 与 `韦小宝`；`老顽童`(316) 与 `周伯通`；`成吉思汗`(393) 与 `铁木真`(363)；`童姥`(534) 与 `天山童姥`；`姑姑`(509/**7 书**) 是**泛称**不是别名。
2. **缺词导致误切**：`铁掌`(113) 实为「铁掌帮」被切断后的残留；`九阳`(157) 出现在地名表属误分类。
3. **跨书同名与泛称**：`马夫人` / `王夫人` / `保定帝` 这类称谓在不同书指不同人。

➡ **裁定**：别名**不删除、要归组**。武侠里「老顽童」本就是周伯通的外号 ⇒ 人物表设 `name` + `alias[]`，别名反而是叙事资产（正文里可以按关系亲疏换称法）。这一条改变了原草案 §十六「人物只有 name」的设想。

## 五、能用与不能用（结论）

| 用途 | 判定 | 说明 |
|---|---|---|
| **叙事模板取材**（写景/动作/对话的用词） | ✅ **最佳用途** | 860 万字语料是词句富矿，`scene` / `act` / `talk` 三层模板的语料基础 |
| **人物池**（NPC 生成） | ✅ 可用（需归组） | top 200 足够；别名归组后一人一条 |
| **门派池** | ✅ 可用（需合并同义） | 26 门已按实测校准 |
| **武功池** | ⚠️ 有限可用 | 仅 ≥25 次的约 30 条可靠；384 条长尾只作随机秘籍 |
| **地点池** | ⚠️ 需重分类 | 必须剔除政权/民族名（蒙古/契丹/满洲/波斯），只留具体地点 |
| **武器表** | ❌ **不可用** | 通名与噪声占多数（`无` 26,241 次），建议整体废弃，另按「兵器类别 + 著名兵刃」重建 |
| **人物阵营/性别/正邪** | ❌ 语料里没有 | 必须人工标注，不能从频次推出 |

**还缺的数据（语料给不了，需另建）**：
1. **人物属性**（性别 / 阵营 / 门派归属 / 武学归属）—— 只能人工标注或从百科抽，语料只能给"共现"不给你"是哪个门派"。
2. **武功的属性**（内功/拳掌/兵器/轻功/奇门 + 刚柔四性）—— 名称可猜，但准确分类需人工过一遍。
3. **情节节点**（谁在哪一章做了什么）—— 语料有全文，但要抽成结构化事件需另做抽取，量级远超本轮。
