---

成就图鉴与人生传记是《三千世界》的**跨世沉淀面**：图鉴把「遇到过什么」变成永久资产（id 引用、跨世不清），成就是把「做过什么」即时兑现成遗泽与称号，传记把「活过怎样一世」在转世瞬间凝固成一篇可读的短文。三面共用一个账本（meta 层）、一个写口（轮回卷 legacy 事务通道）、一套词表族（`codex.*`）——收集不改变任何池数据，成就不开任何新乘区，传记不进 tick：它们只是把游戏已经在发生的事**记下来、奖一次、讲一遍**。

### 1.2 总纪律（五条）

1. **条目 = id 引用**：图鉴只存池内条目 id（或稳定短 id），名称 / 描述全部走 lexicon 词表渲染（`codex.*` 族 + 各池既有 `event.*` / `talent.*` / `treasure.*` 等 key 族）——图鉴层零文案存储、数据文件禁文案纪律不变；
2. **跨世永不清**：九面图鉴与成就账本只增不减（转世重置矩阵轮回卷 §四 的「继承」侧）；重复获得同条目不刷新首录时间戳（百器录 gearSeen 先例，数值详设 §3.7）；
3. **幂等只奖一次**：里程碑与成就的遗泽 / qiRate / 称号全部挂幂等键（里程碑键 `codex.ms.{face}.{档}`、成就键 = 成就 id），跨世重复触发零效果（断言 #204）；
4. **写口分工**：`codices / achv / titles / biographies` 四字段由图鉴成就模块唯一写口；遗泽入账**不直写 `meta.karma`**，一律经轮回卷 legacy 事务通道（轮回卷 §7.1）——同一事务内完成「记键 + 入账 + karmaLog」；
5. **只读池数据**：图鉴 / 成就判定只读各池正典（事件池 / 天赋池 / 法宝 / 功法 / 道友 / 秘境 / 势力），永不写池、永不改池计数——池扩容批（如 ✅ 深化批 196 天赋已于 2026-10-07 取证确认落地：`SQ.TALENTS.common` 72 + `xiuxian` 124 = **196**）只需刷新图鉴面的「分母」（§2.1 动态分母口径）。
