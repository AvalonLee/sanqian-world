## 二、全局交互规则

### 2.1 模态栈调度

- 优先级：**EVENT_CHOICE > OFFLINE_REPORT > TRIBULATION_RESULT > CONFIRM**；同屏只出一个，其余入队按序弹出；
- 队列上限 8，溢出丢弃最低优先级项（写日志不弹）；**EVENT_CHOICE 永不适用丢弃**——它由 pendingChoice 持久化挂起，只会被弹出、不会被挤掉 ★；
- **回线时序**（有挂起奇遇 + 有离线结算时）：LOADING → MAIN（修行页）→ 恢复 EVENT_CHOICE → 玩家选完 → 弹 OFFLINE_REPORT → 若结算中含渡劫 → TRIBULATION_RESULT；★ 渡劫演出排在闭关弹窗之后（先知道赚了多少，再看最后一劫）；
- pendingChoice 跨离线保留：回线必恢复，不可被任何模态顶掉（优先级 1）；
- CONFIRM 之间不嵌套：浮层内触发的 CONFIRM 盖在浮层上（z 序 +1），关闭回浮层不回页面 ★。

### 2.2 红点体系（**红点裁决批 2026-10-02 结案**：校对批悬置的「四类 vs 五处」分歧已按现行实现裁决——两方口径各实现一半、坊市重合，实现态 = **Tab 级 6 处 + chip 级 2 处**（v1.13 六向批收口：+天象 chip ✅），全量见下表；原「五处」「四类」两个计数口径均作废。补充实现事实：传闻红点并入奇遇 Tab；「地」chip 红点实现未实现 = 待实施 TODO）

### 2.3 toast 通道（仅存清单）

法器拾得/替换/入库/炼化 · 功法入门 · 道友升档护法（批 3）· 迁居完成（批 2）· 系统提示（补货等）。**事件类 toast 已废止**。统一：底部浮动、3 秒自动消失、点击展开详情、不打断任何操作、同屏最多 2 条（第 3 条顶掉最旧）★。

### 2.4 返回与关闭

- 浮层类（karma/属性/明细/名录/百器录/总账/洞府/系统日志）：✕、点遮罩、物理返回均可关；
- **EVENT_CHOICE：仅分支按钮可关**（点遮罩/返回无效 + 轻震动反馈提示「必须选择」）★；
- CONFIRM：✕ 与「取消」等义，状态无损；
- 创角三屏：物理返回 = 回上一屏；屏 1 返回 = 直接退出（未入世不写档、无损失，不弹确认）★；
- 浮层内二级页（道友详情）：‹ 返回回名录一级，✕ 直接关整个浮层。

### 2.5 容错三态（每个数据区块必备）

| 态 | 表现 |
|---|---|
| 加载中 | 「--」占位（module 卡）/ 骨架灰块（view 内浮层）★ |
| 桥失败 | 人话错误一行（错误码 + 说明）+「重试」按钮，不白屏（#89） |
| 空数据 | **不隐藏区块**，给引导文案（总账空态「第一块灵石在秘境里等你」、名录「？」剪影、lastOffline=null 整卡不渲染是唯一例外——「从未发生」与「发生了但是空」语义不同） |

### 2.6 数字与格式

- 滚动动画：收功/渡劫/购买后的余额与修为变化，600ms ease-out 滚动 ★；
- 缩写：<1万 千分位 / ≥1万「万」/ ≥1亿「亿」，百分比 1 位小数；
- 倒计时：「X时Y分」，<1h 显示「X 分钟」；洞府迁居冷却以游戏历显示（「X 游戏年 X 游戏日」；1 游戏年 = 360 游戏日 = 360 现实秒，走查批 v2.8）；
- 所有概率：文言档位 + 精确值并列（「四成之数 · 40%」）。

### 2.7 动效总开关

- `prefers-reduced-motion` 命中时：全部动效降为瞬时切换（呼吸/射线/红闪/震屏/滚动全停），信息不丢失（闪电常亮、进度线满格、数字直接终值）。

## 四、分稿交互对照

### 4.1 创角三屏（P2 · 批 1 补倾向）

- **步骤条**：一二三汉字节点，当前实心金、已过描金；点击不可跳转（只随流程走）★；
- **屏 1**：输入实时校验（空/1字/9字 → 确认置灰 + 红字文案走词表）；「掷杯问名」无限次整名重掷，重掷后输入框可继续手改；
- **屏 2**：重抽天命 = 三卡整体重掷（组合分布 40/35/25，#13/#14），**不清已选倾向**；倾向三段单选，默认左道，点选即高亮（无确认按钮）；「确认锁定」→ 入定 CONFIRM（摘要 pills 全摊开：天赋正绿负红 + 倾向）→「入定」写入并跳屏 3，「再想想」回屏 2 状态无损；锁定后回退到屏 2 = 只读态（重抽按钮消失）★；
- **屏 3**：live 卡可选（描金选中态），coming 卡点击 = 轻震 + 文案「此界尚在混沌，未可投生」（不可选但不静默）★；世界名首渲染生成一次，同会话重进不重掷；
- **入世**：一次性写入序列 = profile（name/talents/alignBias/gender/race）→ worlds.xiuxian 初始化（含 cave.current = market_yard）→ meta → worldName → 直进 MAIN 修行页，无过场（#19）。

### 4.2 修行页（批 1 · chip 批 2/3 · 界面批三/四/五）

- **角色总览卡 `.stathero`（界面批四）**：页面顶部**战力大字**（30px 主色）+ 精/气/神三维三格；战力行由秘境页**上移**至此（§4.5 秘境页不再有战力行）；
- **境界说明浮层 `#modal-realm`（界面批四）**：总览卡下方「当前境界：{境界名}」行右侧「境界说明」链接点开；逐行十阶（序号/名称/状态已过·当前·未至），当前行主色描边 + 显示修炼速度/基础战力/突破需求修为/渡劫成功率；纯只读；
- **页面无 h1 标题（界面批四）**：修行页与其余各页一致，顶部直接进内容（奇遇页页首计数徽标为豁免项，见 §4.3）；
- **产出明细浮层**：点「含加成明细 ▾」开；逐行来源+乘区归属+数值（加算绿/独立乘金/折损红），底部结算式一行 ★；批 1 无洞府行、批 3 前无护法相关行；
- **渡劫预估浮层**：点「明细 ▾」开；加项逐行 + **封顶态显式展示**（「加总 1.20 → 封顶 95%」）；魔道档三态同源：karmaMod 红负值 / 护法行灰字「无人护法」/ 正道档位行隐藏；tribNext 类一次性修正生效时追加临时行（用后即清）；
- **手动渡劫（界面批三；自动批 2026-10-02 开关迁修行页）**：渡劫默认**不自动触发**；修为达阈值且自动渡劫关闭（`settings.autoTrib` 缺省 false）时，页内出现「修为圆满」卡 + 「渡劫」按钮，点按才掷判（词表 `trib.manual.*`）；**修行页底部「自动」区**（原设置页）可开自动渡劫恢复原行为；
- **四柱 chip**：点 chip 开对应浮层——**法 chip = 弹只读修习功法浮层 `#modal-arts`（界面批五改，原为跳功法页定位主修）**，与财/地/侣同级；红点见 §2.2；**chip 副标内容口径 ★**（与视觉稿对齐，UI/四柱卷 ASCII 同步）：财 = 余额 + 「收 X · 支 Y」摘要（ledger 两列合计）/ 侣 = 「护法·道号③」（结缘后换「道号 · 双修形态名」）/ 法 = 「主修·功法名 Lv」/ 地 = 「洞府名 ×mult」；
- **闭关所得面板**：常驻；「明细 ▾」展开逐行构成（含「离线零奇遇 · 时钟冻结于 X 分 X 秒」行 ★）；null 不渲染；
- **回线弹窗**：已弹标记为内存变量、以 `lastOffline.at` 为键（与 UI 卷 v2.4 同口径）——同 session 内同一结算不重弹，页面刷新视为新 session 允许再弹一次；与 EVENT_CHOICE 冲突时顺延到下一次进入修行页；
- **收功**：手动 claim → 数字滚动 + toast 不再弹（页面内直接刷新）★；「已臻化境」满态：进度条满格变色 + 文案替换。
- **历练入口预告（体验手感批 2026-10-02）★**：当前秘境战力不足（`power < need`，与秘境页瓶颈同一口径）时，结算区「外出历练」卡常驻红色预告行——词表 `idle.mode.venture.warn`（举步维艰 + 建议先闭关破境，--bad 色）；不拦截点击，纯预期管理。

### 4.3 奇遇页 + 抉择模态（批 1）

- **页首计数徽标**：页首保留「已遇 n/N · 天级 n/N」计数徽标（功能性计数非标题，界面批四 h1 移除的豁免项，UI 卷 §3.5 同源）；
- **叙事流**：默认展开最近 3 条，其余折叠（点卡头展开/折叠，200ms）；「未择之路」折叠区仅佩戴照世镜时渲染（卸下即隐藏、已展开态复位）；
