稿一批注（UI v2.0 §3.3 侣浮层）
  • 20 格分两节：道友 16 / 道侣候选 4；格内四态全展示——已结缘（头像字 + 档名 + 好感进度条）、未结缘（剪影「？」，名讳隐藏）、护法位（☂ 金角标，好感最高者自动担任）、绝交锁（「缘尽」灰格，身份永不揭示——本稿存档里是当年夺过碗、后来业力又修回正道的那位：缘断不可复结）；
  • 候选格无论结缘与否都带藕荷「双」角标——「有一位可结道侣的人藏在？」是收集牵引；
  • 顶部两行常驻：护法位摘要（档 3 起显示渡劫加项）+ 双修状态行（未结缘 = 虚线灰态提示）；
  • 档名走词表 `bond.{id}.title.{1..4}`：相识 / 知交 / 生死之交 / 道护；
  • 「侣」chip 红点 = 有人升档或候选可提亲，进浮层即消。
