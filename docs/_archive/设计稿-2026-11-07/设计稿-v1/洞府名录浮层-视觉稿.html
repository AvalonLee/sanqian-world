稿一批注（UI v2.0 §3.3 地浮层）
  • 卡片四态：驻留中（描金边 + 「驻留中 · 签名生效」态标 + 签名标「生效中」）、已持有（迁居按钮）、未达资格（剪影压暗 + 缺项 chips 三段式逐段标红：境界/首通/灵石，达标段转绿 ✓）、未持有但资格齐 = 「入驻」按钮 + 付费（稿二）；
  • 灵气叙事是入驻奖励：未达资格卡叙事折叠为「入驻后方可阅」——把 30~60 字正典文案变成盼头；已持有卡全文展示；
  • 排序规则：驻留中置顶 → 已持有按 mult 降序（迁居就近可比）→ 未达资格按 mult 升序压轴（阶梯尽头 = 古仙人府终极目标）；
  • 迁居冷却为全局一次：任一迁居成功后所有「迁居」按钮变倒计时「X 时辰后（23:12:05）」——世界观换算 + 括注精确值（§六）；
  • 「地」chip 红点 = 新洞府资格达成，进浮层即消；秘境页首通角标 ↔ 本浮层缺项 chips 同源（cleared 字段）。
