帧四批注（UI v2.3 §3.7 / 属性设计 §六）
  • 三值卡 = 当前值 + 构成明细行（基础/滋养/装备/事件/buff 逐项，基础 30 =（境界索引+1）×6 对表）+ 一行「这属性管什么」的实战换算（中等判定成算 / 瓶颈判定 / 损失修正）；
  • 成算用文言档位 + 精确值并列（「四成之数 · 40%」），正道 dc×0.95 已计入并标注算式——与事件分支按钮的成算预告同源；
  • dc 标准线随境界漂移：本帧 dc 60 = 化神基础 30×2，晋升炼虚后同一事件自动变「简单」（旧内容自动降难，无需改词条）；
  • 天赋缩略卡 = 创角屏 2 同款 pill（正绿负红），锁定态不可点；倾向行与 karma 浮层第四分量同源（左道 = 0 演示）；
  • 底部纪律行向玩家直白交代「属性是判定轴不是产出轴」——防「为什么不加产出」的困惑，设计红线（属性设计卷首）的用户侧表达。
