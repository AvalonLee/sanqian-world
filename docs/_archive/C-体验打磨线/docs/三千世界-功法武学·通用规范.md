## 一、品阶体系（两世界通用）

功法/武学按价值分四品阶，**学习要求随品阶递进**（落实「根据价值而定」）：

| 品阶 | 主效果/级 | 学习要求带 | 获取渠道 | 定位 |
|---|---|---|---|---|
| 黄字阶 | 3~5% | 无要求 ~ 界位 1 + 无属性门槛 | 商店低价 / 初始 | 前期过渡与字段补齐 |
| 玄字阶 | 5~7% | 界位 1~2 + 属性 ≥12~18；邪派 恶名 ≤-100~-120 | 商店中价 / 低区首通 | 中期主力 |
| 地字阶 | 7~10% | 界位 3~4 + 属性 ≥24~30；邪派 恶名 ≤-180~-200 | 商店高价 / 中区首通 / 奇遇 | 后期核心 |
| 天字阶 | 9~14%（tribBonus/gateMod 类例外：0.015~0.025/级） | 界位 5~8 + 属性 ≥36~54；邪派 恶名 ≤-300~-500 | 高区首通 / 稀有奇遇 / 黑市高价 | 终局追求，渡劫清零后的长线重修目标 |

- **属性门槛 = 对应界位裸身基础值**（(界位索引+1)×6，详设 §4.4 规律）——养成玩家可提前一界学会，裸身玩家界位达标即学会，永不死锁；
- 阵营分布目标（每世界）：正 ≈19 / 中立 ≈18 / 邪 ≈14——邪派单部效果 ×1.5 但总数少、门槛深，维持「快但险」；
- **品阶带例外（校对批登记）**：聚灵诀（黄字阶）`qiCap +10%/级` 超黄阶 3~5% 带——qiCap 为低敏感乘区（只放宽挂机上限、不加速产出，见《精气神属性实现》§二），词条值维持定稿（功法全录与数值详设 §4.3 一致），登记为黄阶换算带例外；
- **数值预算（P5 审计修订版 · v2.2 独占重基线 · 校对批 Lv9 重校准）**：同乘区功法层**期望合计（典型双修 Lv3）≤ +80%**（实测最大 combatPower 78% ✓）；**极限 6 槽满级逐字段审计上限（修行状态批 v2.0：等级上限 0~9、满级 = 每级效果 ×9，按 top6 每级和 ×9 推导）**：combatPower +540% / qiRate +540% / offlineEff +450% / combatSpeed +351% / qiCap +315% / stonesRate +306% / artsSpeed +144% / eventLuck +153% / eventRate +117% / dropRate +81% / tribBonus +59% / realmCost −18%（实测极值 qiRate 531%、tribBonus 58.5% 向上取整，offlineEff 450% 恰顶格，其余为精确值；旧 Lv5 上限 300/300/250/195/175/170/80/85/65/45/33/−10 全部作废——原「极限 ≤+120%」与天字阶 9~14%/级 ×9 级 ×6 槽的数学上限矛盾，修订为逐字段审计值——超出即词条漂移，验收 #105 同口径）。**v2.2 历史注**：修仙 3 部天阶独占（斩三尸诀 qiRate 7%/级、太上忘情篇 qiRate 11%/级、红尘炼心录 offlineEff 8%/级）进 top6 池——独占获取受天级特殊奇遇「指定分支+判定链全过」门槛约束，且三部按 align 门槛互斥性极强，极限 build 达成成本进一步提高，不改节奏结论。**不入乘区审计的字段（校对批澄清）**：checkBonus（斩三尸诀 3%/级 → Lv9 27pp，由判定端三源合计 ≤+15pp 封顶兜底，#131）、attrBonusAmp（红尘炼心录 10%/级 → Lv9 90%，奇遇属性收益放大独立通道）、tribFailLossMod（太上忘情篇 **−8pp 固定值**，Lv1 全效不随级缩放——校对批裁定，登记进渡劫失败损失封顶清单，见数值详设 §4.5）。极限单字段 build 节奏（旧 Lv5 口径 ≈ ×3.75 产出 → 真仙 13.3d→约 8d，与魔道速通同带）为**历史值**——Lv9 下极限 qiRate 功法层 ≈ ×6.3，节奏天数待实施批 sim-pacing 重校准；**双书扩容批验算（2026-10-01）**：新增 6 部（§2.6，大衍诀 qiRate 9%/级 等）全部落在既有 top6 阈值之下或持平——qiRate 实测极限 531%→**540% 恰顶格**（上限不变），combatPower/combatSpeed/qiCap/offlineEff 及其余字段 top6 零漂移；且渡劫清零后 6 部满级单字段重修成本极高，作为长线极限目标可接受；**双书二批验算（2026-10-01）**：新增 10 部（功法全录 §2.7）各字段每级值均 ≤ 该字段现行 top6 第 6 位值（qiRate 8 / combatPower 7 / combatSpeed 5 / qiCap 4 / offlineEff 6，平替入位；程序化联合验算表见 §2.7）——#105 十二审计字段 top6 每级合计全部不变、上限表零漂移，qiRate 维持 540% 恰顶格；现行十二字段全部恰顶格、零余量，故不足 6 部的字段（stonesRate/artsSpeed/eventLuck/eventRate/dropRate/tribBonus/realmCost）本批一律不新入任何正值（龙泉锻剑录原方向 stonesRate 经主代理裁定改 offlineEff +6%/级，问心篇/圣心经按卡内备选取 offlineEff/qiRate）；新部主效果被第 6 位封顶产生的品阶带例外（星辰真经/圣心经天阶 8% < 9~14，昆吾镇魔章 4% / 问心篇 6% / 龙泉锻剑录 6% / 隐官诀主 5% < 地带下沿 7%）照 §2.7 自检行如实登记（聚灵诀品阶带例外同先例）；
