## 一、G2 主资源挂机（修为）

### 1.1 产出公式

```
每秒产出 = 境界基础产出 × (1 + Σ qiRate 加成) × 阵营修炼倍率 × buff 倍率
```

- **境界基础产出**：见 §六境界表 `baseQi` 列；
- **阵营修炼倍率**（善恶系统联动，v1.8 重做）：正道 `0.75` / 左道 `1.0` / 魔道 `1.5`，按当前 karma 区间实时取（karma 跨过分界线的瞬间切换，无缓冲）；阵营档位还联动战力/奇遇频率/掉落/判定等维度，全表见主设计文档 §6.3「三阵营状态效果」与本文档 §8.1 ALIGN_EFFECTS；
- **buff 倍率**：奇遇限时 buff 与 debuff 的乘积。

### 1.2 积累上限（qiCap）

```
修为上限 = max( baseQi × 7200 秒 , 下一阶突破 need × 1.15 ) × (1 + Σ qiCap 加成)
```

- 上限永远高于突破阈值 15%（复核修订：**旧式「纯 2 小时产出」会封死化神以后的所有突破**，见复核报告问题 1）；
- 渡劫到阈值即消耗（界面批三起默认**手动触发**，开 `settings.autoTrib` 自动渡劫开关后恢复自动掷判——**自动批 2026-10-02 起开关位于修行页底部「自动」区**，原设置页挂靠作废），因此该上限在正常游玩中几乎不可见——它的实际角色是 **真仙（无下一阶）后的溢出水槽** 与异常兜底；真仙后上限回落为 2 小时产出量，到顶显示「已臻化境」；
- `qiCap` 加成乘区（天赋/聚灵诀）作用于整个 max 结果。

### 1.3 离线结算

- **离线门槛 60 秒（v1.7 新增）**：本次结算间隔（`now − lastSave`）**< 60 秒时不进入离线规则**——该区间按在线口径全额推进（不打离线效率折、不吃 12h 上限、不跑批量渡劫循环、不产生离线收益汇总）。短切后台/秒回不触发「闭关结算」弹窗，避免收益面板被碎片化；`≥ 60 秒` 才走以下离线规则；
- **离线效率基准 50%**：离线期间按 `每秒产出 × (0.5 + Σ offlineEff 加成)` 计算；
- **离线时长上限 12 小时**：超出部分不计（未来可留「鸿蒙大世界云补偿」钩子，本期不做）；
- 离线期间每攒满一次突破阈值就在结算循环内掷一次渡劫（主文档 §7.5 已定，循环上限 64 轮）；**离线不触发奇遇**（v1.7 同步奇遇时钟机制，见奇遇池设计 §四）；
- 结算完成后写一条汇总日志：「闭关 X 小时 Y 分，得修为 N，渡劫 M 次（成 K 败 L）」；
- **离线收益汇总字段（v1.7 登记）**：每次离线结算（≥60s）同时写 `worlds.{id}.lastOffline = { at, secs, qi, stones, trib: { n, s, f } }`，供修行页离线收益面板与回线首次弹窗消费（UI 设计 §3.2）；旧存档缺省 `null`，面板与弹窗对 `null` 不渲染。

### 1.4 修为用途（资源水槽）

| 用途 | 出口 |
|---|---|
| 渡劫突破 | 攒满阈值后手动点「渡劫」掷判定（`settings.autoTrib` 开启则自动掷；主文档 §七） |
| 渡劫失败损耗 | 失败修为 ×0.5（受 tribFailLossMod 修正） |

### 1.6 游戏历（走查批 v2.3）

- **1 游戏日 = 现实 1 秒**，自入世（`profile.createdAt`）起算；12 月 × 30 日 = **360 日/年**，离线照常流逝；
- 起始年 `ws.calYear` 创角随机 1~9000（脏档 normalize 钳位、缺省 1 保幂等）；显示名 = 世界名去尾字（罗云州 → 「罗云历4321年7月8日」）；
- 视图换算不存累计值；修行页顶部常驻显示，日志页与奇遇叙事流时间戳均按游戏历渲染；
- 冷却类时长统一以游戏时间表述：势力叛离 = 1 游戏年、洞府迁居 = 1 游戏年（走查批 v2.8 统一口径）。

## 二、G3 战斗历练（秘境）

### 2.1 核心循环

```
选择秘境 → 按战斗速度持续击杀 → prog 0→100 → 通关：掉装备 + 解锁下一秘境
```

- **击杀节奏**：`每小时击杀数 = 60 × 战斗速度系数`，基准速度 1 次/60 秒（P4 勘误：原「1 次/10 秒」与本公式矛盾，以公式为准，验收 4.4 #31 同口径），受 `combatSpeed` 乘区修正；**战斗只随在线 tick 推进，离线期间不模拟秘境**（P4 登记决策：离线收益聚焦挂机修为，秘境刷取是在线玩法）；
- **单杀进度**：每次击杀 `prog +5`（20 杀通关），首通额外 `prog` 清零重计为可重复刷取模式（重复刷只掉装备/灵石，不再解锁）；
- **单杀收益**：灵石 = 秘境表 `stonesPerKill` × (1 + Σ stonesRate)；每次击杀掷掉落（见 §2.3）。

### 2.2 瓶颈机制

```
当前战力 < 秘境需求战力 → 击杀间隔 ×3，且 prog 封顶 90（无法通关）
```

- UI 在秘境入口显示红字「修为不足，举步维艰」，并给出建议（换装备 / 升功法 / 先渡劫）；
- **战力公式**：

```
战力 = (境界基础战力 + Σ 装备 atk) × (1 + Σ combatPower 加成) × (1 + Σ 功法战力加成)
```

### 2.3 掉落规则

- **单次击杀掉落率**：基准 `8% × (1 + Σ dropRate)`；
- **品阶权重**：按秘境索引查掉落表（§六），索引越高稀有度重心越靠上；
- **通关必掉**：prog 满 100 时必掉 1 件装备，品阶权重在常规基础上整体上浮一档；
- 掉落即进入 G4 自动择优流程，玩家无感知（只弹 toast：「拾得 玄铁剑（良品）→ 已替换 / 已炼化 +60 灵石」）。

### 2.4 秘境切换

- 同一时间只有一个「进行中秘境」；切换秘境不损失 prog（各秘境 prog 分别存档）；
- 已通关秘境可回访刷取（收益不变），未解锁秘境显示剪影 + 解锁条件。

## 三、G4 装备（法器）

### 3.1 槽位（4 槽）

| 槽位 | 修仙词表 | 主词条侧重 |
|---|---|---|
| weapon | 兵刃 | atk |
| treasure | 灵器 | qiBonus |
| armor | 甲衣 | atk / resist |
| accessory | 佩饰 | resist / qiBonus |

### 3.2 品阶（5 阶）与词条池

品阶从低到高：**凡品 → 良品 → 上品 → 灵品 → 仙品**。词条随品阶递进解锁（主文档 §7.6 已定）：

| 品阶 | atk | qiBonus | resist | 词条基础区间 |
|---|---|---|---|---|
| 凡品 | ✅ | — | — | atk 2~5 |
| 良品 | ✅ | ✅ | — | atk 4~8，qiBonus 3%~8% |
| 上品 | ✅ | ✅ | ✅ | atk 8~14，qiBonus 8%~15%，resist 40~80 |
| 灵品 | ✅ | ✅ | ✅ | atk 14~24，qiBonus 15%~25%，resist 80~150 |
| 仙品 | ✅ | ✅ | ✅ | atk 22~36，qiBonus 25%~40%，resist 150~260 |

> **缩放规则（复核修订，见复核报告问题 2/4）**：
> - `atk 实际值 = atk 基础区间随机 × max( P[掉落秘境解锁境界] / 100 , 1 )`——与境界基础战力指数挂钩（旧的线性 ×(1+索引×0.35) 跟不上境界 ×3 增长，会导致后期秘境数学上不可达）；
> - **qiBonus（百分比）不随秘境缩放**，固定区间——百分比若参与缩放，后期单件可破 130%，击穿乘区体系；
> - **resist 不随秘境缩放**，固定区间——它喂给有封顶的渡劫公式（满仙品 Σ≈1,040，resist 项 ≈0.17，永远拿不满 0.20 上限，留追求空间）；
> - **attrValue（属性亲和，第四词条）灵品起解锁**，不随秘境缩放：灵品 8~14 / 仙品 15~25，单属性随机（精/气/神），槽位亲和权重与判定机制见《角色属性设计》§3.3。词条解锁阶梯更新为：凡 1 / 良 2 / 上 3 / **灵·仙 4**。
> - **独占法器（v1.12 勘误）**：`exclusiveGear` 的 `atk` 按同规则缩放，但倍率在**获得时**以 `max( P[当前最高首通秘境解锁境界] / 100 , 1 )` 一次定格、此后不随新首通重定（防「压着晚拿」刷倍率）；qiBonus / resist / attrValue 仍为定值顶格不缩放。修复背景：定值 atk 36 对上后期缩放装（atk 数千~数万）会被自动择优瞬间顶掉，「顶级独占」名存实亡——配套豁免见 §3.4。

### 3.3 阵营（alignment）分布

- 掉落时掷阵营：**基础分布 左道 60% / 正道 25% / 魔道 15%**；
- **档位联动位移（v1.12 新增，ALIGN_EFFECTS `dropAlignW`）**：按当前 karma 档位实时取——正道光环档 = 左 50 / 正 38 / 魔 12；左道档 = 基础分布；魔道气息档 = 左 45 / 正 10 / **魔 45**。「同气相求」：档位越高越掉对应阵营装，魔道装词条 ×1.10 且每件 karma −15，构成魔道「质高而难回头」的掉落侧落点，与事件性质权重（35/65）同构；商店与事件 `dropGear{alignment}` 指定产出**不受**位移影响；
- 魔道装备词条数值 **×1.10**（补偿 karma 代价：每件 -15）；正道装备 ×1.00；左道 ×1.00；
- 商店与奇遇 `dropGear{alignment:'evil'}` 可定向产出魔道装备（如「魔道密使」事件）。

### 3.4 评分与自动择优

```
评分 score = ( atk + qiBonus×100 + resist×0.5 + attrValue×3 ) × 特殊词条系数
特殊词条系数 = 带 special 时 1.15，否则 1.0（特殊词条价值 ≈ 半条主词条，P5 复核）
```

（score 仅用于自动择优的 **同槽比较**，不再参与经济结算——见下方炼化修订）

- **要求前置检查**：拾取/购买装备先过佩戴要求（§3.5）——不满足者**不参与择优比较**，直接入库藏阁（见下）；
- **自动替换**：满足要求的新装备 score > 当前槽位 score → 自动装备，旧件自动炼化；
- **独占法器择优豁免（v1.12）**：独占法器（诛邪剑残/照世镜）**不参与自动替换比较**——穿上后只有手动操作能取下；随机新件 score 更高时不自动顶换，改 toast「拾得 仙品·XX——当前佩戴『诛邪剑残』为独占法器，是否手动替换？」+ CONFIRM（旧独占件入库藏阁，豁免溢出炼化）；
- **库藏阁（stash）**：不满足要求的装备自动入库暂存，**动态容量 12→15**（随境界/挂点解锁，融合批 F5；冒烟 #133/#134，工程规范 #98 同口径）；每次境界提升后自动复检，达标即参与择优；库满时自动炼化其中 score 最低者（写日志）；
- **自动炼化（复核修订，见复核报告问题 3）**：返还为 **品阶固定表 × (1 + 境界索引 × 0.5)**：

| 品阶 | 凡品 | 良品 | 上品 | 灵品 | 仙品 |
|---|---|---|---|---|---|
| 返还基数（灵石） | 5 | 20 | 100 | 500 | 2,500 |

  旧的 `score × 品阶系数` 公式会让后期单件炼化返还 ≈ 1 小时刷图收入（掉落 ~29 件/小时 → 通胀 20 倍），已废弃；
- 无手动锁定功能（本期不做，保持全自动的省心定位）；
- 每次替换/炼化/入库写日志，玩家可在日志栏回溯。

### 3.5 佩戴要求（按价值而定）

装备要求 = **品阶基础境界** + **极品词条追加**，两层叠加：

| 品阶 | 基础佩戴境界 |
|---|---|
| 凡品 / 良品 | 无要求 |
| 上品 | 金丹（境界 2） |
| 灵品 | 化神（境界 4） |
| 仙品 | 合体（境界 6） |

- **极品词条追加（神兵认主）**：`resist` 或 `attrValue` roll 到区间 **前 10%** 的高价值装备，佩戴境界 **+1 阶**——价值越高要求越高；
- 特殊词条**不**追加要求（避免与「无视佩戴要求」词条自我矛盾）；
- 未达标装备在 UI 显示红字要求（「需境界：化神」），入库藏阁等待；
- **设计意图**：低境界刷到仙品不再是「即刻战力」而是「存起来的盼头」，给秘境刷取加一条长线钩子；同时压住前期跳级配装对瓶颈机制（§2.2）的击穿。

### 3.6 装备特殊词条（special，随机低概率）

上品及以上装备掉落/购买时掷一次特殊词条：

| 品阶 | 附带概率 |
|---|---|
| 凡品 / 良品 | 0%（不携带） |
| 上品 | 3% |
| 灵品 | 8% |
| 仙品 | 15% |

每件至多 1 条特殊词条，从下池等权抽取（「无视佩戴要求」权重略高——它只对本就有要求的装备生效，实际有效率低）：

| id | 名称 | 效果 | 权重 |
|---|---|---|---|
| `ignore_req` | **无视佩戴要求** | 该装备的佩戴要求（含极品追加）全部无效，拾取即可择优佩戴 | 12 |
| `sword_heart` | 剑魄 | combatPower +8% | 9 |
| `spirit_rune` | 聚灵纹 | qiRate +8% | 9 |
| `adamantine` | 金刚质 | resist +60（加在词条之上） | 9 |
| `swift_shadow` | 疾影 | combatSpeed +10% | 9 |
| `merchant_wit` | 商慧 | shopCost -8% | 9 |
| `karma_mirror` | 照业镜 | eventLuck +12% | 9 |
| `dao_oath` | 道侣之约 | offlineEff +12% | 9 |
| `thunder_mark` | 雷纹 | tribBonus +0.05 | 8 |
| `devour` | 噬灵 | 击杀灵石 +12% | 8 |

- 特殊词条效果进入对应乘区（§八总表登记为「装备特殊词条」来源），数值幅度 ≈ 半条主词条——**低概率补偿高价值**；
- 带特殊词条的装备在 UI 上加暗金角标 + 词条名，炼化/替换日志中注明（防玩家没看见好东西被自动炼化——入库藏阁与炼化日志必须带 special 标记）；
- 存档结构：装备 item 字段为 `{ slot, name, alignment, tier, atk, qiBonus?, resist?, attrValue?, reqs, special, source }`，其中 `reqs: { realm }`、`special: string|null` 与 `source`（获得溯源 `{type:'zone'|'event'|'shop'|'exclusive', ref}`，v1.12 新增，旧档 null 不回填）在生成时定格；功法 item 为 `{ id, name, alignment, attr, reqs, special }`，`reqs: { realm?, attr?: {id, min}, karmaMax? }`、`special` 固定（工程规范存档字段总表同步登记）。

### 3.7 百器录（法器图鉴 · v1.12 新增 · 财柱收集维度）

- **入录范围**：① 特殊词条法器——获得即按 `special` 词条 id 入录（10 词条，同词条不重复计数）；② 独占法器——按法器 id 入录（2 件）；
- **炼化/替换不除名**：一经入录永久保留（存档 `worlds.{id}.gearSeen = { key: 首获ts }`，与 `eventHistory.seen` 同纪律）；
- **纯荣誉零数值加成**（防通胀红线）；UI 入口 = 法器页顶「百器录」，格子组件复用奇遇图鉴（未入录 = 「？」+ 品阶色剪影，已入录 = 词条名 + 首获时间 + 来源）；
- 设计意图：四柱落地后功法（70 部）/ 奇遇（113 格）/ 洞府（6 处）/ 道友（58 人）皆有收集线（双书梗化二批 v1.22 计数口径；洞府 6 处本批不动），唯法器是纯消耗品（拾得→替换→炼化）——百器录补上「器」的留存感，与财柱总账（流水统计）一荣誉一流水，互补不重叠。
- **v1.18 注**：本法器图鉴（`SQ.Gear.codex` · 浮层 `#modal-gearcodex`）与 **G15 法宝图鉴**（`SQ.Treasures.codex` · 法宝页内嵌节，见 §十）是两套独立图鉴，勿混。

## 四、G5 技能（功法）

### 4.1 结构

- **6 个修习槽位** + **待修习架（shelf，容量 24**——功法全录扩容（54→60 部时由 12 上调；现行 70 部，含双书梗化二批 §2.7，容量维持 24 不动），容纳收集玩法**）**；
- 功法可自由装入/移出槽位（无冷却无成本），只有槽内功法生效；
- 功法等级 **渡劫成功后全部清零**（槽位与持有关系保留）——境界重置带来的重修循环，是长线目标感来源；
- **（修行状态批 v2.0）等级上限 0~9**（原 0~5）；每级效果随等级线性放大（×lv），Lv9 = 每级效果 ×9；
- **（修行状态批 v2.0）练习度（artsPractice）**：每部功法独立 0~100，仅**槽内已入门且未满级**者在线 tick 增长（离线不涨）；主修（槽位第 1 位）+25/h、其余 5 槽 +10/h，× (1+ΣartsSpeed) × 模式 practiceMult（闭关 1.5 / 历练 0.5）；满值 → **顿悟**（Lv+1 并清零重来）。

### 4.5 功法固定特殊属性（special，每部一条）

> 特殊属性已扩展为**共享池（15 条 × 弱/标准/强三档参数）**，两世界词表换名共用，全表见《功法武学·通用规范》§三；下表 12 条为核心部签名定稿。核心部允许专属签名效果，扩容批 39 部必须选自共享池（挂点白名单驱动，工程可控）。

与装备的随机低概率不同，**每部功法固定携带一条专属特殊属性**——它是该功法的「签名效果」，走引擎标准挂点（世界包声明，引擎按挂点调用；挂点白名单见工程规范）。特殊属性随功法等级**只解锁不缩放**（Lv1 即全效，避免与主效果乘区双重成长）：

| id | 名称 | 特殊属性 | 效果 |
|---|---|---|---|

### 10.1 结构

- **全录 30 件**：**先天 12 件**（`x01~x12`，全局唯一，**认主**成长 `MAX_STAGE 3`，认主随渡劫成功推进——每 n 次渡劫 +1 阶）/ **后天 18 件**（`h01~h18`，**祭炼**成长 `MAX_LV 5`，耗资源升阶、三成机率失败降级）；**双书梗化扩容批 +6（先天 3 / 后天 3 → 先天 15 / 后天 21 = 36 件，见 §10.6）**；**双书梗化二批 +10（先天 4 / 后天 6 → 先天 19 / 后天 27 = 46 件，见 §10.7）**；

### 11.7 势力冲突与门中供给（势力深化批 v1.23 · 正典《势力全录（16处）》§五/§六）

## 十二、G17 江湖传闻（江湖传闻批 v1.0 · 正典《三千世界-江湖传闻系统设计.md》）

### 12.1 机制摘要

- 在线按现实分钟节奏刷新的**限时传闻卡**（`rumorClock` 每跨 `REFRESH_MIN=10` 分钟掷一批 `BATCH=[1,2]` 条，活跃上限 `MAX=4`），指向当前角色**可触发**的事件（抽取复用 `natureDraw` + 阵营 `tierW` + `buildPool` 全过滤 + 天→地→人降级回退，再滤活跃卡已指向 evId）；
- TTL 按品阶：人 40 / 地 70 / 天 110 现实分钟；**离线只过期不刷新**（绝对时间戳判定，与「离线零奇遇」正典对齐；回归聚合日志「江湖事过境迁」）；
- **触发** = 主动点击「前往查证」：校验链（未过期 / pendingChoice 空 / condOk 复核 / 非 once 已见 / 非冷却中）→ 落地五件套照抄 fire（冷却/lastId/seen/pendingChoice，`via:'rumor'`）——**不清 eventClock、不消耗 eventShield**（独立通道）；抉择模态、判定 DSL、resolveBranch、图鉴、feed 全链路与随机奇遇零差异；
- **过期** = 未触发即作废：once/冷却/seen 均未消耗，事件可再次出现；在线静默移除、离线回归聚合日志；
- **war 卡**：势力冲突开战推送 `{kind:'war'}` 传闻（TTL = 冲突剩余时长，不占 MAX 名额），**交战方**卡内「应战」按钮点击跳势力页/应战 CONFIRM，**非交战方只读「观望」无按钮**（走查修复批 2026-10-02，§11.7 联动）；
- 文案：common 词表 `rumor.tpl.{tier}.1~10` 模板 × `rumor.place.1~8` 地点池（生成时掷定入档 `tpl/place`，不剧透事件名；世界分卷可覆写）。

### 12.2 常量与存档

```
RUMORS: { MAX: 4, REFRESH_MIN: 10, BATCH: [1,2], TTL: { ren: 40, di: 70, tian: 110 }, TPL_PER_TIER: 10, PLACES: 8 }
worlds.{id}.rumors = [{rid, evId, tier, nature, bornAt, expireAt, tpl, place} | {rid, kind:'war', bornAt, expireAt}]
worlds.{id}.rumorClock = 0    // 在线累计秒；normalize：结构校验 + 过期/未知 evId 丢弃
```

### 12.3 红线

- 经济零新增：只改事件触达方式，不改任何事件收益（双锚缩放与事件池 §十三勘误全沿用）；
- 通道公平：与随机通道同一套 once/冷却/seen/独占判定链语义；
- 引擎 `rumors.js` 零裸中文（CJK 纪律 A1 同口径）；#161 冒烟段预登记。
