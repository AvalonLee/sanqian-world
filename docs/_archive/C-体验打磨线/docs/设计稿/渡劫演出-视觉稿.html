帧三批注
  • 失败三要素齐展示：红闪（1.4s 循环）+ 震屏（0.5s ×2 次后静止）+ 损失明细行（500万 → 250万，−50% 基准；若带不动明王/神修正则逐行列出「基准 50% − 不动明王 5pp = 45%」，总损失 clamp 30~70%）；
  • 成算复盘行是失败帧的教育位：让玩家看见 karmaMod −0.12 与「无护法」各值多少——魔道「快而险」的险，每败一次都具象一次；
  • 独行文案「雷云之下，唯你一人」= 魔道档位护法位失效的叙事化（数值详设 §8.1 / 引擎卷 §3.3）；正道/左道失败帧此行显示护法叙事（护法在场仍可能失败，p 不是保票）；
  • 无冷却字段：半损后自然低于阈值，攒气时间即冷却（#53）；离线批量渡劫不逐次演出——结果进闭关所得面板「渡劫 4 次（成 2 败 2）」，演出只属于在线的每一道雷。
