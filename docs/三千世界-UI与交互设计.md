## 一、Surface 与状态机

扩展有四个 surface（manifest `surfaces: ["module", "view", "window", "drawer"]`；`openIn: ["view", "window", "drawer"]`）：

| Surface | 用途 | 尺寸约定（x-hub 平台规范） |
|---|---|---|
| module | 宿主工作台常驻摘要卡 | 工作台**网格格子**，三形态 `standard / compact / wide`（同一 `module/index.html` 用 `:root[data-xhub-variant]` 分支）；视口=卡片内容区，**最矮可到 ~86px**，禁止假设固定像素尺寸、禁止写死 min-height；宿主已给卡片套玻璃底，页面保持透明 |
| view | 完整游戏界面 | 主工作区整页，移动端竖屏优先自适应 |
| window | 独立窗口形态 | **复用 `./view/index.html`** 同一入口；三种运行形态经 `xhub.storage` 共享同一份存档，切换形态不丢进度 |
| drawer | 侧边抽屉形态 | 同上，复用 `./view/index.html` |

> **响应式布局（工程约定）**：窄屏 `<720px` 单列（顶栏 / 内容 / 底部 Tab 导航）；宽屏 `≥720px` 两列（264px 固定左栏 = 角色摘要 + 竖向 Tab 导航，右栏内容区居中限宽 980px）。`minSize` 声明 `380×620`。

### view 状态机

```
LOADING（boot 模式：await 读档 + normalize 完成后才首绘——宿主存储是异步桥，禁止顶层同步读）
   │
   ├─ 无存档 ──► CREATION_1 起名 ──► CREATION_2 天赋+问道初心 ──► CREATION_3 选世界 ──► MAIN
   │                                      ▲______重抽（无限次，不清倾向）______│
   └─ 有存档 ──► MAIN
```

MAIN 之上可叠加的模态层（优先级从高到低，同屏只出一个，其余排队）：

| 优先级 | 模态 | 触发与关闭 |
|---|---|---|
| 1 | **EVENT_CHOICE** 三分支奇遇抉择 | 在线奇遇时钟命中即弹；**必须选择才关闭**（无倒计时、不自动选、点遮罩不关）；跨离线保留（pendingChoice 回线恢复） |
| 2 | **OFFLINE_REPORT** 闭关所得汇总 | ≥60s 离线结算后、本次 view session 首次进修行页弹出；手动关闭；与 EVENT_CHOICE 冲突时顺延 |
| 3 | **TRIBULATION_RESULT** 渡劫结果全屏演出 | 渡劫掷判后；2 秒自动关闭或点击关闭 |
| 4 | **CONFIRM** 通用二次确认 | 锁定天赋 / 炼化提示 / 提亲 / 洞府入驻付费 / 购买最终价等 |

- 事件类 **toast 通道已废止**（所有奇遇进抉择模态）；toast 仅保留给非事件消息，通道清单见 §五；
- 创角三屏之间可**回退**（返回上一屏修改），但未点最终「入世」前不写存档；
- 「入世」（CREATION_3 确认按钮）一次性写入 profile（含 alignBias 与预留的 gender/race 默认值）+ 初始化 worlds[worldId] + 生成 worldName，随后直接进 MAIN，无过场加载。

## 二、创角三屏细则

### 屏 1 · 起名

| 元素 | 规则 |
|---|---|
| 标题 | 「道名初定」 |
| 输入框 | 1 个，占位符「请输入角色名」 |

### 屏 2 · 天赋 + 问道初心

布局与规则以《天赋池设计文档 §七》为准，此处为屏幕级结构：

```
┌────────────────────────────┐
│  天命所赋（2 正 1 负）        │ ← 组合类型角标
│ ┌──────┐ ┌──────┐ ┌──────┐ │
│ │ 正面卡 │ │ 正面卡 │ │ 负面卡 │ │ ← 稀有词条加描边角标
│ └──────┘ └──────┘ └──────┘ │
│                            │
│  问道初心（阵营倾向 · 可不选） │
│  ( 正道 ) ( 左道 ) ( 魔道 )  │ ← 三段选择，默认左道居中
│  「此生道心，偏向何处？」      │
│                            │
│  [重抽天命]      [确认锁定]   │
└────────────────────────────┘
```

- 「确认锁定」触发 CONFIRM 模态：「天赋确认后此生不可更改，是否入定？」；
- 单正单负组合时正面卡追加「极致单一 · 效果增强」角标（解释 ×1.5）；
- **阵营倾向**：三段选择写入 `profile.alignBias`（right/neutral/evil，默认 neutral），与天赋一起「确认锁定」后不可更改；三段各配一行小字说明（正道「逢源多奇遇，修行缓」/ 左道「不偏不倚，随心而行」/ 魔道「进境迅猛，福缘薄」）；重抽天赋不影响已选倾向；倾向只驱动 karma 缓慢漂移（12/天，封顶 ±260），**不锁定玩法**——后续行为随时可覆盖；
- **性别/种族预留**：本期创角三屏**不提供**性别与种族选择入口（不做置灰占位，避免「即将开放」的预期管理负担）；存档预留 `profile.gender='male'`（默认男性）/ `profile.race='human'`（默认人族），normalize 补默认，未来版本开放后启用；结缘双修不限性别，开放女性玩家后自动兼容。

## 六、文案与数字格式规范

- **数字缩写**：< 10,000 原样千分位；≥ 10,000 用「万」（12.3万）；≥ 1 亿用「亿」（4.0亿）；百分比保留 1 位小数；
- **时间**：倒计时「X时Y分」；补货/冷却 < 1 小时显示「X 分钟」；洞府迁居冷却以游戏历显示（「X 游戏年 X 游戏日」；1 游戏年 = 360 游戏日 = 360 现实秒，走查批 v2.8）；
- **文案基调**：修仙世界半文半白短句（「天雷落下」「速速收功」），系统级提示用白话（「确认后不可更改」）——两类都走词表层；
- **禁语**：不出现「服务器/数据/概率UP」等出戏词；概率表达用「十之七八」「渺茫」+ 精确数字并列（「成功率 76%」）；
- **双修文案红线**：一律写意留白（灯灭帷幕落级别），无任何亲密描写；炉鼎形态的黑暗感只靠代价机制与「失去」叙事表达（词表正典见道友池卷 §三（原四柱框架卷 §5.4））。

## 七、可访问性与适配

- 最小适配宽度 320px；顶栏与底部 Tab 固定，内容区滚动；
- 品阶/阵营/等级不用纯色传达（色弱友好）：品阶配文字角标（凡/良/上/灵/仙），阵营配符号（正 ☯ / 魔 ☠ / 左 ·），奇遇等级配文字徽标（天/地/人），性质配图标（机缘☀/危机☾）；
- 所有可点区域 ≥ 44×44px；重抽/炼化/分支按钮等高频操作放拇指热区（屏幕下半）；
- 动效可被系统「减弱动态效果」降级为瞬时切换（prefers-reduced-motion）；
- **桥调用容错**：所有 `xhub.*` 调用包 try/catch，被拒或失败时界面显示人话提示（错误码 + 说明），不允许白屏。

## 八、视觉基调与宿主主题规范（x-hub 平台铁律）

> 原「深底水墨」方案与平台铁律冲突（页面永远不铺不透明底），修订为「宿主主题打底 + 水墨语义强调」方案。

### 8.1 主题归属

- **深浅色归宿主管**：宿主在 `<html>` 维护 `data-xhub-theme="light|dark"`，扩展**不做自己的主题切换按钮**；
- **页面底**：`body { background: var(--xhub-page-bg, transparent) }`；
- **内容表面**：面板/卡片/弹层底一律 `var(--xhub-surface)` 玻璃令牌；按钮/输入区「井」底用 `var(--xhub-bg-card)`；
- **壁纸透底态**（`data-xhub-wallpaper-clear="1"`）：面板去白描边、只留中性落影，文字加一档黑柔光晕；
- **所有颜色写成 `var(--xhub-*, fallback)`** + 「双声明 fallback」：`:root` 浅色兜底 + `:root[data-xhub-theme="dark"]` 深色兜底。

### 8.2 水墨 × 暗金的游戏语义层

游戏自有 design token 映射宿主变量，仅作**小面积语义强调**，绝不当页面底色：

| 游戏 token | 映射宿主变量 | 用途 |
|---|---|---|
| `--sq-primary` | `var(--xhub-accent, 暗金兜底)` | CTA、境界名、稀有高亮 |
| `--sq-brand` | `var(--xhub-brand-soft, …)` | 标题区弱底、正道徽标底 |
| `--sq-karma-right` | `var(--xhub-yellow, 金)` | 正道光环、正道分支按钮 ☯ |
| `--sq-karma-evil` | `var(--xhub-red, 暗红)` | 魔道气息、魔道分支按钮 ☠、炉鼎采补形态色 |
| `--sq-karma-neutral` | `var(--xhub-text-3, 青灰)` | 左道、左道分支按钮 ·、互助双修形态色 |
| `--sq-tier-tian` | 暗金（`--sq-primary` 同族，压亮） | 天级奇遇：叙事流卡边 / 图鉴格底 |
| `--sq-tier-di` | 赭石（自定义 token，双声明） | 地级奇遇 |
| `--sq-tier-ren` | 黛青（`--xhub-text-3` 同族） | 人级奇遇 |
| 品阶色（凡/良/上/灵/仙） | 自定义 token，双声明（灰白/青绿/靛蓝/紫/金，压暗饱和度） | 法器词条、掉落 toast |
| `--sq-success` / `--sq-danger` | `var(--xhub-green)` / `var(--xhub-red)` | 渡劫成败演出、正负天赋卡、阴阳双修形态色（success 族） |

- 水墨氛围靠**字重/字距/留白/内联 SVG 纹样/文案**表达，不靠自绘深色底；
- 强调色实底上的文字**按主题显式给**（亮色主题 accent 深 → 白字；暗色主题 accent 浅 → 深字）；
- 字体：系统字体栈（`system-ui, "Songti SC", SimSun, serif` 兜底链营造书卷气），**不引入外部字体、零 CDN**；
- icon.svg：一柄剑横贯「三」字，`stroke="currentColor"` 单色描边（随宿主主题自适应）。
