## 一、问题清单

### 🔴 问题 1（致命）：修为上限封死中后期全部突破

- **现象**：`qiCap = 2 小时产出`，而境界 4（化神）起「下一阶 need」超过上限本身：
  - 化神：上限 583,200 < 需求 600,000 ❌
  - 合体：上限 5,184,000 < 需求 15,000,000 ❌
  - 渡劫：上限 45,360,000 < 需求 400,000,000 ❌
- **影响**：玩家从化神开始 **永远无法突破**，游戏在中期硬性死亡。叠满全部 qiCap 加成（天赋 25% + 聚灵诀 50% = ×1.75）后，合体/大乘/渡劫三阶依然封死。
- **修订**：上限公式改为 **`qiCap = max(baseQi × 7200, 下一阶 need × 1.15)`** ——上限永远高于突破阈值 15%，「回来收功」的钩子保留，但不阻断进度。真仙（无下一阶）后上限回落为纯 2 小时产出，作为「已臻化境」的溢出水槽。
- **连带发现**：由于渡劫到阈值即消耗（界面批三起默认手动触发、开 `settings.autoTrib` 后自动掷判），旧上限在正常游玩中几乎不可见——修订后上限的实际角色就是「真仙溢出保护 + 异常兜底」，UI 的「已臻化境」提示只在真仙后出现。

### 🔴 问题 2（致命）：秘境需求战力自相矛盾且中后期不可达

- **现象**：文档声称「每区需求 ≈ 对应境界基础战力的 1.3~1.6 倍」，但原表实际比值是 **1.5 → 3.9 倍** 且单调恶化；同时装备 atk 采用线性缩放（×(1+秘境索引×0.35)），跟不上境界基础战力的 ×3 指数增长。
- **证明**：大乘境界（基础战力 42,000）解锁天渊龙墟（需求 160,000 = 3.8 倍）；秘境 6 掉落的满配仙品 4 件 atk 合计仅 ≈ 22,000，叠满功法/天赋乘区后战力 ≈ 90,000，**不到需求的 60%**——后期秘境在数学上永久卡死。
- **修订**（三处联动）：
  1. 秘境需求战力统一改为 **`1.5 × 解锁境界基础战力`**（回到文档声称的设计意图）：30 / 90 / 270 / 810 / 2,400 / 7,200 / 21,000 / 63,000；
  2. 装备 atk 缩放改为 **与境界基础战力挂钩**：`atk = 品阶基础区间 × max(P[掉落秘境解锁境界] / 100, 1)`，品阶基础区间：凡 2~5 / 良 4~8 / 上 8~14 / 灵 14~24 / 仙 22~36；
  3. **qiBonus（百分比词条）不参与秘境缩放**——原「词条数值 ×(1+索引×0.35)」规则若作用到百分比上，后期单件装备 qiBonus 可达 130%+，会击穿乘区体系；百分比词条固定区间，只有 atk（绝对值）随秘境缩放。
- **修订后验证**：各境界「上品套 ≈ 压线触发瓶颈、灵品套稳过、仙品套余裕」，瓶颈机制（G3 的设计意图）恰好生效：

| 境界 | 秘境需求 | 上品套战力 | 仙品套战力 | 结果 |
|---|---|---|---|---|
| 元婴 | 810 | 805（压线，需天赋/功法补足） | 973 ✓ | 瓶颈有压力、可解 |
| 合体 | 21,000 | 20,946（压线） | 25,438 ✓ | 同上 |
| 大乘 | 63,000 | 62,608（压线） | 75,712 ✓ | 同上 |

### 🔴 问题 3（致命）：炼化返还经济崩坏

- **现象**：`炼化返还 = score × 品阶系数`，而 score 随 atk 缩放增长。后期仙品 score ≈ 6,000+ → 单件返还 72 万灵石，**恰好等于一小时刷图收入**；掉落率 8% × 360 杀/小时 ≈ 29 件/小时 → 炼化收入是刷图的 ~20 倍，灵石体系瞬间通胀，商店/功法/刷新费全部水槽失效。
- **修订**：炼化返还改为 **品阶固定表 × (1 + 境界索引 × 0.5)**：凡 5 / 良 20 / 上 100 / 灵 500 / 仙 2,500。score 公式保留，仅用于自动择优比较。
- **修订后验证**：仙品炼化返还从早期「139 分钟收入」（惊喜大奖）平滑衰减到后期「0.2 分钟收入」（垃圾回收），炼化重新成为辅助收入而非主收入；对照商店仙品售价（55,200 @真仙），炼化返还 ≈ 售价 25%，「刷图炼化 < 直接购买」的价值梯度成立。

### 🟠 问题 4（高危）：resistBonus 公式中期自封顶，resist 词条失效

- **现象**：原式 `min((Σ装备resist + 战力/50) / 1000, 0.35)` 中，战力随境界 ×3 增长——化神境界裸战力 1,600/50 = 32，加上任意装备即逼近 350 封顶值；合体起 **不带任何 resist 装备也已封顶**。渡劫抗性作为装备第三词条的身份（决策 8）从中期开始形同虚设。
- **修订**：拆成两项、各自封顶（保留「战力 + 法器抗性」双来源的既定决策）：

```
resist项 = min( Σ装备resist / 1200, 0.20 )
战力项   = min( (战力 / 当前境界基础战力 - 1) × 0.15, 0.15 )
resistBonus = resist项 + 战力项        （理论上限 0.35，与原封顶一致）
```

  - 战力项的含义改为「**配装富余度**」：裸境界 = 0，装备/功法把战力堆到境界基础值的 2 倍才拿满 0.15——不再随境界水涨船高；
  - resist 区间同步上调（不随秘境缩放）：上品 40~80 / 灵品 80~150 / 仙品 150~260，满仙品 Σ≈1,040 → resist 项 ≈ 0.17，**永远拿不满**，留追求空间。
- **修订后验证**：resistBonus 全程 0.10~0.32 渐进增长，渡劫成功率 p 的四项来源（base/resist/天赋/karma）在终局分别贡献 0.45/0.32/0.15/0.20，任何一项都不冗余。

### 🟠 问题 5（高危）：「真仙是月级目标」宣称失实

- **现象**：按原 need 表模拟，典型玩家（×2.25 产出）**1.9 天**即可从练气推到真仙，裸身也只要 3.5 天——终局目标一周末就通关，长线放置游戏没有支撑。
- **修订**：need 曲线后期抬升（前 6 阶不变，保留新手流畅期；合体起加陡）：

| 突破 | 原 need | 修订 need |
|---|---|---|
| →合体 | 3,000,000 | **5,000,000** |
| →大乘 | 15,000,000 | **60,000,000** |
| →渡劫 | 75,000,000 | **500,000,000** |
| →真仙 | 400,000,000 | **4,000,000,000** |

- **修订后基准**（详见 §二）：裸身 35.6 天 / 典型 13.3 天 / 魔道速通 8.4 天 / 毕业正道 10.5 天——「真仙 = 月级（裸身）/ 双周级（典型）」宣称成立，且魔道「快但险」、正道「稳」的阵营节奏差（8.4 vs 10.5 天）在终局曲线上依然可感知。

### 🟡 问题 6（低）：两处次要不一致

1. **秘境只有 8 区、境界有 10 阶**：渡劫/真仙两阶无新秘境可解锁，终局玩家只能重复刷天渊龙墟。**修订**：补 2 区——混沌雷海（渡劫解锁，需求 187,500，灵石 5,000/杀）、界外古道（真仙解锁，需求 562,500，灵石 15,000/杀），掉落权重整体再上浮；
2. **奇遇事件灵石「按境界缩放」未定义系数**：早期 80~200 灵石是 10 分钟收入、真仙期不足 0.1 分钟，事件的经济存在感断层。**修订**：统一规则「事件灵石绝对值 × (1 + 境界索引)³」，并明确后期事件的核心价值是 buff/karma 而非灵石。

## 五、遗留调参项（P5 实机复查，不阻塞开工）

1. 合体→大乘 need ×4 陡增墙的体验：若测试期玩家流失集中在此，优先降 need（60M→40M）而不是提产出；
2. 上品套「压线瓶颈」依赖功法金钟罩满级——若玩家跳过功法直接推图，卡关时长会超预期，观察瓶颈提示浮层的转化率；
3. 魔道速通 8.4 天 vs 毕业正道 10.5 天：差距 20% 是否足以构成「险的代价」，还是应该让魔道 karma 恶化更快（-0.25 档更容易触达）；
4. ~~事件灵石 ×(1+境界)³ 在真仙期 ≈ 1~2 分钟收入，若显得鸡肋可上调至四次方~~ **（代码批 1 实测推翻）**：该估算基于「日均 2~3 条」的旧密度；v1.5 在线时钟把密度抬到 ≈6.5 条/小时后，三次方锚与刷图曲线不同源，境界 2~6 的「奇遇/刷图」灵石比实测 1000~2600%，事件成了灵石的主要来源而非风味。已改双锚（灵石挂刷图曲线 `max(1, 0.075×ZONES[境界].stones)`、修为保留三次方），比值收敛到 28~397% 且与境界无关；详见事件池 §十三.8；
5. zone8/9 的灵石/杀（5,000/15,000）使终局刷图收入达 540 万/小时，数字膨胀的显示格式（「万/亿」）需在 UI 层压测。
