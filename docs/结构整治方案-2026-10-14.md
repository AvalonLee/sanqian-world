## 三、装置设计

### 3.1 单一账本

`docs/ledger.json`（ASCII 名，与 FACTS/VERSIONS 同目录同族）。每条记录四字段：

```json
{ "smoke_asserts": { "value": 300, "src": "run-smoke:SMOKE_ALL_GREEN", "copies": ["docs/FACTS.md", "docs/三千世界-UI与交互设计.md"], "gen": true } }
```

- `value` — 现算值，**只有取数函数能写，人不许手改**
- `src` — 取数出口（件名:标记），即"读数由出厂探针自己打印"的落地形态
- `copies` — 该值当前被引用进哪些文件的哪些哨兵段
- `gen` — 是否参与文档生成（`false` = 只入账不刷文档）

### 3.2 哨兵段

```
<!-- SQ:LEDGER:BEGIN 现行读数由 .tests/gen-ledger.cjs 生成，手改即漂；段外散文一律不参与覆盖 -->
| 冒烟断言 | 300 | .tests/run-smoke.cjs |
<!-- SQ:LEDGER:END -->
```

- 段内 = 生成器唯一可写区；**段外一字不动**（这是"历史注不改写"的机械保证）。
- `.js` / `.cjs` 内用 `/* SQ:LEDGER:BEGIN ... */` 同型标记。
- 覆盖文件（首批）：`docs/FACTS.md`、`DESIGN.md`、`README.md`、`docs/三千世界-工程规范与验收计划.md`、`docs/三千世界-项目设计文档.md`。`manifest.json` 无注释位，作**事实源**而非生成目标。

### 3.3 生成器 `.tests/gen-ledger.cjs`

```
node .tests/gen-ledger.cjs          只对账 → 末行 LEDGER_IN_SYNC n / LEDGER_DRIFT m（漂 ⇒ 退码 1）
node .tests/gen-ledger.cjs --fix    取数 → 写 ledger.json → 刷哨兵段 → 复跑自检
```

纪律：按原文行尾写回（照 `versions-check.cjs:101-106` 的 eol 保护，Windows 上否则会出现"只改 12 格却整文件逐行 diff"）；取数函数返回空/异常一律判红，不许拿空值刷文档。
