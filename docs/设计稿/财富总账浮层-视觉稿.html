稿一批注（UI v2.3 §3.3 / 引擎卷 §4.1 / 工程规范 §3.2）
  • 对账恒等式置顶：启动资金 100 + Σin − Σout = 当前余额，逐笔可验——冒烟 #113「万次随机操作零漂移」的可视化前端；
  • 收入四类 / 支出四类 = ledger 契约全量（v2.5 清理后无占位空类）；每行小字标注字段名与口径，数值透明纪律与产出明细浮层同源；
  • 条形按各区内最大值归一（非跨区对比）；占比小字给「钱从哪来、往哪去」的结构感——击杀 74% 印证「刷图是主收入」的经济设计；
  • 只增不清、跨渡劫不归零（与 karmaEventScore 同纪律）——「装备可以换，花过的钱赖不掉」的财柱表达；
  • 结语 + 印章为词表文案（`ui.ledger.epitaph`），印章按净值分档换文案（负债态/小康态/巨富态各一句，实施批 2 时定稿三档文案）。
