## 〇、三条裁定（用户 2026-10-16 选定，本稿按此展开）

1. **四榜叫「榜」**：天榜 / 地榜 / 玄榜 / 黄榜（不用「券」）；功法品阶那排 chip **不动**，只在页内加一行副标说明它筛的是功法品阶、不是榜单。
2. **天榜前三的隐世高手完全不可交互**：不给切磋、不给袭杀入口，榜面也不给任何可点态。
3. **玩家自己入对应那一榜并高亮**（不另开「我方之势」行）。

## 一、角色库（200 名）放哪儿

- **名录 = 静态内容表，绝不入存档。** 现档最坏态落盘 61,103B / 红线余量 4,433B（6.76%），而 `ws.prodigies` 30 行已占 7.64KB（#206 原账分解实测）——200 人若入档必然越线。
- **文本与结构分家**（被审计 A1 钉死）：名号 / 称号 / 简介等中文文本必须进**词表分卷**（新建 `assets/worlds/xiuxian/lexicon-jianghu.js`，A1 白名单命中）；境界带、势力归属、战力偏移、关系边等结构进 `data.js` 新表 `D.JIANGHU`。`data.js` 不在 A1 白名单内，把简介写进去直接判红。
- 词表规模影响：200 人 × 名号 + 简介 ≈ +400 键（现行 4754，A4 只判「值内不许有英文词」，名号值天然合规）。
- 新件必须**只挂进 `view/index.html` 的装载序列**（D2 单源），`module/index.html` 不许分叉。
- **存档只落三样**：世级种子一枚、本世出场位（每榜 10 人 × 4 榜 = 40 条 `{id, 生死, 榜}`）、角色间关系的**稀疏边**（只存确实有关系的对，硬上限 ≤ 40 条，超限按最旧裁）。
- 名池唯一性：现行命名池 9×7×5，道友池已占 58 名 ⇒ 每世出场者按「池内不重名」抽（沿用天骄名录既有的 `usedNames` 去重写法），并保证与道友/道侣不撞名。

## 二、四榜切法与升榜

一刀切在「境界带 × 身份」两维上，同一角色只在一榜：

- **天榜**（10）：隐世 3（见下）+ 七席当派掌门 / 宗主 / 太上，境界带 realm ≥ 8。
- **地榜**（10）：各派长老、退役豪强、道友中的高阶者、天骄前列，境界带 6~7。
- **玄榜**（10）：门中骨干（长老以下）与有名散修，境界带 4~5。
- **黄榜**（10）：新秀与无名散修（含各派首徒），境界带 ≤ 3。

隐世三席：战力 = `REALMS[9].power × 际遇上限 ×（0.7 + 0.2 × 世内浮动）`，浮动由**世种子派生且 normalize 幂等**（读三次档数字不许变）；名号与一切明细显 `？？？`，按裁定 2 不给任何交互入口，只作背景与伏笔（传闻里出现、天道问天里点到）。

升榜与补位：角色境界跨过带界 ⇒ 即时升上一榜并播一条传闻；角色死亡 ⇒ 出榜（复用既有 `killOff` 单一写口）、榜位空缺由名库同带最高者**即时补位**并播报。现行榜面节律 `RANK_REFRESH_MS` 是 10 游戏年（3,600 现实秒），太长，只保留作**战力重排**的节律，生死与升榜走即时。

玩家入榜（裁定 3）的三条细则（未单独裁定，按不新增歧义的原则定）：玩家按当前战力插进对应境界带那一榜并高亮「你」；玩家飞升/兵解即腾位、由补位者填；玩家**不占掉落池**，也不给自己当对手（对自己的两颗按钮不渲染）。

## 三、榜面不再显战力

改显 **境界 / 势力 / 兵刃 / 法宝 / 主修功法** 五项（前三项天骄行已有，兵刃/法宝/主修为**新增字段**，由世种子从名库派生、不入档）。

撤掉数字后必须补一个「够不够格」的表达，否则切磋与袭杀成盲盒：用**三档徽标**——可压 / 相当 / 悬殊，由引擎现有 `ratio = 我方实付 / 对方` 直接分档（阈值沿用切磋表值 1.5 与 0.8，**不新建判定口径**）。这条与 N54「故意不报成算百分比」同取向：报档位，不报假精确。

## 四、袭杀掉落改口径

满 3 次身死后，从该角色的兵刃 / 法宝 / 主修功法里随机掉 **≤ 2 件**（档位不高于其境界带）+ 灵石 + 丹药。三条闸：一次性（身死即结，不许刷第二次）；法宝若已持有走既有重复折算；功法若要求未达，**正好落进第卌六批刚上线的「要求未达」一节**（承接方现成，不用新写去处）。加闸的理由写在明处：第卌四批的寻仇链、和第册三批的赏金通胀，都是「新通道没有终止条件」长成流水的同一形状。

## 五、同境界战力差（用户要「上下限相差超过两个大境界」）

- 建议口径：**不新立乘区，改偏移境界表**——`power = REALMS[clamp(rlm + 际遇offset, 0, 9)].power × 资质微调`，offset 取 `−1 / 0 / +1 / +2` 四档 ⇒ 同境界上下限差 = 3 档 ≈ **27 倍**，按权重让多数人是 0/+1，少数奇遇者是 +2。这样「战力」与「境界」永远同源（第卅八批「第三套战力口径」的教训不复发），也让「隐世高手」有自然的极端档。
- 若要更保守，可先跑 offset `0 / +1 / +2`（差 2 档 ≈ 9 倍）——两档都可行，**这是数值取向，留给用户点一句**。
- 牵连面（一次改全，别漏）：切磋让差（`crush 1.5` / `brave 0.8`）、袭杀门槛 `KILL_RATIO 1.2`、第卌五批的寻仇墙 `REVENGE_FINAL_MIN 1.2`、`sim-pacing` 九画像 18 断言、`sim-event-economy` 阵营主轴与膨胀线、`sim-playthrough` 轨迹锚。这一批**必须**按「改引擎批」双跑换锚 + 主轴复跑。
