稿二 · 三分支抉择模态（EVENT_CHOICE · 模态栈优先级 1）
地 危机 ☾ 守陵人 特殊
荒山古陵起雾，你在雾里迷了路，忽见一点灯火——守陵老翁的小屋。老翁热情留饭，粗茶淡饭竟意外可口，只是汤有点苦，喝下去从喉咙凉到胃里。闲谈间你无意瞥见：油灯照着老翁，他的影子却不在地上，而在墙上——朝着与灯光相反的方向。老翁顺着你的目光看过去，不慌不忙地笑了：「客官看见了？那……这顿饭，就得换个吃法了。」雾，更浓了。
必须选择 · 无倒计时 · 点遮罩不关闭 —— 善恶后果，选后才知
稿二批注（对应 UI v2.0 §5.1）
  • 按钮信息层 = 分支名 + 收益区间预告（浮动值显示「约 X~Y」）+ 判定预告：attr 类给文言成算话术（四成之数/三成把握），stones/qi 类显示花费，companion 类显示所需档位；
  • karma 数值不预告——结果页才揭示（「道心 +N / 道心蒙尘 −N」）；
  • 置灰示例（本稿未画）：karma/align/art/gear/companion 不满足 → 按钮 50% 透明 + 缺项红字（魔道档位下 companion 分支显示「无人可援」）；
  • 带绝交锁的魔道分支加「绝缘」暗纹角标（如迷途灵犬·卖狗、乞丐老仙·夺碗）；
  • 选定后：判定演出 1 秒掷判（判定链逐级），随后进结果页（karma 变化 + 区间内实际取值 + bond 入账行 + 独占获得时全屏演出）；
  • 模态跨离线保留（pendingChoice），回线恢复弹窗，且优先于闭关所得弹窗。
