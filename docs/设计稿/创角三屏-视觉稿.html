帧二批注（UI v2.3 §二 屏 2）
  • 组合角标三型：2正1负（主流 35%）/ 1正1负（40%，正面卡追加「极致单一 · 效果增强 ×1.5」角标）/ 1正2负（25%，高风险高回报）；
  • 稀有词条描金边 + 「稀有」角标；卡面 = 名 + 效果两行，正/负用 success/danger 语义色 + 文字角标（色弱友好）；
  • 问道初心：三段选择写 `profile.alignBias`，默认左道居中；重抽天命不清倾向；倾向只驱动 karma 漂移（12/天，封顶 ±260），不锁定玩法——本演示档选左道、后以行为入正道档，即「底色可被大笔覆盖」的活例；
  • 性别/种族无入口（v2.3 预留纪律：不做置灰占位，默认男/人族，normalize 补默认）；
  • 重抽无限次免费，放拇指热区（屏幕下半）。

  • 锁定只锁创角决策，不锁玩法：倾向可被行为覆盖（karma 漂移只是底色）。

帧四批注（UI v2.3 §二 屏 3）
  • 只展示 `visibleWorlds()`：live（青云界，随机世界名已定格）+ coming（？？？灰显，名字不剧透）；hidden（克苏鲁）永不出现；
  • 世界名与 profile.worldName 同源——屏 3 首次渲染时生成一次，同会话重进不重掷（防刷世界名）；
  • 关键词标签 3 枚（词表 world.{id}.tags），一眼看出世界差异；首发只有一张 live 卡仍按列表布局（为多世界留结构）；
  • 「入世」一次性写入：profile（name/talents/alignBias/gender/race）+ worlds.xiuxian 初始化（含初始洞府·市井别院）+ meta.unlockedWorlds + worldName → 直接进 MAIN 修行页，无过场加载；
  • 入世后再见这些字段的位置：倾向 → karma 浮层「初心倾向」行；洞府 → 地 chip；总账 → 财 chip（启动资金 100 即第一笔 ledger 基数）。
