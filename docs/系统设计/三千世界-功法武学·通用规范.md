## 一、品阶体系（两世界通用）

功法/武学按价值分四品阶，**学习要求随品阶递进**（落实「根据价值而定」）：

| 品阶 | 主效果/级 | 学习要求带 | 获取渠道 | 定位 |
|---|---|---|---|---|
| 黄字阶 | 3~5% | 无要求 ~ 界位 1 + 无属性门槛 | 商店低价 / 初始 | 前期过渡与字段补齐 |
| 玄字阶 | 5~7% | 界位 1~2 + 属性 ≥12~18；邪派 恶名 ≤-100~-120 | 商店中价 / 低区首通 | 中期主力 |
| 地字阶 | 7~10% | 界位 3~4 + 属性 ≥24~30；邪派 恶名 ≤-180~-200 | 商店高价 / 中区首通 / 奇遇 | 后期核心 |
| 天字阶 | 9~14%（gateMod 类例外：0.015~0.025/级；**tribBonus 类第卌二批随渡劫难度批减半 = 0.0075~0.0125/级**，现行三部 护体 +0.01 / 九天 +0.0125 / 九霄 +0.01，top6 合计 0.065→0.0325、×9 满级 58.5%→29.25%） | 界位 5~8 + 属性 ≥36~54；邪派 恶名 ≤-300~-500 | 高区首通 / 稀有奇遇 / 黑市高价 | 终局追求（🔧 第廿五批 2026-10-13：渡劫不再清功法等级 ⇒ 长线目标改由「等级全程累积到天阶满级 + 融合」承担，原「清零后重修」口径作废） |

- **属性门槛 = 对应界位裸身基础值**（(界位索引+1)×6，详设 §4.4 规律）——养成玩家可提前一界学会，裸身玩家界位达标即学会，永不死锁；
- 阵营分布目标（每世界）：正 ≈19 / 中立 ≈18 / 邪 ≈14——邪派单部效果 ×1.5 但总数少、门槛深，维持「快但险」；
  🔧 **品阶强度重排批 2026-10-14 · 第卅八批**：上面那张四档「主效果/级」带**整体换档**（3~5 / 5~7 / 7~10 / 9~14 全部作废，
  它们与天字阶 ×9 级 ×6 槽的旧极限表本来就是两套数）。现行口径 = **同字段黄阶中位 × 词条侧阶梯 1 / 2 / 3.5 / 6**（滋养侧另有一条压缩阶梯 1 / 1.5 / 2 / 2.5，见本节下方「数值预算」那条 🔧 与 §4.3），且**黄阶 14 部一字未动**（返工裁定）。
  **主效果带**（每部最大非红线字段）黄 2~10% ‖ 玄 4~12% ‖ 地 11.2~21.9% ‖ 天 9~31.5%，四档中位 4.0 / 9.0 / 16.1 / 23.3。
  零重叠的**射程要说清**：冒烟 **#301(b)** 只管「同字段 玄→地→天 不倒挂」——实测口径 = 8 个有黄阶样本的非红线字段内的 **19 对相邻阶**，其中 **12 对（玄→地 / 地→天）零容忍**、**7 对（黄→玄）不参与零容忍**；
  **黄→玄 允许两条在册例外**（聚灵诀 qiCap 10% 高于 qiCap 玄阶最低 6.4%，吐纳法 qiRate 5% 高于 qiRate 玄阶最低 4.8%），由 #301(g) 钉成**集合相等**——
  多一条倒挂或例外被悄悄抹平都会红。学习要求带与获取渠道两列**一字未动**。
- **品阶带例外（校对批登记）**：聚灵诀（黄字阶）`qiCap +10%/级` 超黄阶 3~5% 带——qiCap 为低敏感乘区（只放宽挂机上限、不加速产出，见《精气神属性实现》§二），词条值维持定稿（功法全录与数值详设 §4.3 一致），登记为黄阶换算带例外；

  「黄阶保持现值」——现按 dev 原值 **10%/级** 回补，于是它仍然高过 qiCap 玄字阶中位（8%）。这条就是 §一 上面那条
  「黄→玄 在册例外」的第一条，判据 #301(f)(g) 认它的存在；`qiCap` 的天字阶顶格（混元功 30%/级 = 黄中位 0.05×6）仍按同一条阶梯推导。§2.7 各批登记的其它品阶带例外（星辰真经 / 圣心经 / 昆吾镇魔章 / 问心篇 / 龙泉锻剑录 /
