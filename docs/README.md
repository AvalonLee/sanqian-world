> 入口 HTML 与回归资产（`.tests/`）在 `extensions/com.avalonlee.sanqian-world/` 下——**仓库里只有一份
> 事实源**（原先仓库根那份逐字节副本已删，审计 B9 退役、D4 接管）。本目录各卷正文与批次史里的
> `assets/…`、`view/index.html`、`.tests/…`、`node .tests/…` 一律读作**相对扩展目录**；这是历史行，
> 按「历史注逐字不改写」纪律不批量替换，只在此立一条口径。

> **归置与文档纪律 → 现行唯一事实源 = [`总纲/docs-归类整理规范.md`](./总纲/docs-归类整理规范.md)**（册262 立）：分区准入（docs 根只减不增）/ 入口件职责表（全仓 README 分工）/ 文档三态与维护义务 / 新建五步 / 随批更新矩阵 / 归档退出五步 / 检索纪律（任何检索先排 `_archive`）。2026-10-01 归置纪律与 2026-10-02 整顿批六条（①版本志分层 ②批次单账本=主设计 §七A ③版本总账=VERSIONS ④计数总账=FACTS ⑤归档区 ⑥卷名去计数）已全部并入该卷 §一~§六，此处不再复制；历史全文走 git 史。

> 代码冻结纪律：所有数值/字段调整**先改文档再改代码**；文档间引用以各卷「唯一事实源」标注为准，历史版本注只追加不改写。
