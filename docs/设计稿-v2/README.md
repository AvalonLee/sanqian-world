## 怎么打开

直接双击 `index.html`（或浏览器打开本地文件）。零依赖、零外链、无构建步骤。

顶部工具条（屏幕选择器 / 桌面·手机切换 / 渡劫演出 / 抉择模态 / 更新公告 / 墨夜）与底部说明区都是**原型专属工具**，不入产品：

- 屏幕选择器：直接跳到任意一屏；
- 桌面 / 手机（预留）：在 1440 宽与 392×848 设备框之间切换；
- 渡劫演出 / 抉择模态 / 更新公告：浮层演示入口；
- 墨夜：原型自带主题切换（D1=B 已拍板迁入时保留纸面与自带墨夜，但入口是否保留需在 B1 定）。

## 演示占位的边界

原型里的世界名、玩家数值、道友名册与苏晚设定、黑市货池、宗门弟子、委托与事件名等，**都是演示数据**，不是规格；迁入时从引擎与词表取。逐项清单见移植方案 §2.7。原型里的「天 / 地 / 人」品阶也已按现行数据改回「稀有 / 寻常」——现行创角池只有 `common` / `rare`（转世另有 `epic`）。
