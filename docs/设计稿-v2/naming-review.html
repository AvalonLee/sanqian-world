名字的问题不在难听

我把 15 个页名连同页内区块名，对着 assets/lexicon.js 和 worlds/xiuxian/lexicon.js 核了一遍。 结论是：页名本身大多不差，真正乱的是同一概念有好几个名字——玩家得在脑子里做翻译。 比如同一条数值，浮层标题叫「善恶」，事件结算写「道心 +15」；同一页内容，导航叫「法与器」，日志分类叫「功法」，四柱 chip 又叫「法」。

一六类问题

01一物多名

同一条数值：浮层标题 karma.system = 「善恶」，事件文案 = 「道心 +15」，代码 = karma。

同一套东西：导航「法与器」、日志分类「功法」、四柱「法」。

02层级被并列

combat.system = 「秘境洞天」：秘境是去打的地方，洞天是住的地方，两者在页内是两节，却拼成一个页名。

「势力」与「宗门」并列成两页，但宗门本就是势力的一种。

03页名与内容不符

jianghu.system = 「江湖榜」，但页里只有同代天骄，没有别的榜。

已裁定保留榜名作江湖门面更响，语义靠页首副标补足。

04页名与模式撞名

「历练」既是修行页的一个模式（idle.mode.venture = 外出历练），又在新导航里当区名。

一个词指两个层级，玩家说「去历练」时不知道是切模式还是换页。

05长度不齐

修行、奇遇、坊市、道友、势力、宗门、成就、轮回、日志、设置——十个两字。

秘境洞天、炼丹炼器两个四字，在竖排导航里会折行或被迫缩字号。

06产品词混进叙事

日志、设置是产品词，其余十三个都是世界观词。

混排会让「生平」区读起来像设置面板，而不是人生记录。

四四条命名规则（建议写进 AGENTS.md）

一
页名答「去哪」，模式名答「干什么」

页名一律是地方或名册（秘境、坊市、天骄榜）；模式名一律是动作（闭关、历练）。同一个词不能同时当两者。

二
一个概念，四处同字

导航、页标题、浮层标题、日志分类——这四处出现同一个概念时，必须用同一个词。改一处就要四处一起改。

三
两字优先，四字只在不可拆时用

竖排导航与底部 tab 都吃字数。炼丹炼器是唯一必须四字的情况（两套熟练度），其余一律两字。

四
产品词不与世界观词混排

日志、设置这类产品词，集中放在「生平」区最末，不与秘境、道友这类世界观词交错出现。

五决议

「秘境洞天」→「秘境」 导航与页面标题。洞天福地仍在页内分节，也仍是「秘境」区的子项。
采纳
「善恶」统一为「道心」 浮层标题、属性浮层、渡劫预估、伏击文案一并改。「善恶到头终有账」这类散句保留原文，不当作标签。
采纳
修行页模式名 →「闭关 / 历练」 原「闭关修炼 / 外出历练」四字在按钮里会挤。散句里仍可写「闭关修炼」，不强制改。
采纳
「江湖榜」是否改「天骄榜」 页内只有同代天骄，但榜名作为江湖门面更响。
保留原状
「法与器」拆为「功法 / 百器」两页 2026-10-19 追加。原页一半是功法养成、一半是法器配装，靠「功法／法器」分段来回切，两种玩家意图挤在一起。词表里 gear.system 本就叫「法器」，四槽为兵刃／灵器／甲衣／佩饰，与「法宝」（treasure.system，三槽、一条签名效果、不可炼化）是两套独立系统。页名取「百器」而非「法器」，是为与「法宝」拉开距离（法器／法宝在中文里几乎是同义词），也呼应原项目自己的「百器录」。拆开后道器区成为 功法 / 百器 / 法宝 / 炼丹炼器 / 坊市。

落码：gear.system 现值「法器」需改为「百器」；tribulation.resist（渡劫明细里的「法器抗性」）同步改「百器抗性」。
