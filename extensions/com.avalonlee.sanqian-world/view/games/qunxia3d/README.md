# 山河棋盘 · 三维水墨演示（three.js demo）

把《三千世界》武侠江湖页中央的「山河棋盘」（`view/games/qunxia/game.html` 世界图）做成**三维可旋转水墨地图**的独立演示稿。**仓外 spike，零仓内改动**——不进扩展、不碰门禁；将来若正式并入 game.html 属独立批次（接管点 = `renderWorldMapNodes()`，game.html:3800）。

**当前阶段**：可视化壳完成（世界图真实地理 + 30 特色本境 + 钻入双层）→ 游戏化改造启动，总纲见 **《游戏化改造计划书.md》**（M0~M6 里程碑 + 迁移清单 + 数值对表纪律），本境设定资料见 **《本境3D规划.md》**。

## 打开方式

- **双击 `index.html`**（file:// 直开，classic script 无 CORS 限制），或
- 本地服务：`node <任意静态服务>` 后开 `http://127.0.0.1:<port>/`。

## 操作

| 动作 | 效果 |
| --- | --- |
| 拖拽 | 旋转方位/俯仰（带阻尼；拖拽时自转自动关停） |
| 滚轮 / 双指捏合 | 推近拉远（世界 240~1500 / 本境 220~1150 钳制） |
| 双击 / 「复位视角」 | 镜头回 Home（本境内回本境 Home） |
| 点击地界 | 水墨信息卡 + 镜头聚焦；邻接 chips 可连跳 |
| 「进入本境 ▸」 | 相机俯冲 + 纱幕过渡 → **本境 7 格 3D 沙盘**（Esc / 「⟵ 回到山河」退出） |
| 本境内点格 | 格卡（名号/类型/描述/邻接格 chips 可跳转）；驻足格带朱砂印与脉冲环 |
| 「自转」 | 缓慢环绕展示开关（世界/本境通用） |
| 「地名」 | 竖排地名显隐（世界层） |

## 数据来源声明（演示占位，规范 §2.7 惯例）

- **30 地界**：名号/副题/势力/描述提取自现行 `game.html` `REGIONS` 表（分支 wuxia，commit cfaf5d3）；**坐标为真实地理投影版**（2026-11-07）：真实经纬锚点 → `x=(lon-82)*20, y=(50-lat)*20`（东经 82~132°、北纬 20~50° 映射 1000×600）+ 最小间距 40px 松弛（桃花/侠客/冰火三岛钉死）。经纬锚表与重排脚本：`%TEMP%\sq-demo3d-regeo.cjs`（一次性，可重跑再生成；黑木崖/冰火岛等原著模糊处取通行说法）。
- **山河湖海骨架同步真实化**：河道 = 真实黄河（星宿海源-河套-风陵渡-开封北-入海）与长江（石鼓弯-宜宾-重庆-荆江-建康-长江口）简化折线；湖泊 = 洞庭 / 鄱阳 / 太湖 / 青海湖真实落位 + 星宿海泽畔诸池（挂星宿海节点，湖心孤屿护持——燕子坞即太湖畔孤洲）；山系 = 名山主峰挂真实地界 + 昆仑/喜马拉雅/天山/祁连/阴山/太行/秦岭/巫山武陵/南岭/横断/长白余脉/江南丘陵/武夷/阿尔泰走廊成链；长城按明长城走向（嘉峪关-河套-雁门关-居庸-山海关）；东海岸按真实岸线（辽东口-山东半岛-长江口-杭州湾-闽粤）+ 北隅冰海一角（冰火岛所在，古地图留海隅惯例）。
- **河道**：取自同文件世界层装饰性河道 SVG path（L897-898），二次贝塞尔采样后加低频蜿蜒。
- **事件 4 枚**（雁门/光明顶危机、燕子坞事件、华山论剑终局）为**演示占位**，非现行世界事件排期（正典排期在 `content-merge.js` `EV_TURN_MAP`）。
- **峰群 / 海岸线 / 地界台地**为美术占位（`board3d.js` `PEAKS` 表 + terrainH），非地理数据。东海岸 = `COAST` 折线 + 噪声岸线，桃花岛 / 东海侠客岛 / 极北冰火岛三地界以孤屿形式落于海中（`ISLANDS` 表 punch 出陆域），桃花岛另有粉墨桃花点缀与环岛舟。
- **湖泊**（洞庭湖 / 太湖 / 星宿海泽畔诸池，`LAKES` 表）、**城镇村落**（8 镇 + 16 村 + 4 处大城城郊，seeded 伪随机布点于路旁水畔）、**边墙烽燧**（北境意趣）、**植被分布**（松随山、竹随水、苇随湖）与**舟楫**均为美术演示占位，非历史地理数据。
- 聚落房屋 = 徽派白墙黛瓦（人字双坡顶 + 白山墙，单几何体合并 + InstancedMesh ~120 实例）；植被 = Points 逐点尺寸/浓淡（4 种 canvas 墨笔纹理，~1100 点，成簇分布）。
- **本境双层**：每地界 7 格按 game.html 本境坐标（1000×560）铺成 3D 台地沙盘，八类格用小景（渡口栈桥/酒肆酒旗/铸炉炉火/宗门重檐/演武台/灵脉石门/秘境石拱/名胜亭树）全用墨色原语与 mist 晕染；钻入 = 相机俯冲 + 纸色纱幕切场景，世界/本境各自独立轨道与 Home，格数据与格间 `next` 路网取自现行 game.html。
- **本境特色化（设定卡驱动）**：每地界一张设定卡（`local-specs.js`）→ 起伏地形（贴卡着色两阶 + 台基护平 + 水域下切）、有机岸线水域、环境植被（松/竹/苇/花树，uTint 调色：桃粉/杏粉/山茶红/银杏金/枯草黄）、29 种参数化标志件（城楼/城墙/烽火台/佛塔/白塔/三塔/多檐楼/石阶/铁索桥/石拱桥/毡帐/吊脚楼/木屋/鼎/崖壁/火山锥/冰岩/石峰簇/太极台/古墓丘/瀑布/旗幡/火盆/花圃/废墟柱/雪斑/石室弧阵/极光带/阵法桩）、五族天候粒子（牡丹落瓣/落雪/余烬/浮萤玉蜂/潇湘雨）、雾浓与雾染逐卡可调。全部程序生成零资产。

## 美术要点（调参入口都在 board3d.js）

- **墨色**：地形 ShaderMaterial 按高度/坡度/噪声定墨密度，皴笔 = 高处顺坡淡横纹；`PAL` 调色板。
- **山形**：`terrainH()` = fBm 丘陵 + 高斯峰群（ridged 锐化）+ 缘山带 − 河道下切 + 地界台地宽缓压平。
- **海墨**：东南隅 smoothstep 海 mask（海岸线带 fbm 起伏），谷底淡黛染由 fragment shader 依高度混色。
- **竖排地名**：canvas 逐字竖排 + 裱纸晕边（`vlabel()`）；印章 = 圆角方印白文单字（`sealTexture()`）。
- **行脚**：随机邻接游走（`walk` 状态机）+ 尾波环池；**雾**：8 枚缓漂雾团 sprite + scene.fog + 地形 shader 手写雾。
- **雪意**：高山留白（fragment shader 依高度混纸色，大雪山大长白白头）；**湖面** = terrainH 洼地（水面基准启动期按周边地形自适应）+ 有机岸线多边形。
