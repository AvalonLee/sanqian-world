# 山河棋盘 3D · 三维水墨武侠棋盘（自包含子应用）

把《三千世界》武侠江湖页中央的「山河棋盘」（`view/games/qunxia/game.html` 世界图）做成**三维可旋转水墨地图**，并自第册二百七十二批起**整目录入库为扩展子应用**（qunxia-home 双路由 `?engine=3d/classic`；**册282 M7 起缺省 3d**，classic 为 `?engine=classic` 备选；最终形态已拍板 = 3D 版成熟后替换 game.html + 启动层世界选择器）。

**当前阶段**：**M0~M5 收官 + M6 尾量 + M7 已翻转缺省**（册273~册293）——数据抽取管线 11 表 + core/state|time|player 纯函数 + 存档续玩（新键 `shanqian3d_save_v1`）+ 八格动作/三招对决/36 案生命周期/五抽屉/名宿三幕/终局/五曲 BGM/设置中心/邸报合集全部在码；册299 创角改为**真五步分屏**（出身→命格→誓言→姓名→复核）。余量 = 自选原声导入 + P4 五大扩展（定序 A 市井 → C 朝廷 → B 配角 → F 立号 → E 情缘）。数值对表 `table-check` 263 判、走查 `QUNXIA3D_ALL_GREEN 54/54` 常驻门禁。总纲见 **《游戏化改造计划书.md》**（M0~M7 里程碑 + 迁移清单 + 四铁律 + 新知沉淀），本境设定资料见 **《本境3D规划.md》**。体验 3D 版 = 缺省即是（或本目录 index.html file:// 直开）。

## 打开方式

- **双击 `index.html`**（file:// 直开，classic script 无 CORS 限制），或
- 本地服务：`node <任意静态服务>` 后开 `http://127.0.0.1:<port>/`。

## 美术要点（调参入口都在 board3d.js）

- **墨色**：地形 ShaderMaterial 按高度/坡度/噪声定墨密度，皴笔 = 高处顺坡淡横纹；`PAL` 调色板。
- **山形**：`terrainH()` = fBm 丘陵 + 高斯峰群（ridged 锐化）+ 缘山带 − 河道下切 + 地界台地宽缓压平。
- **海墨**：东南隅 smoothstep 海 mask（海岸线带 fbm 起伏），谷底淡黛染由 fragment shader 依高度混色。
- **竖排地名**：canvas 逐字竖排 + 裱纸晕边（`vlabel()`）；印章 = 圆角方印白文单字（`sealTexture()`）。
- **行脚**：随机邻接游走（`walk` 状态机）+ 尾波环池；**雾**：8 枚缓漂雾团 sprite + scene.fog + 地形 shader 手写雾。
- **雪意**：高山留白（fragment shader 依高度混纸色，大雪山大长白白头）；**湖面** = terrainH 洼地（水面基准启动期按周边地形自适应）+ 有机岸线多边形。
